# 面试答题方法论

## 七步框架

1. 澄清输入、输出、规模、重复、是否有序、是否允许修改。
2. 先给能工作的基线，不急着跳最优解。
3. 指出基线中被重复执行的昂贵工作。
4. 识别 Hash/单调性/前缀/局部性/等价类/区间聚合等结构性质。
5. 明确不变量，并用它指导代码。
6. 手推边界；再报告最坏/平均/摊销复杂度。
7. Follow-up 先找“被改变的前提”，只替换受影响的结构层。

## 面试评分视角

- Problem framing：是否主动澄清而非猜题。
- Algorithmic reasoning：是否能从 baseline 推导优化。
- Correctness：是否能用 invariant/归纳/反证解释。
- Code quality：命名、边界、模块化、无隐式高复杂度操作。
- Complexity：是否给出正确口径。
- Communication：是否持续让面试官知道当前假设与下一步。
