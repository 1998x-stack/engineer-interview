使用说明与版权边界
定位 这不是“100 个答案”的堆叠，而是一套面向编码面试的结构化训练系统。每题统一从题意澄清、基线方
案、关键洞察、不变量、参考实现、复杂度、失分点和追问展开。

本书借鉴《剑指 Offer》“围绕问题组织知识、逐步优化解法、强调代码质量与面试沟通”的教学思想，但全
文、代码、图表和版式均为重新设计的原创内容，不复刻该书文字或页面。

题目来源口径：一部分是长期高频的经典数据结构原型；少量题目标记为“公开面经变体”，来自候选人公开
分享，仅用于观察题型趋势，不代表任何公司的官方题库，也不保证未来重复出现。

建议使用方式：第一次只看“题目 + 题意澄清”，自己讲出基线方案；第二次读“关键洞察 + 不变量”；第
三次手写代码并覆盖边界；最后只看追问，训练结构替换能力。

能力地图：100 题不是 100 种算法
高质量准备的目标不是记住 100 份代码，而是把问题快速压缩到有限的结构模式。可以把整套题库近似理解
为：

 核心公式 100 道题 ≈ 20 个核心 Pattern × 多种边界/约束/追问变体。真正的面试能力来自“识别 Pattern →
 建立不变量 → 用约束证明复杂度”。

复习优先级与面试方法
截至 2026 年，Tech Interview Handbook 的最新学习清单仍把 Array、String、Sorting/Search、
Matrix、Tree、Graph 列为 High Priority；Hash Table、Linked List、Queue、Stack、Heap、Trie、
Interval 列为 Mid Priority。本书因此将前 86 题作为主战区，区间树与复合设计用于冲击更高难度和高级岗
位。

每道题建议按以下 7 步口述：① 澄清输入/输出与边界；② 给出能工作的基线；③ 指出瓶颈；④ 识别可利用
的结构；⑤ 写出不变量；⑥ 编码并自测；⑦ 报复杂度并主动回答 follow-up。

   输入是否有序？是否有重复/负数/空值？
   允许修改输入吗？需要稳定顺序吗？
   数据规模多大？目标复杂度是否暗示特殊结构？
   先说基线，避免“背答案感”。
   优化时明确“减少了哪类重复工作”。
   写代码时用 invariant 驱动而非凭感觉。
   最后主动覆盖空输入、单元素、极端重复、极端偏斜等边界。

目录
第一章 数组、字符串、矩阵与区间                     Q001-Q015

   把连续空间问题压缩成 Hash、双指针、滑动窗口、前缀和、二分与 Sweep Line。

第二章 HashMap / HashSet       Q016-Q023

   理解 O(1) lookup 的价值，也理解它只是平均复杂度；从应用走到底层冲突与扩容。

第三章 链表      Q024-Q033

   核心不是 API，而是指针不变量：保存 next、Dummy、快慢指针、局部反转。

第四章 Stack / Queue / Deque      Q034-Q043

   嵌套结构、最近未完成状态、单调关系、FIFO 层级搜索。

第五章 Binary Tree / BST     Q044-Q058

   从递归定义出发，区分“向父返回的状态”和“当前节点形成的全局答案”。

第六章 Heap / Priority Queue      Q059-Q066

   Top-K、动态最值、K 路归并、在线中位数与调度。

第七章 Trie / Prefix Tree   Q067-Q072

   把字符串集合压缩成公共前缀图；理解空间换查询与前缀剪枝。

第八章 Graph / BFS / DFS / Union-Find          Q073-Q086

   先建模图，再决定遍历、最短路、拓扑、连通性还是最小生成树。

第九章 Fenwick / Segment Tree / Range Structures           Q087-Q092

   处理“动态更新 + 区间查询”，理解数据结构如何缓存可组合的区间信息。

第十章 复合数据结构设计             Q093-Q100

   把单一结构的短板通过组合补齐，并用 invariant 驱动 API 复杂度设计。
