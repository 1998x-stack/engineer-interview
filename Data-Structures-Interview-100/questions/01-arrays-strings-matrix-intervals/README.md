# 数组、字符串、矩阵与区间

> 本章覆盖 **001-015**，共 15 题。

## 源书稿章节导语

> 把连续空间问题压缩成 Hash、双指针、滑动窗口、前缀和、二分与 Sweep Line。

## 章节能力目标

- 优先检查 Hash、双指针、滑动窗口、前缀和、二分、单调结构与 Sweep Line。

## 深化版章节训练目标

**章节核心：** 索引、连续区间、单调性与边界

**主要 Pattern：** `Hash / Two Pointers / Sliding Window / Prefix / Binary / Sweep Line`

### 面试前的三次检查

1. 先判断是否连续区间
2. 再判断是否有序/单调
3. 最后考虑是否需要在线状态或区间事件

### 难度分布

- `E`：1 题
- `H`：5 题
- `H+`：1 题
- `M`：8 题

### 推荐训练顺序

1. **基础结构题**：先练接口与基本不变量，不追求花哨优化。
2. **Pattern 题**：把同一结构的 2–3 题连续做，找共同状态定义。
3. **Hard/变体题**：只看约束，不看题名，练从 baseline 推 structure。
4. **Follow-up 复盘**：不重写整题，只回答“哪个前提变了、哪一层结构要换”。
