# 链表

> 本章覆盖 **024-033**，共 10 题。

## 源书稿章节导语

> 核心不是 API，而是指针不变量：保存 next、Dummy、快慢指针、局部反转。

## 章节能力目标

- 先画指针关系，再修改 next；Dummy、快慢指针、局部反转是高频基本功。

## 深化版章节训练目标

**章节核心：** 指针不变量与 O(1) 局部重连

**主要 Pattern：** `Dummy / Reverse / Fast-Slow / Interleaving`

### 面试前的三次检查

1. 所有改链前保存 next
2. 用 dummy 消除头节点特殊分支
3. 节点身份与节点值分开

### 难度分布

- `E`：2 题
- `E/M`：2 题
- `H`：1 题
- `M`：4 题
- `M/H`：1 题

### 推荐训练顺序

1. **基础结构题**：先练接口与基本不变量，不追求花哨优化。
2. **Pattern 题**：把同一结构的 2–3 题连续做，找共同状态定义。
3. **Hard/变体题**：只看约束，不看题名，练从 baseline 推 structure。
4. **Follow-up 复盘**：不重写整题，只回答“哪个前提变了、哪一层结构要换”。
