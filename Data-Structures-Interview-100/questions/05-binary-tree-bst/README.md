# Binary Tree / BST

> 本章覆盖 **044-058**，共 15 题。

## 源书稿章节导语

> 从递归定义出发，区分“向父返回的状态”和“当前节点形成的全局答案”。

## 章节能力目标

- 先定义函数“向父节点返回什么”，再区分全局答案；BST 额外利用有序性。

## 深化版章节训练目标

**章节核心：** 递归状态、全局答案与 BST 有序约束

**主要 Pattern：** `DFS / BFS / Postorder DP / Bounds / Serialization`

### 面试前的三次检查

1. 先定义 return state
2. 再定义 global candidate
3. BST 使用全局上下界而非父子局部比较

### 难度分布

- `E`：2 题
- `E/M`：1 题
- `H`：2 题
- `M`：10 题

### 推荐训练顺序

1. **基础结构题**：先练接口与基本不变量，不追求花哨优化。
2. **Pattern 题**：把同一结构的 2–3 题连续做，找共同状态定义。
3. **Hard/变体题**：只看约束，不看题名，练从 baseline 推 structure。
4. **Follow-up 复盘**：不重写整题，只回答“哪个前提变了、哪一层结构要换”。
