# Security Policy

This repository is educational content and tooling, not a deployed Agent runtime. Security-relevant corrections are still important because examples discuss permissions, Prompt Injection, HITL, sandboxing, credentials, RAG ACLs, and tool side effects.

For a potentially harmful error in these materials, open an issue that identifies the affected question/file and explains the safer engineering boundary. Do not include real credentials, private data, or exploit material from production systems.
