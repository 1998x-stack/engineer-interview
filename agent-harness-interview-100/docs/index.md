## 推荐入口

- **第一次系统学习**：`preface → architecture → core-20 → 100题`。
- **两周面试冲刺**：先做 Core 20，再做 Q45–Q80，最后练 Q91–Q100。
- **Senior/Staff**：优先第 5–10 章；每题都必须能落到状态模型、fault injection、SLO 与 ablation。
- **生产故障复盘**：从 Failure Taxonomy 反向跳转到对应题目。

## 每题阅读层级

`1–3A` 建立概念与生产机制；`4–7` 训练 failure/trade-off/eval/追问；`8–11` 训练面试表达；`12–13` 做资料与知识关联；`14` 进入 Design Review / Fault Injection / Staff-level 深挖。
