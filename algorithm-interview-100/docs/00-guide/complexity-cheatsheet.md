# 复杂度速查

| 结构/算法 | 常见复杂度 | 面试解释重点 |
|---|---:|---|
| Hash/Set | 平均 O(1) 查询/更新 | 说明平均复杂度与额外空间 |
| 排序 | O(n log n) | Top-K 不一定值得全排序 |
| Heap | push/pop O(log k) | 为什么堆只需保持 K 个 |
| BFS/DFS | O(V+E) | 网格通常 O(mn) |
| 二分 | O(log R) | R 可以是索引空间，也可以是答案范围 |
| Union-Find | 摊还近 O(1) | 路径压缩 + 按秩/大小合并 |
| DP | 状态数 × 单状态转移 | 先数状态，再数每状态工作 |
| Backtracking | 通常指数级 | 说明剪枝和输出规模，不机械背 O(2^n) |
