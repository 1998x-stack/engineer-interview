# 六步白板协议

1. **复述约束**：规模、有序性、能否修改、重复/负数/空输入。
2. **给出基线**：先给正确方案，让优化有比较对象。
3. **找信息浪费**：重复计算了什么？能否哈希、排序、复用状态、利用单调性？
4. **定义不变量**：窗口何时合法？`dfs` 返回什么？heap 保存什么？`dp[i]` 精确表示什么？
5. **写代码并 dry-run**：至少测一个正常样例 + 一个极端边界。
6. **主动给追问**：复杂度、空间优化、流式/分布式、约束变化。

## 面试表达模板

> “基线方案是 …，瓶颈在 …。这里可以利用 … 把重复工作消掉。我会维护的不变量是 …。因此每个元素最多被处理 … 次，复杂度为 …。写完后我会用 … 边界做 dry-run。”
