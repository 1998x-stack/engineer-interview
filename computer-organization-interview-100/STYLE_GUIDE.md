# Style Guide · v2

每题采用统一顺序：

1. 面试定位
2. PDF 核心内容
3. 第一性原理推导
4. 机制展开
5. 定量模型与最小例子
6. 边界条件与反例
7. 工程验证
8. 架构实现差异
9. 30 秒 / 2 分钟 / 5 分钟回答
10. 追问树
11. 错误表达修正
12. 评分标准与自测
13. 关联题与官方参考

## 强制原则

- 先结论后细节；
- 明确 architectural vs microarchitectural；
- “更快/更慢”必须落到 latency、throughput、IPC/CPI、miss rate、bandwidth、MPKI 等指标；
- 教材模型与现代实现并列，而不是互相替代；
- 任何具体 cache latency、ROB size、predictor 结构都不得冒充 ISA 固定事实；
- 原 PDF 内容与 GitHub 增强内容必须显式分区；
- 不伪造公司/面试轮次归属。
