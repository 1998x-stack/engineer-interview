# 第 1 章｜体系结构与数据表示

> **本章目标**：从“软件看到的抽象”与“硬件真正保存的位模式”之间建立映射：同一串 bit 在不同类型、端序、位宽与 ABI 下可能具有不同语义。

## 能力阶梯

| 层级 | 你应该做到什么 |
|---|---|
| L1 定义 | 30 秒说清术语和目标 |
| L2 机制 | 能画出最小硬件/执行链 |
| L3 定量 | 能用公式、数量级或 PMU 指标分析 |
| L4 边界 | 能指出架构保证与微架构差异 |
| L5 工程 | 能设计 benchmark / profiling 验证假设 |

## 本章核心指标

重点关注表示范围、编码空间利用率、对齐/访存代价与 ABI 可移植性。

```mermaid
flowchart LR
A[源程序中的值] --> B[编译器/ABI]
B --> C[机器位模式]
C --> D[寄存器/内存]
D --> E[端序/对齐/类型解释]
E --> F[程序可观察结果]
```

## 学习要求

建议每题完成三轮：

1. **30 秒**：只答结论、机制、边界；
2. **2 分钟**：加入一个公式/最小例子；
3. **5 分钟**：加入架构差异、工程指标与反例。

完成本章后，不应只“认识名词”，而应能把 10 道题连接成一条因果链。
