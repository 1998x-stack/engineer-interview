# 第 2 章｜运算器与计算机算术

> **本章目标**：把运算理解为“有限位宽上的布尔电路”，而不是无限精度数学。正确性来自编码规则、进位链、舍入规则与异常状态。

## 能力阶梯

| 层级 | 你应该做到什么 |
|---|---|
| L1 定义 | 30 秒说清术语和目标 |
| L2 机制 | 能画出最小硬件/执行链 |
| L3 定量 | 能用公式、数量级或 PMU 指标分析 |
| L4 边界 | 能指出架构保证与微架构差异 |
| L5 工程 | 能设计 benchmark / profiling 验证假设 |

## 本章核心指标

关注关键路径、组合逻辑深度、吞吐/延迟、溢出条件与舍入误差。

```mermaid
flowchart LR
A[输入操作数] --> B[编码/符号解释]
B --> C[ALU/FPU 数据通路]
C --> D[规格化/舍入/标志位]
D --> E[有限位宽结果]
```

## 学习要求

建议每题完成三轮：

1. **30 秒**：只答结论、机制、边界；
2. **2 分钟**：加入一个公式/最小例子；
3. **5 分钟**：加入架构差异、工程指标与反例。

完成本章后，不应只“认识名词”，而应能把 10 道题连接成一条因果链。
