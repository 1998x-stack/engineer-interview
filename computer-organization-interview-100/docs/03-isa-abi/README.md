# 第 3 章｜ISA 与 ABI

> **本章目标**：ISA 是软件与处理器之间的架构契约；ABI 是已编译软件之间的二进制契约。面试时必须把“架构规定”与“某颗 CPU 的实现”分开。

## 能力阶梯

| 层级 | 你应该做到什么 |
|---|---|
| L1 定义 | 30 秒说清术语和目标 |
| L2 机制 | 能画出最小硬件/执行链 |
| L3 定量 | 能用公式、数量级或 PMU 指标分析 |
| L4 边界 | 能指出架构保证与微架构差异 |
| L5 工程 | 能设计 benchmark / profiling 验证假设 |

## 本章核心指标

关注编码密度、取指/译码带宽、寄存器压力、调用开销与兼容性。

```mermaid
flowchart LR
A[高级语言] --> B[编译器]
B --> C[ABI]
C --> D[ISA 指令]
D --> E[微架构实现]
E --> F[硬件执行]
```

## 学习要求

建议每题完成三轮：

1. **30 秒**：只答结论、机制、边界；
2. **2 分钟**：加入一个公式/最小例子；
3. **5 分钟**：加入架构差异、工程指标与反例。

完成本章后，不应只“认识名词”，而应能把 10 道题连接成一条因果链。
