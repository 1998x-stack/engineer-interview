# 第 4 章｜数据通路与控制

> **本章目标**：把一条指令拆成“数据如何流动”和“控制信号如何选择路径”。单周期、多周期与流水线的差异，本质是硬件资源复用和时序切分方式不同。

## 能力阶梯

| 层级 | 你应该做到什么 |
|---|---|
| L1 定义 | 30 秒说清术语和目标 |
| L2 机制 | 能画出最小硬件/执行链 |
| L3 定量 | 能用公式、数量级或 PMU 指标分析 |
| L4 边界 | 能指出架构保证与微架构差异 |
| L5 工程 | 能设计 benchmark / profiling 验证假设 |

## 本章核心指标

关注 critical path、clock period、CPI、资源复用与控制复杂度。

```mermaid
flowchart LR
PC --> IF[取指]
IF --> ID[译码/读寄存器]
ID --> EX[执行/地址计算]
EX --> MEM[访存]
MEM --> WB[写回]
WB --> RF[寄存器文件]
```

## 学习要求

建议每题完成三轮：

1. **30 秒**：只答结论、机制、边界；
2. **2 分钟**：加入一个公式/最小例子；
3. **5 分钟**：加入架构差异、工程指标与反例。

完成本章后，不应只“认识名词”，而应能把 10 道题连接成一条因果链。
