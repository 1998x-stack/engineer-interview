# 面试回答 Playbook

## 30 秒层

一句结论 + 两个关键词 + 一个边界。目标是让面试官确认你“知道是什么”。

## 2 分钟层

按 **设计目标 → 核心机制 → 性能/正确性代价** 展开。此时可以画最小结构图或写一条公式。

## 5 分钟深挖层

主动区分教材模型、ISA 保证与具体微架构实现；给出一个工程例子，并说明如何用 PMU/trace/微基准验证。

## 被追问时的通用顺序

1. 先确认抽象层级：语言 / ABI / ISA / 微架构 / OS / 设备。
2. 再讲可见行为，不先陷入某款 CPU 的细节。
3. 再讨论性能代价：latency、throughput、bandwidth、miss rate、IPC/CPI、coherence traffic。
4. 最后说明“具体实现依处理器/协议 revision 而异”。
