# Contributing

感谢参与。优先接受四类改进：

1. 公式或适用条件纠错；
2. 工程 Gotcha 与可复现实验；
3. 公开权威来源补充；
4. 内部链接、结构与可读性改进。

## 提交前

```bash
python scripts/validate_repo.py
python -m compileall scripts examples/python
```

修改 PDF 原始内容区时，请在 PR 中说明依据；如果只是扩展知识，请放到“仓库增强”区，保持来源边界。

## v1.1 内容质量要求

每个问题文件必须同时保留：

- `PDF 原始内容（完整保留）`：不得在无依据时改写；
- `专家版扩展 v2`：明确属于仓库扩展；
- 高频追问必须给出实质答案，禁止只留下“先定义、再说明”等模板占位；
- 新增公式应写明适用条件；
- 工程结论至少给出一种可验证方法或失败模式。

校验器还会检查正文长度、控制字符、结构化追问答案和内部链接。
