# Content Quality Report — v1.1 Expert Expansion

本页记录仓库 v1.1 第二轮扩写的可验证质量指标。

## 覆盖范围

- 问题 Markdown：**100 / 100**
- PDF 原始字段保留：**100 / 100**
- 专家版扩展 v2：**100 / 100**
- 高频追问：**300**
- 已替换模板占位的追问：**300 / 300**
- 章节 README 专业学习框架：**10 / 10**

## 每题新增结构

1. 核心边界与题目专属专家补充；
2. 推导路线与适用条件；
3. 可计算的小例子；
4. 工程验证矩阵；
5. 高频追问详答；
6. 反例与失效条件；
7. 30 秒 / 2 分钟 / 5 分钟三档回答深度；
8. 自测题。

## 自动质量门槛

运行：

```bash
python scripts/validate_repo.py
```

校验内容包括：100 题数量、PDF parity、v1.1 章节存在、每题最低内容长度、300 追问结构化答案、模板残留、异常控制字符、章节学习框架、内部链接以及 PDF 文件存在性。

## 内容边界

PDF 原始字段仍以随仓库 PDF 和 `data/questions.json` 为准；`data/question_enrichment_v2.json` 与“专家版扩展 v2”属于后续仓库扩展，二者在 Markdown 中明确分区，避免来源混淆。
