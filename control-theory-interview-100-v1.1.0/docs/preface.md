# 前言与使用说明

## 定位

面向控制算法、机器人、自动驾驶、无人机、工业控制、电机控制、航空航天与嵌入式控制岗位。

## 方法

借鉴“问题驱动、连续追问、从概念到实战”的面试书写方法，不复刻任何受版权保护作品的具体文字或版式。

## PDF 使用说明（内容基线）

这不是一本按教材章节重新抄写的控制理论讲义，而是一套以面试决策为中心的知识组织。每一道题均使用固定结构：**标准回答、公式与推导、工程直觉、常见误区、高频追问和 30 秒口述版**。建议第一遍只看“30 秒口述”，第二遍补推导，第三遍按追问链做白板演练。

## 题库来源与边界

题目结构参考公开课程与工程资料的稳定主干：MIT 16.06 将反馈、时域/频域指标、稳定性、根轨迹、Nyquist、频域设计与状态空间列为经典控制核心；Stanford EE363 覆盖状态空间、可控可观、LQR 与 Kalman；Michigan CTMS 按 PID、Root Locus、Frequency、State-Space 与 Digital Control 组织工程教程；Berkeley 非线性控制课程覆盖 Lyapunov、feedback linearization、sliding mode；MathWorks 工业 PID 文档明确讨论 clamping 与 back-calculation anti-windup。

仓库据此构造“真题化”问法，但**不声称某一道题属于某家公司某一场未经公开验证的面试原题**。
