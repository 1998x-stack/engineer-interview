# 参考资料

以下资料用于题库结构核验和仓库增强；PDF 原始内容保持独立标识。

- **MIT 16.06 Principles of Automatic Control** — 经典反馈、时域/频域、Routh、根轨迹、Nyquist、补偿与数字控制。
  - https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/pages/lecture-notes/
- **Stanford EE363 Linear Dynamical Systems** — 状态空间、矩阵指数、可控可观、极点配置、LQR、估计与 Kalman。
  - https://ee363.stanford.edu/lectures.html
- **University of Michigan CTMS** — PID、根轨迹、频域、状态空间、数字控制与工程对象案例。
  - https://ctms.engin.umich.edu/
- **UC Berkeley ENGIN 250A / EE C222 Nonlinear Systems** — Lyapunov、backstepping、feedback linearization、sliding mode。
  - https://undergraduate.catalog.berkeley.edu/courses/1613771
- **MathWorks Anti-Windup Control Using PID Controller Block** — back-calculation 与 clamping anti-windup 的工程说明。
  - https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html
- **Stanford EE364B Lecture 16 - Model Predictive Control** — 有限时域最优控制、receding horizon、MPC 与 horizon/约束。
  - https://see.stanford.edu/Course/EE364B/101

## 使用原则

- 题目不是宣称来自某家公司未经公开验证的“原题”；
- 公开课程用于验证知识主干和扩展阅读；
- 仓库增强内容与 PDF 原文在每个问题文件中明确分区。
