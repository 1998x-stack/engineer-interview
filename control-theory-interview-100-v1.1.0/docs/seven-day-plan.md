# 七天冲刺路线

本页保留 PDF 附录 B 的 7 天安排，并增加每天的验收标准。

1. **Day 1：Q001–Q020** — 反馈、极点、二阶指标、稳态误差。验收：随机抽 8 题，30 秒内不看稿给核心结论。
2. **Day 2：Q021–Q040** — PID、windup、根轨迹、lead/lag。验收：白板画 PID 实现和一张根轨迹。
3. **Day 3：Q041–Q050** — Bode、PM/GM、delay、S/T、Nyquist。验收：手画典型 Bode 并解释低频/交越/高频。
4. **Day 4：Q051–Q070** — 状态空间、可控可观、observer、Kalman。验收：从一个二阶模型写 A/B/C/D 并做 rank test。
5. **Day 5：Q071–Q080** — LQR、MPC、robust、自适应。验收：每个算法能回答“解决什么问题、为什么不用更简单的方法”。
6. **Day 6：Q081–Q100** — 数字实现、Lyapunov、系统调试和开放题。验收：完成一套“仿真稳定实机振荡”根因树。
7. **Day 7：随机 30 题** — 每题 30 秒口述 + 3 分钟深挖；只复习答不顺的追问链。

## 建议计时

- 30 秒：定义 + 核心结论；
- 3 分钟：公式 + 物理直觉 + 一个 Gotcha；
- 10 分钟：完整工程讨论 + 验证方案。
