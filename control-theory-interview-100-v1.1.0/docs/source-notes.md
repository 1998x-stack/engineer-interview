# 来源与内容边界

## PDF 来源层

仓库中的 `pdf/control-theory-interview-100-2026.pdf` 是本仓库的内容基线。每个 Qxxx.md 的 **“PDF 原始内容（完整保留）”** 均来自该 PDF 的结构化生成源，包含：

1. 标准回答；
2. 公式与推导；
3. 工程直觉；
4. 常见误区 / Gotcha；
5. 高频追问；
6. 30 秒口述版。

`data/questions.json` 保存了这些字段以及 PDF 页码映射。

## 仓库增强层

“面试官为什么问”“深度展开”“工程场景”“白板 Checklist”“追问答题提示”“实验建议”“相关题目”等是为 GitHub 版本新增的学习/工程化内容。它们不会伪装成 PDF 原文。

## 公开资料层

MIT、Stanford、Michigan CTMS、Berkeley、MathWorks 等公开资源用于核验知识覆盖与提供进一步阅读入口。
