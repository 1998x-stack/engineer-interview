## 章节学习建议

本章的关键不是记忆术语，而是建立一个统一闭环视角：对象、控制器、测量、扰动和不确定性最终都通过闭环互联发生作用。面试时建议始终追问三个问题：**信号从哪里进入？通过哪条路径到输出？哪个频段最敏感？** 这三个问题能把抽象定义转化成可调试的工程模型。

建模答案最好同时给出“名义模型”和“遗漏项”。前者用于设计，后者用于解释鲁棒性边界。例如刚体模型适合低频姿态控制，但柔性模态、执行器动态和纯延迟往往决定高频可实现带宽。

## 专业学习框架

### 知识主线

- 反馈互联与信号路径
- 传递函数/状态与内部动态
- 极点零点与非最小相位
- 平衡点、线性化与模型误差

### 学完本章应达到

- [ ] 能从物理定律写出最小模型并说明忽略项
- [ ] 能用 S/T 解释反馈、抗扰、噪声和鲁棒性
- [ ] 能区分 I/O 稳定与内部模态问题

### 面试表达原则

建议先画框图，再写方程；所有结论都注明“输入在哪里、输出在哪里、扰动在哪里”。

### 推荐复习顺序

1. 先做本章所有 ★★★★★ 题，只练 30 秒结论。
2. 第二遍只做公式/白板推导，不看标准答案。
3. 第三遍逐题回答“什么时候失效”和“如何用实验验证”。
4. 最后从本章任选两题串成连续追问链，练 5–10 分钟深挖。
