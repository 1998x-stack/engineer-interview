### 标准回答

可控性问的是：是否存在有限时间输入，把系统从任意初始状态送到任意目标状态。Kalman controllability matrix [B AB ... A^{n-1}B] 收集了输入经过系统动态传播后能够覆盖的状态方向；若其秩为 n，则所有状态方向都可被输入影响。

### 公式与推导

$$
\mathcal C=[B\;AB\;A^2B\;\cdots\;A^{n-1}B],\qquad
\operatorname{rank}\mathcal C=n.
$$

### 工程直觉

B 告诉执行器直接推哪些方向，AB 表示推力经过一段系统动态后能传到哪里，继续乘 A 就看更深层传播。

### 常见误区 / Gotcha

rank test 受数值尺度影响。实际大系统应看 controllability Gramian、PBH test 和 condition，而不是仅用浮点 rank 黑盒判断。

### 30 秒口述版

> 可控性是“输入能否触达所有状态方向”。Kalman matrix 把 B 经 A 的传播方向全部展开，满秩就表示理论上每个状态方向都能被操纵。

## 仓库增强：深度展开

可控/可观问题不要只报 rank。rank test 是代数判据，真正的工程问题是：**某个模态能否被执行器影响？某个模态能否在传感器数据中留下可辨识痕迹？** 稳定但不可控/不可观的模态有时可接受，不稳定模态则必须分别满足 stabilizable/detectable。

观测器设计还必须考虑噪声与模型误差；把 observer pole 设得极快虽然名义收敛快，却会显著放大 measurement noise，并暴露离散采样和数值问题。

### 针对本题的进一步理解

可控性是输入方向经 $A$ 反复传播后能否张成整个状态空间。PBH test 往往比 controllability matrix 在理论推导和数值分析中更有洞察。

从面试表达角度，建议把本题组织成四层：

1. **定义层**：先说明对象、变量和适用条件；
2. **数学层**：给最小但足够的关键公式，并解释每一项；
3. **物理层**：把公式映射成能量、时间尺度、频率或信息流；
4. **工程层**：主动说明噪声、延迟、饱和、模型误差或采样等边界。

### 工程场景

以车辆横向控制为例，部分状态可能不能直接测量；观测器用车辆模型与 IMU/GNSS/方向盘传感器融合估计侧偏等内部状态。

将这个场景与当前问题连接时，重点不是套算法名称，而是问：**这个概念会改变哪个闭环信号路径、哪个动态时间尺度、哪个约束余量？** 这能把抽象理论转成可验证的设计判断。

### 1. 核心边界：可控可观与估计

rank test 给二元结论，Gramian/噪声/conditioning 决定工程难度。实际设计不仅问‘能不能’，还问‘代价多大、对噪声多敏感’。

**针对 Q061 的专家补充：** 可控性问的是输入能否在有限时间影响全部状态方向。PBH test 直接检查每个 eigenmode 是否能被 B 激发；Gramian 很小的 eigenvalue 表示理论可控但需要巨大能量，属于‘难控’。

### 2. 推导路线与适用条件

1. 先写 controllability/observability 或 error dynamics。
2. 用 rank/PBH/Gramian 给结构结论，再讨论 conditioning。
3. 估计器问题继续写 innovation 与噪声协方差，说明 bandwidth-noise trade-off。

在白板面试中，建议把“公式”与“成立条件”写在同一块区域。例如写出一个二阶近似或稳定性结论后，紧跟一句：**假设高阶模态足够远、没有显著 RHP 零点/纯延迟、执行器未饱和**。这能明显区分“会背公式”和“会使用模型”。

### 3. 一个可计算的小例子

对同一二阶系统只测位置 $C=[1,0]$，计算 observability rank；给 measurement noise 方差从 $10^{-4}$ 增加到 $10^{-2}$，比较高增益 Luenberger 与 Kalman estimator 的速度和噪声。

这个例子的目的不是训练固定数字，而是练习从 **模型 → 指标 → 非理想因素 → 结论变化** 的完整链路。建议在 Python/MATLAB 中把关键参数做 sweep，而不是只跑一个点。

### 5. 高频追问详答

#### 1. PBH controllability test 是什么？

PBH test：对每个 eigenvalue $\lambda$ 检查 $\operatorname{rank}[\lambda I-A\; B]=n$；等价地，不存在 A 的左特征向量 $v^T$ 满足 $v^TB=0$。它直接检查每个模态是否被输入触达。

#### 2. 可控但非常难控是什么意思？

rank 满只说明理论上存在有限输入能到达状态；若 controllability Gramian 极小 eigenvalue，某方向所需能量巨大，实际 actuator 限制下几乎不可达。

#### 3. Gramian eigenvalue 小代表什么？

有限/无限时域 controllability Gramian 的小 eigenvalue 表示沿某状态方向达到单位幅值需要很大输入能量。rank 只告诉可控/不可控，Gramian 则体现‘好不好控’和 numerical conditioning。

### 6. 反例与失效条件

- **模型层失效**：如果出现未建模柔性模态、显著时延、RHP 零点、强耦合或工作点迁移，原题中的低阶/线性结论可能只在局部成立。
- **实现层失效**：sampling、quantization、filter、scheduler、actuator saturation/rate limit 会改变实际闭环，不应被当作“软件细节”。
- **评价层失效**：只看一个 step response 或单一 PM/GM 容易漏掉噪声、控制努力、内部状态和 worst-case parameter spread。
- **验证原则**：每个重要结论至少对应一个可证伪预测；例如“若根因是 delay margin 不足，则降低 crossover 或减少 latency 后振荡应系统性减弱”。
