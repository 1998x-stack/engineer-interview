# Q083. 采样频率应该怎么选？Nyquist 2 倍为什么远远不够？

### 标准回答

Nyquist 2 倍条件针对理想 bandlimited 信号重建，并不是控制设计推荐。控制环需要在 crossover 附近保留相位和足够时间分辨率；ZOH 与计算延迟都会消耗相位。因此常把 control sample rate 设为 closed-loop bandwidth 的 10--20 倍或更高，再根据 plant、sensor filter 和 processor deadline验证。

### 公式与推导

若 $f_s=1/T_s$，相对 crossover 的离散相位损失与 $\omega_c T_s$ 同量级。

### 工程直觉

每个控制周期相当于只能“看一帧电影”。两帧/周期只够证明没有完全 alias，并不足以看清动作并稳定纠正。

### 常见误区 / Gotcha

提高 sample rate 也不是免费：噪声带宽、计算负载、通信和量化都可能变糟。

### 高频追问

- anti-alias filter 如何选 cutoff？
- inner loop 与 outer loop 可不同采样率吗？
- sampling jitter 如何等效成相位噪声？

### 30 秒口述版

> 控制采样不能只满足 2x Nyquist；通常需要远高于闭环 bandwidth，给 ZOH、计算延迟和滤波留下相位余量，同时满足处理器实时性。

## 仓库增强：深度展开

数字控制不是把连续公式机械替换成差分式。采样、ZOH、计算延迟、量化、溢出和调度抖动都会改变闭环动力学。控制器的实际时序路径应被当成 plant 的一部分。

工程回答最好明确区分采样定理与控制采样率：Nyquist 的 2 倍只是避免理想频谱混叠的下界，而闭环设计通常需要远高于 bandwidth 的采样频率来控制相位损失和离散近似误差。

### 针对本题的进一步理解

采样率选择应从闭环 bandwidth、允许相位损失和 anti-alias filter 一起决定；只说“至少两倍最高频率”通常不是合格控制工程答案。

从面试表达角度，建议把本题组织成四层：

1. **定义层**：先说明对象、变量和适用条件；
2. **数学层**：给最小但足够的关键公式，并解释每一项；
3. **物理层**：把公式映射成能量、时间尺度、频率或信息流；
4. **工程层**：主动说明噪声、延迟、饱和、模型误差或采样等边界。

### 工程场景

以 1 kHz 电机控制循环为例，ADC 采样、滤波、任务调度、PWM 更新会共同造成接近一个或多个 sample 的端到端延迟，这些相位损失必须进入设计。

将这个场景与当前问题连接时，重点不是套算法名称，而是问：**这个概念会改变哪个闭环信号路径、哪个动态时间尺度、哪个约束余量？** 这能把抽象理论转成可验证的设计判断。

## 专家版扩展 v2

> **内容边界**：本节是仓库第二版扩展，基于经典控制理论与工程实践补充；它不改写上面的 PDF 原始内容。若扩展结论需要额外假设，会在正文中显式说明。

### 1. 核心边界：采样、数值与实时实现

数字控制的关键是把 sampling、delay、quantization、overflow、multi-rate 和 scheduler 纳入闭环模型，而不是把它们当软件实现细节。

**针对 Q083 的专家补充：** Nyquist 2 倍只是避免理想带限信号混叠的理论下限，不保证控制性能。控制采样通常应显著高于 closed-loop bandwidth，并留出 anti-alias filter、计算 delay 和 jitter 的相位余量。

### 2. 推导路线与适用条件

1. 从连续模型和采样保持假设开始，不先写差分公式。
2. 推导 $A_d,B_d$、z-plane pole 或离散控制器，并显式加入 delay。
3. 最后做 fixed-point/quantization/jitter/multi-rate 与 worst-case timing 验证。

在白板面试中，建议把“公式”与“成立条件”写在同一块区域。例如写出一个二阶近似或稳定性结论后，紧跟一句：**假设高阶模态足够远、没有显著 RHP 零点/纯延迟、执行器未饱和**。这能明显区分“会背公式”和“会使用模型”。

### 3. 一个可计算的小例子

取连续 pole $s=-5\pm j5$。分别用 $T_s=1\,ms,20\,ms,100\,ms$ 映射到 $z=e^{sT_s}$，再加入 1 sample delay 比较相位余量/阶跃变化，直观看到采样率不是只满足 Nyquist 即可。

这个例子的目的不是训练固定数字，而是练习从 **模型 → 指标 → 非理想因素 → 结论变化** 的完整链路。建议在 Python/MATLAB 中把关键参数做 sweep，而不是只跑一个点。

### 5. 高频追问详答

#### 1. anti-alias filter 如何选 cutoff？

Anti-alias filter cutoff 必须低于 Nyquist，同时不应在控制 crossover 附近引入过多相位。通常需要结合 sensor noise spectrum、desired bandwidth 和采样率联合设计，而不是固定取 $f_s/2$。

#### 2. inner loop 与 outer loop 可不同采样率吗？

可以而且常见。内环通常更快；外环慢速计算降低 CPU 负担。关键是跨速率信号同步、hold、滤波和 latency，避免把异步更新当成同一时刻数据。

#### 3. sampling jitter 如何等效成相位噪声？

Jitter 相当于采样/actuation 时间的小随机延迟，某频率上的相位误差约为 $\omega\delta t$。高频或高 crossover 系统因此对时间抖动特别敏感，可在 robustness test 中注入 timing distribution。

### 6. 反例与失效条件

- **模型层失效**：如果出现未建模柔性模态、显著时延、RHP 零点、强耦合或工作点迁移，原题中的低阶/线性结论可能只在局部成立。
- **实现层失效**：sampling、quantization、filter、scheduler、actuator saturation/rate limit 会改变实际闭环，不应被当作“软件细节”。
- **评价层失效**：只看一个 step response 或单一 PM/GM 容易漏掉噪声、控制努力、内部状态和 worst-case parameter spread。
- **验证原则**：每个重要结论至少对应一个可证伪预测；例如“若根因是 delay margin 不足，则降低 crossover 或减少 latency 后振荡应系统性减弱”。
