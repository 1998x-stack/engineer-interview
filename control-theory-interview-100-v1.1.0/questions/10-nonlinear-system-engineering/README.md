## 章节学习建议

非线性控制题最重要的是说明**局部结论和全局结论的边界**。Jacobian 线性化给局部模型，Lyapunov 可以直接证明更大区域的稳定性，feedback linearization/backstepping/sliding mode 则利用结构主动设计非线性反馈。

系统级工程题则考证据链。优秀调试不是“猜一个参数再试”，而是从日志、频谱、残差、饱和统计和时序数据提出可证伪假设，再通过 A/B 实验把根因固化成 regression test。
