# 面试评分标准

## 单题 5 分制

| 分数 | 表现 |
|---|---|
| 1 | 只会 API 或概念名词，存在明显错误。 |
| 2 | 能给基本定义，但缺少机制和边界。 |
| 3 | 机制正确，能给一个工程例子。 |
| 4 | 能讨论权衡、失败模式、指标和规模。 |
| 5 | 能从约束推导设计，并主动提出验证、降级、治理和成本。 |

## 系统设计特别看什么

- 先估容量，而不是先画组件。
- 区分数据平面、状态平面、控制平面。
- 明确交付语义：at-most/at-least/exactly once。
- 明确 SLO、背压和失败恢复。
- 将数据质量与访问策略作为一等公民。
