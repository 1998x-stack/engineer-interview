# Responsible Crawling / 负责任的数据采集

本仓库将爬虫工程视为网络与数据工程问题，而不是“绕过网站限制”的对抗技巧。

## 基本原则

- 遵守适用的法律、合同、站点政策和 Robots Exclusion Protocol。
- 明确身份与用途；能使用正式 API/数据导出时优先使用正式渠道。
- 采用 per-host 访问预算、退避和 `Retry-After`，避免压垮站点。
- 遇到登录、验证码、挑战或明确访问控制时，将其视为权限/策略边界；不要自动化规避。
- 最小化收集，建立敏感数据治理、保留期限与删除机制。
- 保留来源和采集时间，支持纠错、删除和审计。

## Robots 与授权

RFC 9309 明确：Robots Exclusion Protocol 不是访问授权系统。工程上应分别管理 robots、业务授权、许可和数据治理。
