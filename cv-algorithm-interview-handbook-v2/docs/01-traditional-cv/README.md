# 第 01 章 · 传统图像处理与视觉基础

> 把图像看成信号：卷积、频域、边缘、颜色、尺度与几何。

## 本章怎么学

这一章的高级判断重点是：先把图像当作离散信号，再讨论采样、频率、几何与不变性。很多“深度学习问题”最终仍会回到这些基础假设，例如 resize 的采样误差、边缘保真、尺度空间与局部特征。

## V2 章节学习指南

### 章节定位

**传统图像处理与视觉基础** 覆盖：信号、采样、滤波、边缘、颜色、尺度与局部描述子。本章不以“记住模型名”为目标，而要求建立可以迁移到新论文、新业务和新硬件的分析框架。

### 学完后应能做到

- 能从空间域与频域双重解释滤波/采样
- 能区分不变性、等变性与工程近似
- 能把经典算子与现代网络的 inductive bias 建立联系

### 推荐刷题顺序

1. **第一遍：定义与公式**——每题只看标题，30 秒口述核心定义。
2. **第二遍：机制与反例**——必须回答“为什么有效”和“何时失效”。
3. **第三遍：工程迁移**——为每题绑定一个自己的项目 failure case 或最小实验。
4. **第四遍：连题追问**——随机从本章一题跳到相邻题，训练知识图而不是孤立记忆。
