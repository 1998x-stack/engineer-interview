## 30 秒回答

HOG 用局部梯度方向统计描述轮廓，再通过 block normalization 增强光照/对比度鲁棒性。

如果只能再补一句：**HOG = 局部方向直方图 + block 归一化。**

## 高频追问与参考答案

### 追问 1：为什么要 block normalization？

HOG 的 cell histogram 会受局部对比度影响；把相邻 cells 组成 block 后归一化，可以显著减弱光照和局部增益变化。

## V2 专业深化

> 这一节是在 PDF/原题解基础上的**专业扩展**：用于把“会答”提升到“能推导、能诊断、能做工程决策”。其中的扩展内容属于通用计算机视觉与工程知识，不用于声称某家公司曾逐字问过这些内容。

### 1. 更精确的技术表述

- HOG 通过局部梯度方向直方图描述轮廓，而 block normalization 抵消局部光照/对比度变化，是其鲁棒性的关键。
- cell 决定局部空间粒度，block 决定归一化上下文；bin 数过小丢方向信息，过大则更稀疏且对噪声敏感。
- HOG+SVM 的历史意义在于把“局部形状描述 + 判别分类”系统化；现代 CNN 则把 filter 和组合层级端到端学习。

### 2. 回答时必须显式声明的前提

- 先声明图像是离散采样信号还是连续模型；空间域/频域结论的适用条件不同。
- 区分线性/非线性算子、局部/全局处理，以及“数学性质”与“离散实现细节”。
- 任何增强/滤波都要讨论保真与去噪的 trade-off，尤其是边缘、纹理和小目标。

面试中尤其建议先把输入/输出、坐标或 tensor shape、训练/推理阶段以及评价口径说清楚。很多看似“知识点错误”的争论，本质是双方默认的实现约定不同。
