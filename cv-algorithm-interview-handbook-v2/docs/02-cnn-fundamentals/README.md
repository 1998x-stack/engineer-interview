## V2 章节学习指南

### 章节定位

**CNN 与深度学习基本功** 覆盖：卷积计算、感受野、梯度、初始化、归一化、残差、轻量化与优化器。本章不以“记住模型名”为目标，而要求建立可以迁移到新论文、新业务和新硬件的分析框架。

### 学完后应能做到

- 能现场计算参数/FLOPs/感受野
- 能解释深网训练稳定性的机制而非背结论
- 能从真实硬件角度评价轻量化

### 推荐刷题顺序

1. **第一遍：定义与公式**——每题只看标题，30 秒口述核心定义。
2. **第二遍：机制与反例**——必须回答“为什么有效”和“何时失效”。
3. **第三遍：工程迁移**——为每题绑定一个自己的项目 failure case 或最小实验。
4. **第四遍：连题追问**——随机从本章一题跳到相邻题，训练知识图而不是孤立记忆。
