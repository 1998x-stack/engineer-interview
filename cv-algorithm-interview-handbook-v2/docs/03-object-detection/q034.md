## 30 秒回答

小误差区二次、梯度连续；大误差区线性，兼顾精修与 outlier robustness。

## 关键公式 / 数学口径

Smooth L1（以常见 $\beta=1$ 为例）：

$$
\mathrm{smooth}_{L1}(x)=
\begin{cases}
\frac{1}{2}x^2,& |x|<1\\
|x|-\frac{1}{2},& \text{otherwise}
\end{cases}
$$

## 高频追问与参考答案

### 追问 1：Smooth L1 的 β 控制什么？

β 决定二次区间宽度：误差小于 β 时使用平滑二次项，大误差使用线性项；β 越小越接近 L1。

**回答加分点：** 最后补一句它会如何改变指标、训练稳定性或部署成本；若答案依赖实现约定，先声明约定。

> 这一节是在 PDF/原题解基础上的**专业扩展**：用于把“会答”提升到“能推导、能诊断、能做工程决策”。其中的扩展内容属于通用计算机视觉与工程知识，不用于声称某家公司曾逐字问过这些内容。

### 1. 更精确的技术表述

- Smooth L1 在小误差区为二次项、梯度连续；大误差区转为线性，减少 outlier 对回归的过大梯度影响。
- 它曾与 R-CNN 系列的参数化 bbox offset 非常匹配，但现代检测大量转向 IoU-family loss，因为后者更直接优化几何重叠。
- 选择回归 loss 时要结合 target normalization、box scale、正样本质量与评价指标，而不是脱离训练表示单独比较。

### 2. 回答时必须显式声明的前提

- 检测问题统一沿“表示→匹配/assignment→分类/回归→后处理→评测”定位。
- 始终区分训练正负样本匹配、推理 threshold/NMS、评测 IoU matching，这三者语义不同。
- 至少报告一个尺寸/遮挡/类别切片，避免总体 mAP 掩盖真实 failure mode。

面试中尤其建议先把输入/输出、坐标或 tensor shape、训练/推理阶段以及评价口径说清楚。很多看似“知识点错误”的争论，本质是双方默认的实现约定不同。
