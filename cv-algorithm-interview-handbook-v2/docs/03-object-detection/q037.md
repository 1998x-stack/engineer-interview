## 关键公式 / 数学口径

Focal Loss：

$$
FL(p_t)=-\alpha_t(1-p_t)^\gamma\log p_t
$$

当 $p_t\to1$ 时，易样本权重迅速衰减。

## 高频追问与参考答案

### 追问 1：γ=0 时退化为什么？

Focal Loss 的调制因子 $(1-p_t)^\gamma$ 在 γ=0 时恒为 1，因此退化为带 α 权重的交叉熵。

**回答加分点：** 最后补一句它会如何改变指标、训练稳定性或部署成本；若答案依赖实现约定，先声明约定。

### 追问 2：Focal Loss 与 class weight 的关系？

class weight 主要按类别整体重标权；Focal Loss 还按样本难度动态衰减 easy example。两者可组合，但要防止过度放大少数类。

### 1. 更精确的技术表述

- Focal Loss 在 CE 上乘 $(1-p_t)^\gamma$，使高置信 easy samples 权重快速衰减，把梯度预算集中到 hard examples。
- $\alpha$ 主要平衡类别先验，$\gamma$ 控制 focusing 强度；二者作用不同，不能只把 focal loss 理解为 class weight。
- 若标签噪声多，过度聚焦 hard samples 可能放大错误标注，应结合 sample quality 或 label smoothing/quality focal variants。

### 2. 回答时必须显式声明的前提

- 检测问题统一沿“表示→匹配/assignment→分类/回归→后处理→评测”定位。
- 始终区分训练正负样本匹配、推理 threshold/NMS、评测 IoU matching，这三者语义不同。
- 至少报告一个尺寸/遮挡/类别切片，避免总体 mAP 掩盖真实 failure mode。

面试中尤其建议先把输入/输出、坐标或 tensor shape、训练/推理阶段以及评价口径说清楚。很多看似“知识点错误”的争论，本质是双方默认的实现约定不同。

- **Control**：保留原 baseline 的训练预算、数据版本、输入尺寸和评测脚本，只改变与本题直接相关的一项。
