# 第 04 章 · 图像分割

## 本章怎么学

分割属于 dense prediction。除总体指标外，要特别关注前景稀疏、边界、拓扑、分辨率与标注噪声。工业与医学任务中，业务损失通常集中在很小的像素子集上。

## V2 章节学习指南

### 章节定位

**图像分割** 覆盖：区域、边界、上下文、细长结构、实例与全景分割。本章不以“记住模型名”为目标，而要求建立可以迁移到新论文、新业务和新硬件的分析框架。

### 学完后应能做到

- 能解释 CE/Dice/IoU 的不同优化目标
- 能针对边界与细目标设计指标和 loss
- 能在高分辨率与显存之间做工程权衡

### 推荐刷题顺序

1. **第一遍：定义与公式**——每题只看标题，30 秒口述核心定义。
2. **第二遍：机制与反例**——必须回答“为什么有效”和“何时失效”。
3. **第三遍：工程迁移**——为每题绑定一个自己的项目 failure case 或最小实验。
4. **第四遍：连题追问**——随机从本章一题跳到相邻题，训练知识图而不是孤立记忆。
