# 第 06 章 · ViT、自监督、CLIP 与 SAM

> 从 CNN inductive bias 走向视觉基础模型和 promptable perception。

## 本章怎么学

视觉基础模型题的重点不是背架构，而是比较 inductive bias、tokenization、attention 复杂度、预训练目标和开放词汇/提示式接口。还要知道 foundation model 不等于任何场景都优于专用模型。

## V2 章节学习指南

### 章节定位

**ViT、自监督、CLIP 与 SAM** 覆盖：tokenization、attention、预训练、开放词汇与 promptable perception。本章不以“记住模型名”为目标，而要求建立可以迁移到新论文、新业务和新硬件的分析框架。

### 学完后应能做到

- 能计算视觉 token/attention 复杂度
- 能比较 CNN 与 ViT 的 inductive bias
- 能解释 CLIP/SAM 的训练目标如何带来 zero-shot 接口

### 推荐刷题顺序

1. **第一遍：定义与公式**——每题只看标题，30 秒口述核心定义。

3. **第三遍：工程迁移**——为每题绑定一个自己的项目 failure case 或最小实验。
4. **第四遍：连题追问**——随机从本章一题跳到相邻题，训练知识图而不是孤立记忆。
