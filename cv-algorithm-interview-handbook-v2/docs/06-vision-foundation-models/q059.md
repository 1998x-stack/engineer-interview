## 关键公式 / 数学口径

若图像为 $H\times W$，patch 为 $P\times P$：

$$
N=\frac{HW}{P^2}
$$

每个 patch 展开后经线性映射得到 token embedding。

## 深入解析：从原理到工程

视觉基础模型题的重点不是背架构，而是比较 inductive bias、tokenization、attention 复杂度、预训练目标和开放词汇/提示式接口。还要知道 foundation model 不等于任何场景都优于专用模型。

## 代码 / 伪代码

```python
# PyTorch 中 patch embedding 可以直接用 stride=P 的卷积表达
patch_embed = torch.nn.Conv2d(
    in_channels=3, out_channels=embed_dim,
    kernel_size=patch_size, stride=patch_size
)
# [B, D, H/P, W/P] -> [B, N, D]
tokens = patch_embed(x).flatten(2).transpose(1, 2)
```

## V2 专业深化

> 这一节是在 PDF/原题解基础上的**专业扩展**：用于把“会答”提升到“能推导、能诊断、能做工程决策”。其中的扩展内容属于通用计算机视觉与工程知识，不用于声称某家公司曾逐字问过这些内容。

### 1. 更精确的技术表述

- ViT 将 $P×P×C$ patch 展平并线性映射到 $D$ 维 token；非重叠 patch embedding 可等价实现为 `Conv2d(kernel=P,stride=P)`。
- 序列长度 $N=HW/P^2$；patch 更小可保留更多空间细节，但 attention 的 $N^2$ 成本和激活显存快速增加。
- 绝对位置编码在新分辨率下常需二维插值；分类可用 CLS token 或 global pooling，dense task 通常保留空间 token。

### 2. 回答时必须显式声明的前提

- 视觉基础模型问题从 tokenization、位置/局部先验、attention interaction、预训练目标与迁移接口五层回答。
- 所有 scaling 结论都要带 token 数、分辨率、训练数据与计算预算，不做脱离配置的比较。
- zero-shot/open-vocabulary 是能力边界扩大，不代表专业闭集任务必然更优。
