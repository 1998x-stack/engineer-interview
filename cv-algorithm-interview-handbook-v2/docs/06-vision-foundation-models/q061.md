## 关键公式 / 数学口径

标准 self-attention 的主要矩阵乘法包含 $QK^T\in\mathbb{R}^{N\times N}$，因此对 token 数 $N$ 的时间/显存复杂度具有 $O(N^2)$ 项。

## 深入解析：从原理到工程

视觉基础模型题的重点不是背架构，而是比较 inductive bias、tokenization、attention 复杂度、预训练目标和开放词汇/提示式接口。还要知道 foundation model 不等于任何场景都优于专用模型。

对 **Q061** 尤其要注意：VLM serving 的瓶颈经常是 token 数、activation/KV 与 data movement。 这不是附加知识，而是把理论答案变成“可上线判断”的关键一步。

## 高频追问与参考答案

### 追问 1：FlashAttention 为什么快？

它不改变 attention 的数学结果，核心是按块计算并减少 HBM 与 SRAM 之间的中间矩阵读写，利用 online softmax 避免显式保存完整 N×N attention。

## V2 专业深化

> 这一节是在 PDF/原题解基础上的**专业扩展**：用于把“会答”提升到“能推导、能诊断、能做工程决策”。其中的扩展内容属于通用计算机视觉与工程知识，不用于声称某家公司曾逐字问过这些内容。

### 1. 更精确的技术表述

- 标准 self-attention 的 score matrix 为 $N×N$，时间和注意力激活内存都含 $O(N^2)$ 项；视觉中 $N=HW/P^2$，分辨率翻倍会造成约 4× token、16× attention pair。
- 线性投影 Q/K/V 也有 $O(ND^2)$ 成本，在小 N/大 D 时可能占主导；不能只背 $O(N^2D)$ 一项。
- window/sparse/deformable/linear attention 从不同角度减少 pairwise interaction，但会改变全局信息传播路径。

### 2. 回答时必须显式声明的前提

- 视觉基础模型问题从 tokenization、位置/局部先验、attention interaction、预训练目标与迁移接口五层回答。
- 所有 scaling 结论都要带 token 数、分辨率、训练数据与计算预算，不做脱离配置的比较。
- zero-shot/open-vocabulary 是能力边界扩大，不代表专业闭集任务必然更优。

面试中尤其建议先把输入/输出、坐标或 tensor shape、训练/推理阶段以及评价口径说清楚。很多看似“知识点错误”的争论，本质是双方默认的实现约定不同。

### 5. 建议做的最小消融

- **Control**：保留原 baseline 的训练预算、数据版本、输入尺寸和评测脚本，只改变与本题直接相关的一项。
- **Slice**：至少增加一个与本题机制直接相关的子集指标；例如尺寸、遮挡、边界、长尾、噪声或设备域。
- **Cost**：同时记录参数量/FLOPs 之外的真实成本：显存、wall-clock、目标硬件 latency、P95/P99 或后处理开销。
- **Regression**：列出方案新增的 FP/FN 或退化场景，避免只展示改善样本。
- **Repeatability**：若提升幅度较小，使用多随机种子或 bootstrap 置信区间，判断收益是否超出自然波动。
