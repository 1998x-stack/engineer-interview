## V2 章节学习指南

### 章节定位

**视频、3D 与多模态** 覆盖：时间、光流、相机几何、深度、BEV、跨模态融合与 VLM。本章不以“记住模型名”为目标，而要求建立可以迁移到新论文、新业务和新硬件的分析框架。

### 学完后应能做到

- 能明确坐标系与时间轴
- 能解释几何歧义和标定误差传播
- 能设计模态缺失/异步的鲁棒性测试

### 推荐刷题顺序

1. **第一遍：定义与公式**——每题只看标题，30 秒口述核心定义。
2. **第二遍：机制与反例**——必须回答“为什么有效”和“何时失效”。
3. **第三遍：工程迁移**——为每题绑定一个自己的项目 failure case 或最小实验。
4. **第四遍：连题追问**——随机从本章一题跳到相邻题，训练知识图而不是孤立记忆。
