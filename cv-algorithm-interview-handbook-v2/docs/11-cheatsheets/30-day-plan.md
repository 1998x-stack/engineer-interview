# 30 天复习路线

## 总原则

每天包含四块：**新题 60–90 min + 闭卷口述 30 min + 手撕/公式 20 min + 项目复盘 20 min**。不要把时间全部花在阅读。

| 天数 | 内容 | 输出 |
|---|---|---|
| 1–3 | Q001–Q010 传统 CV | 画出滤波/采样知识图，闭卷解释 aliasing |
| 4–8 | Q011–Q025 CNN | 手算 FLOPs/感受野；口述 BN/ResNet/AdamW |
| 9–13 | Q026–Q040 检测 | 手写 IoU/NMS；完成一次 Recall failure taxonomy |
| 14–16 | Q041–Q050 分割 | 比较 CE/Dice/IoU；准备边界/细目标案例 |
| 17–18 | Q051–Q058 OCR | 画完整 OCR pipeline；讲 CTC alignment |
| 19–21 | Q059–Q067 ViT/CLIP/SAM | 算 token/attention；讲 zero-shot 与 prompt |
| 22–23 | Q068–Q075 Diffusion | 写 DDPM closed form；讲 CFG/latent/eval |
| 24–25 | Q076–Q082 Video/3D/VLM | 画相机坐标变换与融合架构 |
| 26–27 | Q083–Q089 Data/Eval | 设计多 seed + slice + CI 的 ablation |
| 28 | Q090–Q098 部署/手撕 | IoU/NMS/BN 各闭卷写 2 次 |
| 29 | Q099–Q100 项目题 | 完成一个 5 分钟项目因果链 |
| 30 | 全真模拟 | 2 场 45 分钟 mock + 错题回炉 |

## 每日闭环

```text
读题 → 合上答案口述 → 对照修正 → 写一句反例 → 绑定项目 → 第二天随机复述
```

## 最后 48 小时

只看：Top30、公式、三段手撕、项目拷问，不再大面积引入新材料。
