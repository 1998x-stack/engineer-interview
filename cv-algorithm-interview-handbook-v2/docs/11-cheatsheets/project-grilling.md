# 项目拷问 30 题

下面的问题应针对**自己最强的一个视觉项目**逐一写出具体数字。

## 数据与任务

1. 业务最怕 FN 还是 FP？成本分别是什么？
2. 数据有多少，按什么维度拆 train/val/test？
3. 如何避免同视频/同物体/近重复跨 split 泄漏？
4. 最大的类别/尺寸/设备长尾是什么？
5. 标注规范是谁定义的，inter-annotator disagreement 如何？
6. 线上数据与训练数据最明显的 3 个 domain gap？

## Baseline 与失败分析

7. 为什么选这个 baseline，而不是更大/更新模型？
8. baseline 的总体指标与 3 个关键 slice 是多少？
9. 最大的 3 类 FP/FN 分别占多少？
10. 你如何证明某 failure 是模型问题而不是数据/阈值问题？
11. confidence 与 NMS/后处理阈值是怎么定的？
12. 有没有对错误做 taxonomy 和 Pareto 排序？

## 改进与因果证据

13. 每个改动对应哪个明确 failure？
14. 为什么从机制上预期它有效？
15. 有参数量/FLOPs 匹配 control 吗？
16. 多 seed 的均值/方差是多少？
17. 有没有只对某些 slice 有效、总体看不出来的改进？
18. 新方案新增了哪些 FP/FN？
19. 涨点是不是因为训练更久/数据更多/调参更多？
20. 如果移除这个模块，性能会回退多少？

## 工程与部署

21. 输入尺寸、batch、precision、目标硬件是什么？
22. P50/P95/P99 latency 分别多少？
23. 预处理/后处理占端到端多少时间？
24. PyTorch→ONNX→TensorRT 如何做 numerical parity？
25. FLOPs 降了为什么可能不加速？你的模型属于哪种瓶颈？
26. OOM/高并发时系统如何降级？

## 线上闭环

27. 如何监控 data drift 与 score drift？
28. 线上错误如何回流、去重、标注和进入下一版本？
29. 模型版本/数据版本/阈值/规则能否完整回滚？
30. 如果再做一遍，你会优先删掉哪项工作、增加哪项实验？为什么？
