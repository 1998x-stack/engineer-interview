# Contributing

欢迎通过 issue / PR 修正公式、补充工程边界或更新软件版本信息。

## 修改一道题

1. 保留题号与 front matter 的 `id`；
2. 理论性结论优先引用原始论文；工程 API 优先引用官方文档；
3. 新增经验结论时写清适用条件；
4. 运行 `python scripts/check_repo.py`；
5. PR 描述里说明“为什么改”和“如何验证”。

## 不接受

- 把未经验证的面经答案当事实；
- 声称题目来自企业官方/内部题库，除非有公开官方来源；
- 只加模型名词但不解释机制和边界；
- 删除失败场景、trade-off 或验证方法以换取“更短”。
