## 维护原则

- 面经只作为‘是否被问过/问法如何’的证据，不作为理论正确性的最终依据。
- 软件 API、FSDP/vLLM/PEFT 等工程细节以当前官方文档为准。
- 任何题目修订应说明：是理论纠错、工程版本变化，还是面试频度变化。
