## GitHub v2 深度阅读要求

本模块的每一道题都不再以“背定义”为完成标准。建议至少完成四步：

1. **30 秒**：说清本质与边界；
2. **5 分钟**：能写关键公式/结构图，并解释 why；
3. **工程层**：能列失败模式、指标和最小验证实验；
4. **项目层**：能把答案映射到自己的机器人/数据/控制系统，并给出 baseline 与 ablation。

> 判断是否真正掌握：面试官把题目中的机器人、传感器、控制频率或数据规模换掉，你仍能重新推导，而不是只能复述原答案。
