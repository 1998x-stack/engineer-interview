# “真题”与来源标注规范

本仓库区分三类内容：

1. **公开可核验面经题**：公开来源能确认出现过相同或高度一致的问题；
2. **高频真题型**：基于多个岗位 JD、公开面经和主流技术栈还原的高概率题型；
3. **Senior / Research 系统题**：用于二三面、项目拷打或研究岗，不声称来自某家公司原题。

## 原则

- 没有公开证据时，不写“某公司原题”。
- 公司名、日期、岗位方向等信息如果后续补充，应附公开可访问来源。
- 论文/官方文档主要用于核验技术结论，不等于“证明这道题在某公司被问过”。
- PDF Core 与 Repository Expansion 分开，避免后续资料更新改变原 PDF 的历史内容。
