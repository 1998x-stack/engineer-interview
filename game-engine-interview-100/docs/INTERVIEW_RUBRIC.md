# 面试评分标准

## 单题 0-4 评分

| 分数 | 观察 |
|---:|---|
| 0 | 定义错误或无法回答。 |
| 1 | 能说术语/结论，但机制模糊。 |
| 2 | 机制正确，能给一个例子。 |
| 3 | 能谈 trade-off、边界条件、工程实现。 |
| 4 | 能给成本模型、profiling 证据、替代方案，并主动处理追问。 |

## 项目题 8 个固定追问

1. 性能/质量目标是什么？如何量化？
2. 最初方案为何不够？
3. 数据结构为什么这样选？替代方案？
4. CPU/GPU memory layout？
5. 同步与生命周期风险？
6. 最难 bug 如何复现与定位？
7. 规模扩大 10 倍，第一瓶颈？
8. 换平台/API，哪些假设失效？
