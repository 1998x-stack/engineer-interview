# 学习路线：把 100 道题练成面试能力

## 目标不是“看完”，而是形成四层输出

1. **Recall**：30 秒给出正确结论。
2. **Explain**：2 分钟解释机制与 trade-off。
3. **Implement**：能写最小实现/推导/结构图。
4. **Diagnose**：遇到真实性能或 bug，知道用什么工具证明。

## 4 周建议

### Week 1 - C++ / Memory / Concurrency
Q001-Q030。每天 7-8 题，至少做 3 个 microbenchmark：vector/list、false sharing、SPSC queue。

### Week 2 - Algorithms / 3D Math / Raster
Q031-Q060。实现 A*、ray-triangle、perspective interpolation；做一次 RenderDoc/Nsight frame capture。

### Week 3 - PBR / Engine Architecture
Q061-Q080。把 Rendering Equation、Cook-Torrance、BVH、Render Graph、RHI 串成统一知识图。

### Week 4 - Simulation / GPU API / System Design
Q081-Q100。重点做 Q091-Q100；用 Q100 做 45 分钟系统设计 mock interview。
