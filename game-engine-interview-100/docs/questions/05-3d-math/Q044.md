## 2. 30 秒回答（PDF 核心内容）

单位四元数用 4 个数表示 3D 旋转，组合是乘法，避免 Euler angle 的参数奇异；同时适合球面插值。

---

## 3. PDF 深入拆解（Source-derived）

四元数并不是“完全没有奇异性”这类口号，它的核心优势是用单位 3-sphere 上的点表示 SO(3) 的双覆盖，避免 Euler 三角参数化在某些姿态失去自由度。q 与 -q 表示同一旋转，因此插值前常需要检查 dot<0 时翻转一个 quaternion，选择最短弧。累计旋转后也要适当归一化抑制数值漂移。

### PDF 核心抓手
- 单位四元数
- q 与 -q 同一旋转
- 乘法表示旋转复合
- 插值前处理 shortest path

### PDF 工程 Gotcha

说“四元数没有万向节锁”却无法解释 Euler 为什么会锁。

### PDF 面试官在听什么

是否理解旋转空间，而非只会调用库函数。

## 4. 专业扩展（Repository v2）

这一节不再重复 PDF 的“定义答案”，而是把问题推进到 **可实现、可测量、可讨论 trade-off** 的层级。面试时不要求把下面所有内容一次讲完；更好的策略是先给结论，再根据面试官追问选择其中 2–3 个层次深入。

### 4.1 先修知识与概念边界

- Euler angle
- 旋转矩阵
- 复数/四元数基础
- 单位球

### 4.2 核心心智模型

Quaternion 的优势不是“4个数比9个数省”，而是提供无奇异的旋转组合与平滑插值表示。单位四元数位于 S³，并且 q 与 -q 表示同一 3D 旋转。

### 4.3 底层机制：逐层拆开

- axis-angle `(axis,θ)` 映射为 `q=(cos θ/2, axis*sin θ/2)`。
- 组合旋转对应 quaternion multiplication，非交换；顺序与坐标 convention 必须明确。
- 向量旋转可表示 `q v q^{-1}`，工程实现通常展开成更高效公式。
- 数值积累会让长度偏离1，连续组合后需要适度 normalize。

### 4.4 必须守住的不变量 / 正确性条件

- 表示旋转的 quaternion 应接近 unit length。
- q 与 -q 等价，因此插值前通常若 dot<0 翻转一个端点取短弧。

这些不变量比“记住某个 API”更重要：平台、实现或引擎版本可以变化，但只要不变量没变，你就能重新推导正确方案。

### 4.5 Trade-off：什么时候该用，什么时候不该用

- Euler 适合 UI/authoring，但运行时插值和组合容易遇 gimbal lock/不连续。
- Matrix 适合批量变换点；Quaternion 适合存旋转/插值，常相互转换。

### 4.6 在真实游戏引擎中的落点

- Animation keyframe rotation。
- Camera orientation/controller。
- Network rotation compression 可利用 unit quaternion 冗余压缩。

### 4.7 最小实现 / 数学骨架

```math
q=(\cos\frac{\theta}{2},\ \hat a\sin\frac{\theta}{2}),\qquad q^{-1}=q^* \text{ for unit }q
```

> **面试建议**：代码或公式不是为了炫技。写完后要解释：输入是什么、输出是什么、最贵的步骤在哪里、哪个条件一旦破坏就会出错。

### 4.8 Profiling / Validation：如何证明你的判断

- 连续乘上千次小旋转，观察 norm drift；测试 q/-q 插值是否出现长路径翻转。

### 4.9 常见错误答案与为什么错

- “Quaternion 完全不会 gimbal lock 所以任何情况下都比 Euler 好。”——authoring、约束、可读性仍可能用 Euler。
- “四元数4个分量都独立。”——单位约束使自由度仍是3。

### 4.10 Senior 级追问与参考思路

1. **为什么 q 和 -q 同旋转？**  
   单位四元数对 SO(3) 是 double cover；两个 antipodal points 映射到同一个 3D 旋转。
2. **如何压缩 quaternion？**  
   利用单位约束可丢掉绝对值最大的分量并存其余3个+索引/符号，再重建。

### 4.11 推荐实战

> 实现 axis-angle↔quaternion、multiply、normalize、vector rotate，并做与 rotation matrix 的随机一致性测试。

完成实战时建议保留 **baseline、指标、实验变量、结果、结论** 五项记录。真正能在面试中形成 Senior signal 的不是“我写过”，而是“我能解释为什么这个实现更快/更稳，以及证据是什么”。

## 5. 如何验证，而不是“凭感觉优化”

- 检查浮点 epsilon、归一化与数值稳定性

### 推荐实战
