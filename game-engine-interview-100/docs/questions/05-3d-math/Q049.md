## 2. 30 秒回答（PDF 核心内容）

三角形内任意点可写成 P=A+B+C，且 ++=1；三者可用于点内判定和顶点属性插值。

---

## 3. PDF 深入拆解（Source-derived）

Rasterization 中屏幕位置可由 edge function 得到 barycentric weights，再插值颜色、法线、UV 等。对纹理坐标等来自 3D 的属性，屏幕空间权重不能直接线性插，需要透视矫正。重心坐标也可用于 ray-triangle 命中后插值 vertex attributes。

### PDF 核心抓手
- ++=1
- 三者非负表示点在三角形内
- 可插值任意顶点属性
- 屏幕空间属性需区分是否 perspective-correct

### PDF 工程 Gotcha

认为所有 attribute 都能直接用屏幕重心坐标线性插。

### PDF 面试官在听什么

是否能把几何坐标与 raster attribute interpolation 对上。

## 4. 专业扩展（Repository v2）

这一节不再重复 PDF 的“定义答案”，而是把问题推进到 **可实现、可测量、可讨论 trade-off** 的层级。面试时不要求把下面所有内容一次讲完；更好的策略是先给结论，再根据面试官追问选择其中 2–3 个层次深入。

### 4.1 先修知识与概念边界

- triangle affine combination
- 面积/叉积
- attribute interpolation
- inside test

### 4.2 核心心智模型

重心坐标把三角形内任意点表示成三个顶点的仿射组合。它既是“点在哪”的坐标，也是 rasterization 中属性插值权重；三个权重和为1，内部点通常都非负。

### 4.3 底层机制：逐层拆开

- `P=αA+βB+γC`, `α+β+γ=1`。
- 可通过子三角形面积比、线性方程或 edge functions 求权重。
- 若 α/β/γ ≥0（含边界），P 在三角形内部；负值表示在对应顶点对边外侧。
- 屏幕空间 barycentric 可插值 depth/attribute，但透视属性需进一步做 1/w 校正（Q050）。

### 4.4 必须守住的不变量 / 正确性条件

- 重心坐标对 affine transform 保持一致。
- 退化三角形面积≈0 时坐标不稳定/不可定义。

这些不变量比“记住某个 API”更重要：平台、实现或引擎版本可以变化，但只要不变量没变，你就能重新推导正确方案。

### 4.5 Trade-off：什么时候该用，什么时候不该用

- 面积法直观，edge function 更适合 raster incremental/SIMD。

### 4.6 在真实游戏引擎中的落点

- Rasterizer attribute interpolation。
- Mesh surface sampling。
- Ray hit 返回 barycentric 后插值 UV/normal/tangent。

### 4.7 最小实现 / 数学骨架

```math
P=\alpha A+\beta B+\gamma C,\qquad \alpha+\beta+\gamma=1
```

> **面试建议**：代码或公式不是为了炫技。写完后要解释：输入是什么、输出是什么、最贵的步骤在哪里、哪个条件一旦破坏就会出错。

### 4.8 Profiling / Validation：如何证明你的判断

- 测试顶点/边界/中心/退化 triangle，验证权重和=1。

### 4.9 常见错误答案与为什么错

- “重心坐标必须都在0到1之间。”——只有点在三角形内部时；外部仍有合法 affine coordinates。
- “直接用屏幕 barycentric 插值 texture UV 就对。”——需要 perspective correction。

### 4.10 Senior 级追问与参考思路

1. **如何均匀采样三角形？**  
   不能直接 α,β uniform；可用 sqrt 变换，如 `sqrt(r1)` 构造 barycentric，保证面积均匀。
2. **为什么 affine invariant？**  
   barycentric 是仿射组合，仿射变换可分配到各顶点，权重不变。

### 4.11 推荐实战

> 实现 barycentric 求解、inside test 和 triangle uniform sampling，用统计热图验证均匀性。

完成实战时建议保留 **baseline、指标、实验变量、结果、结论** 五项记录。真正能在面试中形成 Senior signal 的不是“我写过”，而是“我能解释为什么这个实现更快/更稳，以及证据是什么”。

## 5. 如何验证，而不是“凭感觉优化”

- 用已知几何构造单元测试：单位矩阵、极端角度、退化三角形
- 显式固定坐标系 convention 并在 debug draw 中可视化
- 检查浮点 epsilon、归一化与数值稳定性

### 推荐实战

> 用 Python/C++ 写数值单元测试，并做 debug draw 可视化几何结果。
