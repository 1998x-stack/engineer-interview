# Q063 · Metallic/Roughness PBR Workflow 是什么意思？

## 1. 这道题在考什么

这题属于 **PBR、阴影、GI 与 Ray Tracing**。面试官通常不是只听一个定义，而是在判断你能否把答案推进到：

1. **机制**：数据/状态究竟怎样流动；
2. **成本**：CPU、GPU、内存、同步或数值误差的成本在哪里；
3. **Trade-off**：什么场景适合，什么场景会失败；
4. **Engine Context**：在真实 renderer / core / asset / simulation 中怎么落地；
5. **Evidence**：如何通过 profiler、测试、frame capture 或汇编证明判断。

本章常见工程落点：material shading、shadow/GI、ray tracing / offline reference。

---

## 2. 30 秒回答（PDF 核心内容）

它用 BaseColor、Metallic、Roughness 等参数约束材质到可解释物理范围：dielectric F0 常约 0.04，metal 的 base color 主要进入 specular，diffuse 基本消失。

---

## 3. PDF 深入拆解（Source-derived）

这种 workflow 的价值是“标准化材质空间” ，让艺术资产在不同灯光环境下保持一致。Metallic 通常应接近 0 或 1，灰区主要用于混合边界；Roughness 改变 NDF，控制微表面方向分散度。 AO 常只影响间接环境项，不能随意乘到所有 direct lighting。

### PDF 核心抓手
- dielectric/metal 的光学差别
- roughness 控制微表面统计
- metal 无常规 diffuse
- workflow 让材质跨场景一致

### PDF 工程 Gotcha

把 AO 直接乘最终颜色、把 metalness 当任意连续“金属感”。

### PDF 面试官在听什么

是否理解 PBR 参数背后的物理约束。

## 4. 专业扩展（Repository v2）

这一节不再重复 PDF 的“定义答案”，而是把问题推进到 **可实现、可测量、可讨论 trade-off** 的层级。面试时不要求把下面所有内容一次讲完；更好的策略是先给结论，再根据面试官追问选择其中 2–3 个层次深入。

### 4.1 先修知识与概念边界

- dielectric vs conductor
- F0
- base color
- roughness

### 4.2 核心心智模型

Metallic/Roughness workflow 用少量艺术参数编码材质物理类别。Metallic 在0/1端点区分 dielectric/conductor；roughness 控制微表面分布；baseColor 对 dielectric 主要是 diffuse albedo，对 metal 主要进入 specular F0。

### 4.3 底层机制：逐层拆开

- Dielectric 的可见光 F0 常约0.02-0.08，很多引擎默认≈0.04；其 diffuse 存在。
- Conductor 几乎没有体散射 diffuse，反射带颜色，F0 来源于金属复折射率的近似/艺术 baseColor。
- Roughness 不改变总能量目标，而改变角分布；perceptual roughness 常平方映射到 GGX alpha。
- Metallic map 中间灰常用于材质混合/抗锯齿，而单一纯材质物理上更接近0或1。

### 4.4 必须守住的不变量 / 正确性条件

- metalness 不等于“越大越亮”。
- roughness 不等于 normal map 强度。

这些不变量比“记住某个 API”更重要：平台、实现或引擎版本可以变化，但只要不变量没变，你就能重新推导正确方案。

### 4.5 Trade-off：什么时候该用，什么时候不该用

- Metallic workflow 参数少、资产管线统一；Specular/Gloss workflow 对 dielectric F0 控制更直接但更难 author。

### 4.6 在真实游戏引擎中的落点

- GBuffer 打包 baseColor/normal/roughness/metalness。
- Texture channel packing：ORM/RMA 等减少采样和内存。
- Mip filtering 时 normal/roughness 需要考虑 specular aliasing。

### 4.7 最小实现 / 数学骨架

```text
Dielectric: F0≈0.04, diffuse≈baseColor
Metal     : F0≈baseColor, diffuse≈0
```

> **面试建议**：代码或公式不是为了炫技。写完后要解释：输入是什么、输出是什么、最贵的步骤在哪里、哪个条件一旦破坏就会出错。

### 4.8 Profiling / Validation：如何证明你的判断

- material validation view 显示异常 metalness/F0/roughness。
- 用 reference spheres 检查不同 HDR lighting 下材质是否保持合理。

### 4.9 常见错误答案与为什么错

- “Metallic=1 只是把 diffuse 关掉。”——还需要把 baseColor 解释为 specular F0。
- “Roughness=1 就没有 specular。”——仍有反射，只是分布非常宽。

### 4.10 Senior 级追问与参考思路

1. **为什么 roughness mip 过滤难？**  
   normal variance 与几何/normal map 高频会改变有效微表面粗糙度，简单平均可能导致 specular aliasing。
2. **金属边缘为何可能出现非物理灰 metalness？**  
   纹理过滤/材质混合在像素 footprint 内混合两种材质，是 coverage mixture，不代表真实半金属。

### 4.11 推荐实战

> 制作 PBR sphere grid，横轴 roughness、纵轴 metallic/F0，在 HDRI 和 point light 下验证。

完成实战时建议保留 **baseline、指标、实验变量、结果、结论** 五项记录。真正能在面试中形成 Senior signal 的不是“我写过”，而是“我能解释为什么这个实现更快/更稳，以及证据是什么”。

## 5. 如何验证，而不是“凭感觉优化”

- 用 reference/path tracer 或离线 ground truth 做视觉对比
- 同时观察 variance、bias、sample count 与 GPU cost
- 对阴影/BRDF 参数做极端值测试，避免只看“正常材质”

### 推荐实战

> 实现一个 CPU reference 或 shader demo，对照公式和可视化结果验证。
