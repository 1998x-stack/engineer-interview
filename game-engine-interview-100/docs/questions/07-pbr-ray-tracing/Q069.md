# Q069 · 什么是 Importance Sampling？

## 1. 这道题在考什么

这题属于 **PBR、阴影、GI 与 Ray Tracing**。面试官通常不是只听一个定义，而是在判断你能否把答案推进到：

1. **机制**：数据/状态究竟怎样流动；
2. **成本**：CPU、GPU、内存、同步或数值误差的成本在哪里；
3. **Trade-off**：什么场景适合，什么场景会失败；
4. **Engine Context**：在真实 renderer / core / asset / simulation 中怎么落地；
5. **Evidence**：如何通过 profiler、测试、frame capture 或汇编证明判断。

本章常见工程落点：material shading、shadow/GI、ray tracing / offline reference。

---

## 2. 30 秒回答（PDF 核心内容）

在积分贡献大的区域更高概率采样，并用 1/p(x) 校正权重；理想 proposal 与 |f(x)| 成比例，可显著降低 Monte Carlo 方差。

---

## 3. PDF 深入拆解（Source-derived）

渲染里常见 cosine-weighted hemisphere、BRDF sampling、light sampling。单一分布无法同时擅长所有情况：小而亮的光源适合 light sampling，强镜面材质适合 BRDF sampling，因此 Multiple Importance Sampling 用权重组合多个 proposal，降低“某一路径策略几乎采不到关键贡献”的风险。

### PDF 核心抓手
- 改变采样分布必须除以 PDF
- 重要性采样目标是降方差
- 不同 proposal 擅长不同光路
- MIS 是现代 path tracing 核心

### PDF 工程 Gotcha

只说“亮的地方多采样”，但没说明 PDF 补偿，否则估计会产生偏差。

### PDF 面试官在听什么

是否具备概率与渲染结合的能力。

## 4. 专业扩展（Repository v2）

这一节不再重复 PDF 的“定义答案”，而是把问题推进到 **可实现、可测量、可讨论 trade-off** 的层级。面试时不要求把下面所有内容一次讲完；更好的策略是先给结论，再根据面试官追问选择其中 2–3 个层次深入。

### 4.1 先修知识与概念边界

- Monte Carlo
- pdf
- BRDF sampling
- light sampling
- MIS

### 4.2 核心心智模型

Importance Sampling 的目标是让 sampling pdf 在 integrand 大的区域更高，从而让权重 `f/p` 更稳定、降低方差。理想 pdf 与 |f| 成比例，但实际只能组合 BRDF、light、cosine 等可采样近似。

### 4.3 底层机制：逐层拆开

- Lambertian integrand 含 cosine，因此 cosine-weighted hemisphere sampling 比 uniform hemisphere 方差低。
- Glossy surface 用 GGX VNDF/half-vector sampling 让样本集中在 specular lobe。
- 小面积光源用 direct light sampling，否则随机 bounce 命中光源概率很低。
- MIS 将多个 proposal（如 BSDF sampling 与 light sampling）组合，通过 balance/power heuristic 降低各自失败场景方差。

### 4.4 必须守住的不变量 / 正确性条件

- 任何采样都必须使用与生成分布一致的 pdf 计算权重。
- pdf 的测度必须一致：solid angle、area 之间转换需要 geometry Jacobian。

这些不变量比“记住某个 API”更重要：平台、实现或引擎版本可以变化，但只要不变量没变，你就能重新推导正确方案。

### 4.5 Trade-off：什么时候该用，什么时候不该用

- 复杂 importance sampler 计算 pdf/逆CDF更贵，但通常比盲目加 samples 划算。
- ReSTIR 等实时方法进一步重用候选，但引入时空相关和复杂权重。

### 4.6 在真实游戏引擎中的落点

- Path tracer direct lighting。
- Environment map luminance importance sampling。
- GGX specular sampling。

### 4.7 最小实现 / 数学骨架

```math
\hat I=\frac{f(X)}{p(X)},\qquad
p(x)\approx\frac{|f(x)|}{\int |f|}
```

> **面试建议**：代码或公式不是为了炫技。写完后要解释：输入是什么、输出是什么、最贵的步骤在哪里、哪个条件一旦破坏就会出错。

### 4.8 Profiling / Validation：如何证明你的判断

- 比较 uniform/cosine/BSDF/MIS 在相同 spp 的 variance。
- 检查 pdf normalization 与 sampled histogram。

### 4.9 常见错误答案与为什么错

- “Importance Sampling 会改变最终真实结果。”——正确权重下只改变方差。
- “pdf 越大权重越大。”——权重是 `f/p`，高概率区域单样本权重反而被除小。

### 4.10 Senior 级追问与参考思路

1. **Area-light pdf 如何转 solid-angle pdf？**  
   使用 `p_ω = p_A * r² / |n_light·(-ω)|` 等 Jacobian 关系。
2. **MIS 为什么能同时处理小灯和 glossy？**  
   light sampling 擅长命中灯，BSDF sampling 擅长高 BRDF 区；MIS 根据各自 pdf 权重组合。

### 4.11 推荐实战

> 实现 uniform/cosine hemisphere sampler并数值积分 Lambertian irradiance，比较方差；再加入 direct light MIS。

完成实战时建议保留 **baseline、指标、实验变量、结果、结论** 五项记录。真正能在面试中形成 Senior signal 的不是“我写过”，而是“我能解释为什么这个实现更快/更稳，以及证据是什么”。

## 5. 如何验证，而不是“凭感觉优化”

- 用 reference/path tracer 或离线 ground truth 做视觉对比
- 同时观察 variance、bias、sample count 与 GPU cost
- 对阴影/BRDF 参数做极端值测试，避免只看“正常材质”

### 推荐实战

> 实现一个 CPU reference 或 shader demo，对照公式和可视化结果验证。
