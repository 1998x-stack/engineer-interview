# Q082 · 为什么 Linear Blend Skinning 会出现 Candy Wrapper？

## 2. 30 秒回答（PDF 核心内容）

LBS 直接线性混合变换矩阵/变换后位置，旋转空间本身不是线性空间，尤其扭转时会造成截面收缩、体积丢失。

---

## 3. PDF 深入拆解（Source-derived）

两个相反旋转的矩阵线性加权后不再是纯旋转，会包含缩放/剪切。Dual Quaternion Skinning 用 dual quaternion 对刚体变换做更合理插值，可显著改善 twist，但对非均匀 scale 支持更复杂。 工业角色还会使用 corrective blendshape、pose-space deformation 修复特定关节。

### PDF 核心抓手
- 线性混合旋转会产生非刚性变换
- DQS 改善 twist/体积
- corrective shape 解决艺术特定形变

### PDF 工程 Gotcha

认为权重归一化就能解决 candy wrapper。

### PDF 面试官在听什么

是否能把数学缺陷与视觉结果联系起来。

## 4. 专业扩展（Repository v2）

这一节不再重复 PDF 的“定义答案”，而是把问题推进到 **可实现、可测量、可讨论 trade-off** 的层级。面试时不要求把下面所有内容一次讲完；更好的策略是先给结论，再根据面试官追问选择其中 2–3 个层次深入。

### 4.1 先修知识与概念边界

- Linear Blend Skinning
- rotation interpolation
- dual quaternion
- volume preservation

### 4.2 核心心智模型

Candy Wrapper 是 LBS 把多个刚性变换矩阵做线性加权导致的非刚性结果。两个相反旋转矩阵平均可能缩短/塌陷向量，尤其绕长轴 twist 时体积丢失。Dual Quaternion Skinning 更自然地 blend 刚性变换。

### 4.3 底层机制：逐层拆开

- LBS 计算 `Σ w_i M_i`，矩阵空间线性组合不保持正交性/刚性，因此会产生 shear/scale。
- 关节弯曲还会出现 elbow collapse；twist 最典型是圆柱截面被压扁。
- Dual quaternion 同时编码 rotation+translation，归一化加权后更接近 SE(3) 上的合理插值。
- DQS 对 non-uniform scale 支持不如矩阵直接，需要混合策略或 separate scale。

### 4.4 必须守住的不变量 / 正确性条件

- 问题不是权重没归一，而是线性空间不是刚体变换流形。

这些不变量比“记住某个 API”更重要：平台、实现或引擎版本可以变化，但只要不变量没变，你就能重新推导正确方案。

### 4.5 Trade-off：什么时候该用，什么时候不该用

- DQS 质量好但 shader/数据复杂；corrective blendshapes 可对特定角色艺术修复。
- 游戏常 LBS + twist bones + corrective shapes，成本/工具成熟度平衡。

### 4.6 在真实游戏引擎中的落点

- Character elbows/wrists twist。
- High-end hero character DQS/corrective deformation。
- Animation authoring 自动增加 twist joints。

### 4.7 最小实现 / 数学骨架

```text
LBS:      p' = Σ w_i (M_i p)
DQS: blend dual quaternions -> normalize -> transform p
```

> **面试建议**：代码或公式不是为了炫技。写完后要解释：输入是什么、输出是什么、最贵的步骤在哪里、哪个条件一旦破坏就会出错。

### 4.8 Profiling / Validation：如何证明你的判断

- 用180° forearm twist cylinder 对比截面积/volume error。
- 视觉回归关节极限姿态。

### 4.9 常见错误答案与为什么错

- “Candy Wrapper 是法线没归一导致。”——根因是位置的矩阵线性混合。
- “DQS 解决所有 skinning 问题。”——scale、muscle deformation、cloth 等仍需其他技术。

### 4.10 Senior 级追问与参考思路

1. **为什么增加 twist bones 有效？**  
   把大角度旋转分摊到多骨骼，降低单点 blend 的极端矩阵差异。
2. **Corrective shape 如何驱动？**  
   根据 joint angle/pose space RBF 等权重激活形变，补偿 LBS/DQS 无法表达的肌肉体积。

### 4.11 推荐实战

> 制作一个圆柱两骨骼180° twist，对比 LBS/DQS/twist-bone 三种体积误差。

完成实战时建议保留 **baseline、指标、实验变量、结果、结论** 五项记录。真正能在面试中形成 Senior signal 的不是“我写过”，而是“我能解释为什么这个实现更快/更稳，以及证据是什么”。

## 5. 如何验证，而不是“凭感觉优化”

- 固定随机种子/输入录制，保证问题可复现
- 区分 simulation state 与 render interpolation state
- 记录 latency、correction magnitude、contact/joint error 等领域指标

### 推荐实战

> 构造可重复 simulation/network demo，记录 state error、latency 或 contact/joint metrics。
