## 1. 这道题在考什么

这题属于 **动画、物理、AI 与网络**。面试官通常不是只听一个定义，而是在判断你能否把答案推进到：

## 2. 30 秒回答（PDF 核心内容）

GJK 判断两个凸体是否相交：A 与 B 相交等价于 Minkowski Difference AB 包含原点；算法用 support mapping 迭代构造 simplex，逼近/包围原点。

---

## 3. PDF 深入拆解（Source-derived）

优势是不需要显式构造 Minkowski Difference，只要每个 convex shape 能给定方向 d 的最远点 support(d)。在 3D simplex 从点/线/三角形到四面体。若需要穿透深度与接触法线，可在相交后用 EPA。GJK 的难点是数值鲁棒性、终止条件和退化 simplex。

### PDF 核心抓手
- Minkowski Difference
- support function
- simplex 迭代
- EPA 补充 penetration depth

### PDF 工程 Gotcha

把 GJK 说成“一个 SAT 的优化版”，两者思路不同。

### PDF 面试官在听什么

是否理解凸几何算法的核心变换。

## 4. 专业扩展（Repository v2）

这一节不再重复 PDF 的“定义答案”，而是把问题推进到 **可实现、可测量、可讨论 trade-off** 的层级。面试时不要求把下面所有内容一次讲完；更好的策略是先给结论，再根据面试官追问选择其中 2–3 个层次深入。

### 4.1 先修知识与概念边界

- convex geometry
- Minkowski difference
- support function
- simplex

### 4.2 核心心智模型

GJK 把两个凸体是否相交转成“原点是否位于 Minkowski Difference A−B 中”。它不显式构造 A−B，而用 support mapping 按方向获得最远点，并迭代 simplex 逼近原点。

### 4.3 底层机制：逐层拆开

- Support of difference `S_{A-B}(d)=S_A(d)-S_B(-d)`，因此只需两个 shape 的 support function。
- 从一个方向取 support point，维护 point/line/triangle/tetrahedron simplex，并选择最接近原点的区域和下一搜索方向。
- 若新 support 在搜索方向上都未越过原点，可判不相交。
- 若 tetrahedron 包含原点则相交；要 penetration depth/normal 常接 EPA。

### 4.4 必须守住的不变量 / 正确性条件

- 经典 GJK 针对 convex shapes。
- 数值终止、重复 support point、退化 simplex 必须处理，否则可能无限循环。

这些不变量比“记住某个 API”更重要：平台、实现或引擎版本可以变化，但只要不变量没变，你就能重新推导正确方案。

### 4.5 Trade-off：什么时候该用，什么时候不该用

- 对 sphere/box 等简单 pair 专用解析算法更便宜；GJK 适合统一任意凸体。
- EPA 提供 penetration 但复杂且数值鲁棒性要求高。

### 4.6 在真实游戏引擎中的落点

- Convex hull collision。
- Distance GJK 可求最近距离/closest points。
- Character/controller convex queries。

### 4.7 最小实现 / 数学骨架

```text
repeat:
  a = support(A-B, dir)
  if dot(a,dir) < 0: no intersection
  simplex.add(a)
  if simplex_contains_origin(): hit
  dir = new_search_direction(simplex)
```

> **面试建议**：代码或公式不是为了炫技。写完后要解释：输入是什么、输出是什么、最贵的步骤在哪里、哪个条件一旦破坏就会出错。

### 4.8 Profiling / Validation：如何证明你的判断

- iterations/query、failure/degenerate count、EPA fallback。
- 与 brute/known analytic shapes 做随机 differential test。

### 4.9 常见错误答案与为什么错

- “GJK 直接构造 Minkowski Difference 网格。”——只通过 support function 隐式查询。
- “dot<0 永远立即 no hit”——要在正确迭代/方向语义下使用，并考虑数值容差。

### 4.10 Senior 级追问与参考思路

1. **为什么 support mapping 高效？**  
   很多 convex primitive 可 O(1)，convex hull可 hill-climb/缓存 extreme vertex。
2. **GJK distance 与 intersection区别？**  
   distance variant 追踪 closest simplex 到原点并返回最近点，而不是只判断是否包含原点。

### 4.11 推荐实战

> 实现2D GJK先理解 simplex，再扩展3D tetrahedron，并用 box/sphere convex hull 随机测试。

完成实战时建议保留 **baseline、指标、实验变量、结果、结论** 五项记录。真正能在面试中形成 Senior signal 的不是“我写过”，而是“我能解释为什么这个实现更快/更稳，以及证据是什么”。

## 5. 如何验证，而不是“凭感觉优化”

- 记录 latency、correction magnitude、contact/joint error 等领域指标

### 推荐实战
