# 面试实战手册 · Professional v2

这份手册解决的不是“100 题答案是什么”，而是 **现场怎么回答、怎么思考、怎么被追问、怎么证明自己真的会教**。

## 1. 四类题，四种回答协议

### A. 数学知识口述题

推荐顺序：

```text
定义/条件 → 核心结构 → 关键公式或 lemma → 等号/边界 → 例子 → 方法选择边界
```

例如问 LTE，不要开场列五个版本。先说它解决什么、一个常用版本及条件，再主动指出 $p=2$ 和加号版本需单独检查。

### B. 陌生数学题

推荐顺序：

```text
重述约束 → 做小例子/特殊化 → 识别目标结构 → 提出中间命题 → 验证/换路
```

面试官往往比最终结果更关注“你有没有持续产生信息”。

### C. 教学/试讲题

推荐顺序：

```text
学习目标 → 学生已有知识 → 动机问题 → 核心结构 → 学生任务 → 反馈 → 迁移检查
```

### D. 教研/学生案例题

推荐顺序：

```text
事实 → 诊断假设 → 方案 → 指标 → 时间窗 → 复盘/备选方案
```

避免直接跳到“我会多沟通、多鼓励、多刷题”。

## 2. 3 分钟回答的时间预算

| 时间 | 内容 |
|---|---|
| 0:00–0:30 | 先给结论 / 方法选择 |
| 0:30–1:40 | 解释关键结构和条件 |
| 1:40–2:30 | 给例子、证明骨架或教学动作 |
| 2:30–3:00 | 主动说边界、风险或下一步 |

如果 30 秒还没出现中心句，回答通常已经开始发散。

## 3. 数学口述：把“我知道”变成“可审查证据”

### 低分表现

> “这题可以用 Cauchy，Titu 也行，还可以 Jensen……”

问题：只报工具名，没有展示选择依据。

### 高分表现

> “这里左侧是多个分式之和，而目标右侧包含线性和的平方。我先检查能否写成 Engel 形式，并确认分母之和会压成目标中的量；等号要求各组向量成比例，所以我还会核对这个比例是否与题目等号一致。”

### 自查四问

1. 我有没有说条件？
2. 我有没有解释为什么这个工具比相邻工具自然？
3. 我有没有处理等号/边界？
4. 我能不能给一个方法失效的反例？

## 4. 陌生题：如何让面试官看到“有效探索”

不要持续沉默，也不要把每个无意义草稿全说出来。可以口述**决策级信息**：

- “先看 $n=1,2,3$，我想判断是奇偶约束还是极值现象。”
- “直接展开增加了项数，没触及等号结构，我暂时停止这条路线。”
- “目标是共点，我会分别测试 Ceva 和根轴能否把它转成标量条件。”
- “若固定 $y$ 后关于 $x$ 是二次，我会检查另一个根是否仍是正整数，从而考虑下降。”

### 10 分钟检查点

- 是否得到一个非平凡特殊情形；
- 是否找到一个候选 invariant / equality / symmetry；
- 是否提出一个可验证的 lemma；
- 是否排除至少一条路线并知道为什么；
- 是否应该换表示。

## 5. Proof critique：先找“最早的坏点”

面试官给一份错误证明时，不要从结论说“错了”。按顺序审：

1. 定义域和量词；
2. 排序/“不妨设”是否合法；
3. 除零、开方、平方、取对数是否合法；
4. 定理条件；
5. 必要/充分方向；
6. 边界和退化；
7. 最后结论是否真的覆盖题目。

找到**最早一个**无法验证的步骤，通常就足以定位根因。

---

## 6. 试讲：一节短课只能有一个中心句

例如辅助线课的中心句可以是：

> “辅助线不是猜出来的；先把目标翻译成标准结构，再补结构缺失的条件。”

所有例题、提问和板书都应服务这句话。

### “假互动”警报

低质量互动：

> “大家是不是都懂了？”

高质量认知检查：

> “如果我要用 Ceva，现在图中三个边比里哪一个还没有来源？”

后者能真实暴露学生当前思维状态。

---

## 7. 三级提示协议

对任何高难题预先准备：

- **Level 1 · 方向提示**：提醒看某种结构，不给操作；
- **Level 2 · 结构提示**：指出关键中间目标；
- **Level 3 · 接近答案**：给出关键构造/公式，学生完成证明。

面试中主动提到分级提示，能体现你不是只有“讲/不讲”两个档位。

---

## 8. 教研题：用 artifact 说话

说“我会做课程研发”证据很弱。更强的回答是直接展示：

- 课程地图；
- 10–20 页专题讲义；
- 测评蓝图；
- 题库 schema；
- 一次依据学生数据修改讲义的版本 diff。

### 教研回答的量化语言

少说：

> “根据学生情况调整。”

多说：

> “如果基础复现正确率 >85%，但近迁移 <60%，下一周期减少同型题，把约一半练习换成隐藏触发信号的变式；两周后用同结构不同表面复测。”

---

## 9. 学生与家长案例：守住专业边界

三条底线：

1. 不承诺不可控奖项；
2. 不用一次成绩给学生贴“有/没天赋”标签；
3. 重大投入决策要让学生本人参与。

一个成熟的沟通句式：

> “目标可以明确，但训练手段要由证据决定。我们先看当前瓶颈，再约定四周行动和指标，四周后一起复盘，而不是把难题数量本身当成进步。”

## 10. 终面：用证据链回答“为什么是你”

推荐结构：

```text
Solve   数学深度
  ↓
Explain 能显性化专家思维
  ↓
Teach   能诊断和设计课堂
  ↓
Build   能建设课程、题库和培养系统
```

每层只讲一个最强证据：一道代表性数学问题、一个试讲片段、一个学生诊断案例、一份教研 artifact。

## 11. 常见面试失败模式

| 失败模式 | 表现 | 修复 |
|---|---|---|
| 工具清单式 | 报很多定理但没有选择理由 | 每题先说触发信号与边界 |
| 神解式 | 直接给关键构造 | 恢复发现链 |
| 口号式教学 | “因材施教、多鼓励” | 行为指标 + 时间窗 |
| 过度展开 | 数学细节淹没中心 | 30 秒先结论 |
| 过度炫技 | 高等方法替代初等结构 | 比较认知成本 |
| 无证据自述 | “我责任心强、热爱数学” | 用 artifact 与数据证明 |
