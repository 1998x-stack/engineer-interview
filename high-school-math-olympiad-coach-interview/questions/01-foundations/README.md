## 模块学习建议

### 专业展开：从“回答观点”升级到“给出可执行决策”
这类题的高分关键不是表达价值观，而是完成 **事实/现象 → 诊断 → 决策 → 验证指标** 的闭环。回答时尽量给出可观察证据，例如“学生能否在无提示情况下提出小例子”“提示一次后能否迁移”“完整证明的漏洞类型是否下降”，而不是使用“有天赋、很努力、感觉适合”这类不可审查标签。

建议口述采用四步：**先下结论 → 给判断依据 → 给一个真实课堂/训练动作 → 给复盘指标**。这样面试官可以判断你是否具备真正的教练决策能力，而不只是竞赛经历。


## 专业版模块导航

### 面试官真正想确认什么
本模块不是“教育理念闲聊”，而是在判断候选人是否具备**岗位级判断力**：能否区分竞赛与校内数学、能否建立分层培养目标、能否用证据判断学生是否适合继续投入，以及能否把个人竞赛经验转化为可复制的训练系统。

### 推荐学习顺序
1. **Q001-Q002**：先建立竞赛能力模型与赛制能力差异；
2. **Q003-Q006**：学习学生诊断与“有效探索”定义；
3. **Q007-Q009**：形成工具观、套路观与好题观；
4. **Q010**：把前面所有判断收束为年度培养方案。

### 面试准备产出物
完成本模块后，建议准备三份真实材料：
- 一页“竞赛能力模型”；
- 一份 6–8 周学生诊断/试训方案；
- 一份一年省一培养路线图，含阶段指标和调整机制。

### 高分答案的共同特征
不要用“兴趣、天赋、多刷题”这种不可操作词作为最终结论。每个判断尽量转化为：**可观察行为 → 训练动作 → 评价指标 → 复盘时间点**。
