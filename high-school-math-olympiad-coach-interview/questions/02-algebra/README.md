## 模块学习建议

### 专业展开：代数题的“五问”
在不等式、方程、多项式和数列问题中，先统一检查：**对象是什么、结构是否齐次/对称、等号或特殊根在哪里、使用的定理条件是否满足、变形是否保留等价性**。竞赛代数最常见的低级失分不是不会定理，而是为了套定理破坏了等号结构或遗漏定义域。

面试表达时最好同时给出“为什么选这个工具”和“什么信号出现时不用它”。能明确工具的失效边界，比多报几个定理更能体现成熟度。


## 专业版模块导航

### 知识主线
本模块可分为四条链：

1. **不等式结构**：Q011 AM-GM → Q012 Cauchy → Q013 $uvw$ → Q014 齐次化 → Q015 Schur → Q016 Jensen → Q022 切线法；
2. **多项式结构**：Q017 根的工具选择 → Q018 辅助多项式 → Q019 Vieta Jumping；
3. **函数方程**：Q020 信息提取 → Q021 单射/满射；
4. **数列与教学迁移**：Q023 递推 → Q024 配方设计 → Q025 纠正暴力展开。

### 训练标准
每个定理至少掌握五件事：**母式、使用条件、等号/边界、触发信号、失效反例**。面试中只报公式通常只能证明“见过”，不能证明“会教、会选”。

### 推荐板书训练
对 Q011-Q016 每题限制一页纸：左侧写“结构识别”，中间写证明，右侧写等号与替代方法。对 Q017-Q023 则重点画“问题类型 → 工具”的决策树。

### 进阶要求
能够比较同一道题的至少两种方法，并回答：哪一种更适合比赛现场？哪一种更适合第一次教学？哪一种更容易推广？
