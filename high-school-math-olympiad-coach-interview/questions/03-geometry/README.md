## 模块学习建议

### 专业展开：把“灵感”还原成目标结构
几何题应尽量用 **目标 → 中间结构 → 可制造条件 → 辅助构造** 来解释。目标是长度比时，优先寻找相似、正弦定理或圆幂；目标是共点/共线时，考虑 Ceva/Menelaus、根轴或投影结构；大量圆与切线则检查圆幂、根轴、反演等。

教练面试尤其忌讳把关键步骤说成“显然作一条线”。优秀回答要恢复发现链，并说明为什么该构造减少了自由度或把结论翻译成标准结构。


## 专业版模块导航

### 能力梯度
本模块不是 15 个几何工具的清单，而是一条从**基础图形语言 → 结构判定 → 表示变换**的路径：

- Q026-Q028：辅助线、追角、共圆——建立基础图感；
- Q029-Q032：圆幂、根轴、Ceva/Menelaus、正弦 Ceva——建立标准结构接口；
- Q033-Q035：坐标、复数、向量——比较不同表示；
- Q036-Q038：反演与方法选择——训练高阶变换观；
- Q039-Q040：把工具重新落回课程顺序与几何直觉培养。

### 统一解题语言
建议每道几何题都强制写一条发现链：

```text
目标结论 → 可用标准结构 → 当前缺失条件 → 构造/变换 → 验证
```

### 面试高频风险
- 根据图形“看起来”判断点序或共圆；
- 只会高级工具却解释不出选中心/选坐标的理由；
- 辅助线使用“显然作……”掩盖真正思考；
- 不处理延长线、有向角或退化情况。

### 教研产出
建议建立一张“几何方法选择表”：目标是角/比/乘积/共点/共线时分别优先检查哪些结构。
