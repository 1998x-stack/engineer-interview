## 模块学习建议

### 专业展开：局部信息与下降结构
数论面试题通常在考三件事：能否从整除关系提取 **局部信息（同余/估值）**，能否利用 **结构性分解（gcd、因式分解、韦达）**，以及能否通过 **极小反例/无限下降** 把存在性问题转成矛盾。

任何引用 LTE、Bézout、欧几里得算法、Legendre 等工具时，都应主动说清条件。数论证明对“条件遗漏”非常敏感，面试官常用追问专门检查这一点。


## 专业版模块导航

### 四条核心主线
1. **局部信息**：Q041 同余 → Q043 平方剩余 → Q044 模数选择；
2. **整除结构**：Q045 Euclid 引理 → Q048 gcd 不变性 → Q049 线性丢番图；
3. **估值系统**：Q046 $v_p$ → Q047 LTE → Q053 Legendre → Q054 组合数估值；
4. **下降与特殊方程**：Q050 Pell → Q051 无限下降 → Q052 Vieta Jumping → Q055 卡题后的方法切换。

### 训练规范
数论证明最怕“定理条件漏掉”。建议所有 LTE、Bézout、Legendre、下降证明都固定加入一行 **Condition check**，把整数性、正性、素数条件、互素条件写清楚。

### 面试表达
当你选择某个模数时，要能回答“这个模数预期排除什么剩余类”；当模数无效时，要及时切换估值、gcd、因式分解、大小或下降，而不是继续随机试。

### 进阶产出
做一张 `local-to-global` 卡片：同余给局部排除、估值给精确指数、gcd 给公共结构、下降给全局不可能性。
