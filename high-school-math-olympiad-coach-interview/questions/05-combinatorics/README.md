## 模块学习建议

### 专业展开：先建模，再选工具
组合题的第一步不是背“抽屉/染色/极值/概率法”，而是定义 **对象、关系、状态、允许操作和目标性质**。随后判断目标更接近：存在性、计数、不可达性、终止性、匹配或同色结构。

建议用“**对象是什么 → 我想保持/优化什么量 → 为什么这个量约束目标 → 结论如何落地**”来讲。组合解法的漂亮之处通常在模型，而不是计算。


## 专业版模块导航

### 先建模，再报定理名
组合题的共同流程是：

```text
对象与关系 → 状态/分类 → 想保持或优化的量 → 存在/计数/构造结论
```

### 内容分组
- Q056-Q060：抽屉、极值、不变量、单调量、染色——存在性与不可达性；
- Q061-Q064：双计数、组合恒等式、递推、容斥——计数体系；
- Q065-Q067：Hall、图论、Ramsey——关系结构；
- Q068-Q070：概率法、生成函数、构造 vs 存在——更高层方法选择。

### 面试高分点
必须明确“我到底在数什么”“状态是否最小充分”“不变量在一次操作后为什么真的不变”。组合题中一句错误建模会让后续计算全部失效。

### 训练建议
每题完成后写一句：如果删除题面故事，我的抽象对象是什么？这句话能显著提高模型迁移能力。
