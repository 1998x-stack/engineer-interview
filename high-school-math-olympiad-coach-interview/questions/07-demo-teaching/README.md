## 模块学习建议

### 专业展开：试讲的目标不是“展示知识量”
高质量试讲应呈现一条学生能跟随的认知路径：**动机问题 → 学生预测 → 核心结构 → 证明/解释 → 一题应用 → 变式或错误辨析 → 总结**。时间短时宁可讲透一个决定性 idea，也不要列举十种技巧。

每个关键步骤都准备三级提示：方向提示、结构提示、几乎完成的提示。这样才能证明你不仅会讲标准答案，还会在学生真正卡住时进行教学决策。


## 专业版模块导航

### 试讲评价的五个维度
1. 数学正确性；
2. 学习目标是否聚焦；
3. 是否展示发现过程而非只给成品；
4. 是否有真实学生参与和分级提示；
5. 是否有即时检查与迁移。

### 推荐演练顺序
先练 Q079-Q082 四个完整短课，再练 Q083-Q088 的“教学决策题”。前四题负责证明你会设计课堂，后六题负责证明你会处理真实学生差异和课堂执行。

### 录课复盘
每次录 10–20 分钟，按分钟标记：教师讲解、学生思考、提问、反馈分别占多少时间；再检查是否有超过 3 分钟的连续单向讲授而无认知检查。

### 必备材料
每个试讲准备：时间轴、板书地图、三级提示、一个错误样例、一个 exit ticket。
