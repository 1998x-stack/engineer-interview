## 模块学习建议

### 专业展开：教育判断必须可解释、可复盘
学生管理题的核心是避免两种极端：用竞赛结果替代对人的判断，或用情绪性安慰替代专业决策。建议使用 **事实 → 解释假设 → 干预 → 观察期 → 再决策** 的框架，并把学生本人纳入决策，而不是只与家长或机构目标对齐。

涉及成绩波动、继续/退出竞赛、训练量时，应同时考虑能力曲线、机会成本、兴趣、校内影响和目标时间窗。


## 专业版模块导航

### 这一模块测试专业边界
竞赛教练不仅要提高成绩，还要在奖项压力、家长期望、学生兴趣和机会成本之间做可解释决策。

### 五题形成一个连续案例
- Q096：强学生的证明习惯；
- Q097：比赛表现波动；
- Q098：家长期望与训练剂量；
- Q099：是否继续投入竞赛；
- Q100：把自己的数学、教学、教研和培养能力整合为终面证据链。

### 统一决策框架
```text
事实 → 解释假设 → 干预方案 → 指标与观察窗 → 再决策
```

### 沟通底线
不做奖项保证、不以一次成绩贴标签、不用“天赋不足/心态不好”替代诊断；学生本人应参与影响其长期时间投入的重大决定。

### 终面准备
至少准备一个“成功案例”和一个“没有达到目标但决策合理”的案例。后者往往更能体现成熟度和专业边界。
