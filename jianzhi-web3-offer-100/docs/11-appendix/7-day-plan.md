# 7 天冲刺计划

| 时间 | 范围 | 训练目标 |
|---|---|---|
| Day 1 | Q01-Q20 | Blockchain + EVM；重点手推 storage / calldata / tx lifecycle |
| Day 2 | Q21-Q40 | Solidity + Security；把 CEI、Proxy、storage layout 讲到能画状态机 |
| Day 3 | Q41-Q60 | DeFi + L2；手推 xy=k、HF、DA、Rollup trust model |
| Day 4 | Q61-Q80 | Wallet/AA + Infra；重点 712/4337/7702、reorg/RPC |
| Day 5 | Q81-Q90 | Solana/Multi-chain；重点 account/program/PDA/CPI 与冲突并行 |
| Day 6 | Q91-Q100 | Coding + System Design；每题限时 30-45 分钟口述/画图 |
| Day 7 | 五星题复盘 | 只看记忆锚点，自测追问，补错题和项目经历映射 |

## 每天固定动作

- 20 分钟：只看前一天错题的“记忆锚点”。
- 60-90 分钟：新题，先口述再看答案。
- 30 分钟：任选 2 题做白板深挖。
- 30 分钟：把答案映射到自己的项目经历，准备真实案例。
- 结束前：记录 3 个最容易混淆的边界条件。
