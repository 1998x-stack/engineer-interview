如何设计一节单元复习课？

题目：请设计一节 90 分钟竞赛专题复习课。

类型 公开教师面试高频
难度 ★★★☆☆

0. 30 秒快速作答卡

  • 第一触发器：题目要求
  • 核心方法/判断：复习课不是“题目串烧”，而是“知识 - 方法 - 触发器 - 易错点 - 迁移”的网络重建。
  • 最终结论/主张：5 分钟 exit ticket
  • 面试必须补充：不仅给结论，还要解释“为什么想到”、边界和学生可能卡在哪里。

1. 面试定位与前置能力

1.1 面试官为什么问

考察课程结构、测评与迁移。

1.2 前置知识 / 能力

  • 岗位场景理解
  • 结构化表达
  • 证据化回答

1.3 结构触发器

  • 信号：题目要求
  • 信号：可观察证据
  • 信号：执行边界

1.4 高分与普通回答的分水岭

普通回答停在“答案正确/观点合理”；高分回答还会给出触发器、选择理由、验证方式、失效边界和迁移。竞赛教师岗位尤其看重能否把专家的隐性判断拆成学生可以执行的步骤。

2. 深度分析：为什么这条路最自然

PDF 基线突破： 复习课不是“题目串烧”，而是“知识 - 方法 - 触发器 - 易错点 - 迁移”的网络重建。

终面回答要同时有价值判断、执行步骤和边界意识；涉及政策/赛事时以最新官方规定为准。

2.1 决策树

  1. 先识别题目最强约束，不急于计算。
  2. 列出 2-3 个候选方法，并优先选择前置最低、可解释、可验证的一条。
  3. 走到关键步骤时检查条件是否全部满足。
  4. 完成后用另一种表示、数值/边界或逆向检查做独立校验。

3. 完整标准解 / 高分回答

3.1 PDF 基线答案

建议结构：10 分钟 retrieval quiz；15 分钟概念/方法地图；25 分钟典型题 2 道；20 分钟变式/对比；10 分钟限时独立题；5 分钟错因复盘；5 分钟 exit ticket。

3.2 GitHub 深化版

复习课的产物应该是一个“方法网络”，不是题目列表。90分钟可用： - 10分钟闭卷提取； - 15分钟概念/方法地图； - 25分钟两道典型题（突出触发器）； - 20分钟对比变式； - 10分钟独立迁移； - 5分钟错因归类； - 5分钟 exit ticket。

难度控制以“多数学生能独立启动、关键处需要思考”为目标。

3.3 为什么主解适合面试

  • 正确且短：主线清晰，不靠无关技巧。
  • 可解释：关键一步有来源，能回答“为什么想到”。
  • 可教学：可以拆成提示梯度，而不是只能由老师表演。
  • 可迁移：能自然生成追问、变式或方法边界。

4. 教学化转译

4.1 PDF 基线教学建议

把题目按“同一结构不同表面”组织，让学生学会识别触发条件。

4.3 分层提示梯度

  1. 弱提示：先让回答者给明确结论，不补背景。
  2. 中提示：追问“你的判断依据/诊断证据是什么？”
  3. 强提示：要求给一个具体动作、一个可观察指标和一个边界。

4.4 10 分钟试讲 / 口述节奏

时间 教师动作 学生动作 / 评价证据
前20% 结论 直接给立场/方案。
中60% 证据与动作 2-3层展开诊断、措施和指标。
后20% 边界与收束 说明限制、复盘和岗位价值。

6. 面试追问：逐题实答

6.1 追问：如何控制难度？

难度用数据控制而不是凭感觉：基础提取题目标高正确率，中档迁移题看无提示启动率，高区分题看能否形成多层得分。若大多数人第一步都无法启动，说明难度或支架失配；若人人秒答，则缺少迁移价值。

6.2 追问：复习课与新授课的提问方式有什么不同？

新授课的问题链主要服务‘建立概念与形成第一模型’，问题更小、支架更密；复习课则服务‘提取、比较、整合、迁移’，应减少提示，更多问‘为什么选这个方法、与另一方法有什么边界、条件换掉还成立吗’。

7. 变式设计与迁移训练

7.1 同构变式

保持本题核心触发器不变，只改变数字、字母、图形位置或表面语言。要求：学生不能靠记答案，必须重新说出触发器。

7.2 近迁移变式

改变一个关键条件，但保留主方法。练习目标是判断“原方法哪一步仍成立、哪一步需要调整”。

7.3 反例 / 边界变式

删掉一个必要条件，要求构造最小反例，或说明为什么原方法失效。对于竞赛教师面试，这类追问非常能区分“背题”与“理解”。

7.4 自己出题的检查表

  • [ ] 变式是否真的改变了认知操作，而不是只加计算量？
  • [ ] 是否能说明它和原题共享哪个结构？
  • [ ] 是否知道原方法的失效边界？
  • [ ] 是否有可快速验证的标准答案/判据？

8. 面试官评分 Rubric

维度 权重 高分表现
结论清晰 25% 开头20秒给明确判断。
诊断/证据 30% 不是泛泛价值观，有事实与依据。
行动方案 25% 步骤具体、适龄、可执行。
边界意识 20% 不夸张承诺，知道何时升级/调整。

8.1 典型档位

  • S / 强通过：主解正确，能解释触发器，追问至少处理一层推广，并能给学生提示梯度。
  • A / 通过：主解正确、表达清楚，但迁移或教学诊断略弱。
  • B / 边缘：知道结论/套路，但解释“为什么想到”困难。
  • C / 风险：存在数学错误、逻辑跳步、过度承诺或不适龄教学。

9. 刻意练习与复盘

当天

  1. 不看答案重新完成一次；
  2. 用 90 秒只讲“为什么想到”；
  3. 用 3-5 分钟讲完整主线；
  4. 处理本页全部追问。

24 小时后

  • 不看标题，仅凭题目写出第一触发器；
  • 判断自己是否仍依赖提示；
  • 重新做一个近迁移变式。

自我复盘问题

  • 我能否在30秒内给出第一有效观察？
  • 我是否能指出一个失效边界或反例？
  • 学生卡住时，我的最小提示是什么？
  • 我能否不用“显然、容易看出”跳过关键认知步骤？

10. 90 秒复述、掌握等级与训练记录

这一节的目标是把“看懂”转成可观察、可复现的面试能力。复习标准不要停在“答案我见过”，而要要求自己在没有原文提示时重构主线。

10.1 90 秒复述模板

前 15 秒：定位。 说出题目最强信号、第一候选工具，以及为什么它比其他候选更自然。不要一开口就铺计算或背景。

15-55 秒：主线。 只保留 2-4 个不可替代的中间节点：条件怎样转化、关键结构怎样出现、结论怎样推出。数学题要说明等价性/充分性；教学与行为题要说明“诊断 → 动作 → 证据”。

55-75 秒：校验。 主动补一个边界、等号条件、异常情况、反例或实施风险。这一步最能区分“记住答案”和“真正掌握”。

75-90 秒：迁移。 用一句话说明：若题面改动一个关键条件，原方法哪一步仍成立、哪一步必须换工具；若是教学题，则说明怎样把结论转成学生可执行任务或课堂评价指标。

10.2 掌握等级

等级 可观察表现 是否建议进入下一题
L0 识别 看答案后熟悉，但不能独立启动 否
L1 启动 能说第一工具，但主线仍依赖提示 否
L2 独立 能完成主解/主回答并自检 可以
L3 迁移 能处理至少一个追问和一个近迁移变式 推荐
L4 教学 能设计提示梯度、解释失效边界并在 5-10 分钟内教清楚 面试级

竞赛教师面试的核心题建议至少达到 L3；需要试讲的题建议达到 L4。

10.3 训练记录模板

每次复习只记录会帮助下一轮决策的数据，而不是写长篇感想：

字段 记录内容 示例
first_move_seconds 看到题到说出有效第一步的秒数 38
hint_level 0=独立；1=方向；2=关键结构；3=几乎给解 1
mainline_correct 主线是否完整正确 yes/no
boundary_named 是否主动指出边界/等号/反例 yes/no
followup_score 本页追问独立完成比例 2/3
teach_back_90s 90 秒复述是否连贯 yes/no
recall_24h 24 小时后能否重构第一触发器 yes/no

退出标准：连续两次 hint_level=0，能在 90 秒内讲清主线，且至少完成一个追问或变式，再把本题从“正在学习”移入“维护复习”。否则优先回到卡点所在的小节，不要机械重做整页。
