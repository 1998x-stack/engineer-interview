# 初中数学竞赛教师面试宝典 · 100 题

> 面向初中数学竞赛 / 数学思维 / 拔尖创新教师岗位的系统面试知识库。

本仓库是《初中数学竞赛教师面试宝典·100题（2026专业版）》的 **GitHub v2.0 深化版**。PDF 作为发布基线，100 个 Markdown 则被进一步扩展为可独立学习的“微章节”：不仅保留题目与答案，还加入前置知识、结构触发器、完整推导、提示梯度、追问实答、变式设计、评分 Rubric 与刻意练习。

## 核心特性

- **100 题 = 100 个独立 Markdown**，方便搜索、复习、PR 和版本维护。
- 覆盖 **代数 / 数论 / 平面几何 / 组合 / 方法论 / 试讲 / 教研 / 学情 / 家长沟通 / 综合终面**。
- 每题统一包含：30秒作答卡、前置能力、结构触发器、完整标准解/高分回答、教学提示梯度、板书骨架、错误诊断、**逐条追问实答**、变式迁移、评分 Rubric 与24小时复现。
- 保留 PDF 发布版，并附 `questions.json` 结构化数据。
- 自带仓库校验脚本，检查题目数、必备章节、链接结构和 PDF 是否存在。

## 题目来源口径

公开网络可直接核验的“初中数学竞赛教师专岗原题”数量有限，因此本项目明确区分：

1. **公开教师面试高频题型**；
2. **根据竞赛教师招聘职责反推的高仿实战题**；
3. **竞赛数学核心功底题**。

不会把第 2 类题目包装成某一机构公开真题。具体说明见 [参考资料与口径](appendices/D-参考资料与口径说明.md)。

## 合规提示（2026）

教育部 2022 年管理办法规定，原则上不举办面向义务教育阶段的学科类全国性竞赛活动；2025-2028 学年全国性中小学生竞赛实行名单管理，竞赛及结果不得作为中小学招生入学依据和高考加分项目。具体赛事应核验最新官方名单和当地规定。

## 内容维护原则

- 单题修改只编辑对应 Markdown；不要把 100 题重新合并成一个巨大文件。
- 新增题必须分配唯一 `Qxxx`、章节、难度、频度和标签。
- 数学题的答案修改必须同步检查：定义域、等价变形、边界、反例和追问。
- 教学题的修改必须说明：学生动作、最小提示、证据和复盘。
- 涉及政策和赛事信息必须标明核验日期并优先使用官方来源。
