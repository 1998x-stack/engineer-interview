# 竞赛数学触发器地图

竞赛能力的核心不是记“题型名字”，而是把题面信号映射到候选工具。

| 题面信号 | 第一候选 | 进一步检查 |
|---|---|---|
| 高次对称式、倒数成对 | 递推 / 对称量 | 是否能降阶到 S_n |
| 整数 + 大指数末位 | 同余 / 周期 | 模 10^k、乘法阶 |
| 恰有 d 个因数且求最小 | 因数个数 + 乘法分拆 | 大指数配小素数 |
| x²-y²=N | 平方差 + 因数对 | 同奇偶、正性 |
| 三线共点 + 边上比例 | Ceva / 面积比 | 是否有更低前置解 |
| 共线 + 三边/延长线比 | Menelaus | 有向线段符号 |
| 圆 + 线段乘积 | 点幂 | 割线/切线点序 |
| 线段和 + 镜面/边界 | 反射 | 是否可展开为直线 |
| 60° + 等边/等长 | 旋转 | 旋转后是否首尾衔接 |
| 计数且“至少存在” | 抽屉 | 抽屉标签怎么选 |
| 铺砖/递归结构 | 末端分类递推 | 分类是否互斥穷尽 |
| 有限集 + 闭合性质 | 极端原理 | 最大/最小元能否制造矛盾 |

## 训练方法

每做完一道题，不记录“题型=某某法”，而记录：

```text
信号 → 候选方法 → 为什么选它 → 关键中间对象 → 边界/反例
```
