# 学情诊断与数据记录

不要只记录“这题对/错”。建议每次练习至少记录：

| 字段 | 示例 |
|---|---|
| first_move_seconds | 45 |
| hint_level | 0/1/2/3 |
| method_tag | factorization |
| error_type | 漏分类 / 逻辑逆用 / 运算 |
| independent_correct | true/false |
| delayed_recall_24h | true/false |
| transfer_success | true/false |

## 五类常见停滞

1. **知识缺口**：定理/概念没掌握；
2. **识别缺口**：知道方法但题面看不出；
3. **执行缺口**：方法对但计算/证明不稳；
4. **迁移缺口**：原题会，换皮不会；
5. **考试策略缺口**：时间、选题、表达导致丢分。

训练策略必须对应根因，而不是统一“再刷50题”。
