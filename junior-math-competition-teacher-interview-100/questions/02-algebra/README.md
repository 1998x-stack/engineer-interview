# 第二章  代数核心功底

代数面试重点是结构识别、等价变形、参数与不等式，而不是纯计算速度。

## 本章学习目标

- 识别代数结构而非机械套公式
- 掌握等价变形、递推、韦达、最值等母题
- 能把“为什么想到”转成教学问题链

## 推荐学习顺序

先完成 Q011-Q025 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。
