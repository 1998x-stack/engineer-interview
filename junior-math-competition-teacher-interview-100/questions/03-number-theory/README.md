# 第三章  数论核心功底

数论考察整数结构、同余、整除与构造，是最能区分竞赛功底的模块之一。

## 本章学习目标

- 建立整除—同余—因数—不定方程的统一视角
- 会用 gcd、质因数分解、平方剩余处理整数约束
- 能解释算法/构造背后的不变量

## 推荐学习顺序

先完成 Q026-Q038 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。
