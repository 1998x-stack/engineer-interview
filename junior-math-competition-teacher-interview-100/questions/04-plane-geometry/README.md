# 第四章  平面几何核心功底

几何的关键不是辅助线数量，而是触发器、变换、比例与证明链。

## 本章学习目标

- 建立几何触发器系统
- 辅助线由目标结构驱动
- 能比较纯几何、坐标、面积、变换等方法

## 推荐学习顺序

先完成 Q039-Q053 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。
