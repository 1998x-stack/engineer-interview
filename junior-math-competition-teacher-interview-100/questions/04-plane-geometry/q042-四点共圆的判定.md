## 0. 30 秒快速作答卡

- **第一触发器**：四点共圆判定

## 2. 深度分析：为什么这条路最自然

### 2.1 决策树

1. 先识别题目最强约束，不急于计算。
2. 列出 2-3 个候选方法，并优先选择前置最低、可解释、可验证的一条。
3. 走到关键步骤时检查条件是否全部满足。
4. 完成后用另一种表示、数值/边界或逆向检查做独立校验。

## 3. 完整标准解 / 高分回答

### 3.1 PDF 基线答案

常用：对角互补；同弦所对角相等；某两角同为 90°（直径圆）；幂关系 PA·PB=PC·PD 的逆向构造。

### 3.2 GitHub 深化版

常用判定可以按“角”与“乘积”组织：

1. **对角互补**：若四边形一组对角和为 \(180^\circ\)，则四点共圆；
2. **同弦视角**：若两个点在弦两侧，应比较补角；若在同侧，看到同一线段所张角相等可推出共圆；
3. **两个直角**：若 \(\angle APB=\angle AQB=90^\circ\)，则 \(P,Q\) 都在以 \(AB\) 为直径的圆上；
4. **幂关系逆用**：若合适的共线关系下有 \(PA\cdot PB=PC\cdot PD\)，可构造圆并用点幂逆向判定。

专业讲解必须提醒：角相等判共圆时要核对点在弦的哪一侧，避免把“相等”与“互补”混为一谈。

### 3.3 为什么主解适合面试

- **正确且短**：主线清晰，不靠无关技巧。
- **可解释**：关键一步有来源，能回答“为什么想到”。
- **可教学**：可以拆成提示梯度，而不是只能由老师表演。
- **可迁移**：能自然生成追问、变式或方法边界。

## 4. 教学化转译

### 4.1 PDF 基线教学建议

建立触发器：题里大量“角”优先角判定；出现两个直角想到直径圆；出现线段乘积想到点幂。

### 4.2 学生最可能卡在哪里

- **表现**：堆性质表。
  - **可能根因**：把内容数量/难度误当学习价值，忽略认知负荷与复用率。
  - **纠偏动作**：回到课程目标，保留高复用结构；将低复用高级内容降为拓展，并用迁移表现决定是否升级。
- **表现**：把充分条件与必要条件混淆。
  - **可能根因**：没有显式检查触发条件、边界或逻辑方向。
  - **纠偏动作**：回退到最近一个确定正确的节点，写出所需条件，再决定是否继续原方法。
- **表现**：圆内外角关系方向错。
  - **可能根因**：没有显式检查触发条件、边界或逻辑方向。
  - **纠偏动作**：回退到最近一个确定正确的节点，写出所需条件，再决定是否继续原方法。

### 4.3 分层提示梯度

1. 弱提示：只指出题面信号——四点共圆判定，暂不报方法名。
2. 中提示：让学生回忆相关结构——角条件。
3. 强提示：明确目标方法/中间对象——点的同侧/异侧需判断，但仍让学生完成关键计算或证明。

### 4.4 10 分钟试讲 / 口述节奏

| 时间 | 教师动作 | 学生动作 / 评价证据 |
|---|---|---|
| 0:00-1:00 | 观察 | 让学生说条件、目标和一个最显眼信号。 |
| 1:00-2:30 | 卡点 | 暴露常规方法为什么不够。 |
| 2:30-5:30 | 突破 | 用提示梯度引出关键结构。 |
| 5:30-7:30 | 完成 | 学生/教师共同完成推导并检查条件。 |
| 7:30-9:00 | 总结 | 提炼“看到什么→想到什么”。 |
| 9:00-10:00 | 变式 | 一题近迁移，验证不是记答案。 |

## 6. 面试追问：逐题实答

### 6.1 追问：如何从“∠ABC=∠ADC”判断四点顺序？

角等关系要配合点相对弦的位置判断。对同一弦AC，顶点B,D在同侧时所张圆周角相等；在异侧时相关角通常互补。画图时先标明点顺序/同侧性，再选“相等”还是“互补”判据。

### 6.2 变式：两点看到一条线段张同角。

若两个点P,Q在同一侧看到线段AB张相同角，即 \(\angle APB=\angle AQB\)，则A,B,P,Q共圆（排除共线退化）；若P,Q在AB两侧，应改用补角版本。

## 7. 变式设计与迁移训练

### 7.1 同构变式

保持本题核心触发器不变，只改变数字、字母、图形位置或表面语言。要求：学生不能靠记答案，必须重新说出触发器。

### 7.2 近迁移变式

改变一个关键条件，但保留主方法。练习目标是判断“原方法哪一步仍成立、哪一步需要调整”。

### 7.3 反例 / 边界变式

删掉一个必要条件，要求构造最小反例，或说明为什么原方法失效。对于竞赛教师面试，这类追问非常能区分“背题”与“理解”。

### 7.4 自己出题的检查表

- [ ] 变式是否真的改变了认知操作，而不是只加计算量？
- [ ] 是否能说明它和原题共享哪个结构？
- [ ] 是否知道原方法的失效边界？
- [ ] 是否有可快速验证的标准答案/判据？

| 结构识别 | 25% | 能解释触发器，不靠背结论。 |
| 教学转译 | 20% | 能设计最小提示并解释学生卡点。 |
| 追问迁移 | 20% | 能解变式、给反例、比较方法。 |

### 8.1 典型档位

- **S / 强通过**：主解正确，能解释触发器，追问至少处理一层推广，并能给学生提示梯度。
- **A / 通过**：主解正确、表达清楚，但迁移或教学诊断略弱。
- **B / 边缘**：知道结论/套路，但解释“为什么想到”困难。
- **C / 风险**：存在数学错误、逻辑跳步、过度承诺或不适龄教学。

## 9. 刻意练习与复盘

### 当天

1. 不看答案重新完成一次；
2. 用 90 秒只讲“为什么想到”；
3. 用 3-5 分钟讲完整主线；
4. 处理本页全部追问。

### 24 小时后

- 不看标题，仅凭题目写出第一触发器；
- 判断自己是否仍依赖提示；
- 重新做一个近迁移变式。

### 自我复盘问题

- 我能否在30秒内给出第一有效观察？
- 我是否能指出一个失效边界或反例？
- 学生卡住时，我的**最小提示**是什么？
- 我能否不用“显然、容易看出”跳过关键认知步骤？


## 10. 90 秒复述、掌握等级与训练记录

这一节的目标是把“看懂”转成**可观察、可复现的面试能力**。复习标准不要停在“答案我见过”，而要要求自己在没有原文提示时重构主线。

### 10.1 90 秒复述模板

**前 15 秒：定位。** 说出题目最强信号、第一候选工具，以及为什么它比其他候选更自然。不要一开口就铺计算或背景。

**15-55 秒：主线。** 只保留 2-4 个不可替代的中间节点：条件怎样转化、关键结构怎样出现、结论怎样推出。数学题要说明等价性/充分性；教学与行为题要说明“诊断 → 动作 → 证据”。

**55-75 秒：校验。** 主动补一个边界、等号条件、异常情况、反例或实施风险。这一步最能区分“记住答案”和“真正掌握”。

**75-90 秒：迁移。** 用一句话说明：若题面改动一个关键条件，原方法哪一步仍成立、哪一步必须换工具；若是教学题，则说明怎样把结论转成学生可执行任务或课堂评价指标。

### 10.2 掌握等级

| 等级 | 可观察表现 | 是否建议进入下一题 |
|---|---|---|
| L0 识别 | 看答案后熟悉，但不能独立启动 | 否 |
| L1 启动 | 能说第一工具，但主线仍依赖提示 | 否 |
| L2 独立 | 能完成主解/主回答并自检 | 可以 |
| L3 迁移 | 能处理至少一个追问和一个近迁移变式 | 推荐 |
| L4 教学 | 能设计提示梯度、解释失效边界并在 5-10 分钟内教清楚 | 面试级 |

竞赛教师面试的核心题建议至少达到 **L3**；需要试讲的题建议达到 **L4**。

### 10.3 训练记录模板

每次复习只记录会帮助下一轮决策的数据，而不是写长篇感想：

| 字段 | 记录内容 | 示例 |
|---|---|---|
| `first_move_seconds` | 看到题到说出有效第一步的秒数 | 38 |
| `hint_level` | 0=独立；1=方向；2=关键结构；3=几乎给解 | 1 |
| `mainline_correct` | 主线是否完整正确 | yes/no |
| `boundary_named` | 是否主动指出边界/等号/反例 | yes/no |
| `followup_score` | 本页追问独立完成比例 | 2/3 |
| `teach_back_90s` | 90 秒复述是否连贯 | yes/no |
| `recall_24h` | 24 小时后能否重构第一触发器 | yes/no |

**退出标准**：连续两次 `hint_level=0`，能在 90 秒内讲清主线，且至少完成一个追问或变式，再把本题从“正在学习”移入“维护复习”。否则优先回到卡点所在的小节，不要机械重做整页。
