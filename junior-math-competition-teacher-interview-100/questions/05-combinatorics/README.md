# 第五章  组合数学核心功底

组合题最能暴露是否会建模：分类、计数、一一对应、不变量与极端原理。

## 本章学习目标

- 会设计计数对象与分类
- 掌握抽屉、容斥、递推、不变量、极端
- 证明分类互斥且穷尽/映射双射

## 推荐学习顺序

先完成 Q054-Q065 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。
