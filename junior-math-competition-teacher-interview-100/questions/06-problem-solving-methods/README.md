# 第六章  解题方法论与证明

真正的竞赛能力是方法迁移：化归、构造、特殊化、反证、归纳与逻辑严谨。

## 本章学习目标

- 把技巧升级成元策略
- 明确探索工具和证明工具的边界
- 形成完整性检查习惯

## 推荐学习顺序

先完成 Q066-Q072 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。

## 本章达标标准

- 任取一道题，30 秒内说出第一触发器/第一立场。
- 数学题能独立完成并指出一个边界；教学题能给出动作与评价证据。
- 至少能处理一道追问，不依赖原答案措辞。
- 能把本章任意一道题改造成一个同构变式和一个边界变式。
