# 第七章  试讲与讲题

试讲考的是“学生能否学会”，不是面试者能否把标准答案说完。

## 本章学习目标

- 10分钟内完成目标—问题链—板书—变式闭环
- 会给分层提示
- 能把学生错误转化为教学资源

## 推荐学习顺序

先完成 Q073-Q082 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。

## 本章达标标准

- 任取一道题，30 秒内说出第一触发器/第一立场。
- 数学题能独立完成并指出一个边界；教学题能给出动作与评价证据。
- 至少能处理一道追问，不依赖原答案措辞。
- 能把本章任意一道题改造成一个同构变式和一个边界变式。
