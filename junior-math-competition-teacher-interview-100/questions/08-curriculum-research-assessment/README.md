# 第八章  教研、课程与命题

教研岗要能把散题组织成课程，把错误组织成数据，把测试组织成反馈。

## 本章学习目标

- 会设计课程、诊断、讲义、模拟卷和复盘
- 用数据而非感觉调整教学
- 建立可维护的教研资产

## 推荐学习顺序

先完成 Q083-Q090 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。

## 本章达标标准

- 任取一道题，30 秒内说出第一触发器/第一立场。
- 数学题能独立完成并指出一个边界；教学题能给出动作与评价证据。
- 至少能处理一道追问，不依赖原答案措辞。
- 能把本章任意一道题改造成一个同构变式和一个边界变式。
