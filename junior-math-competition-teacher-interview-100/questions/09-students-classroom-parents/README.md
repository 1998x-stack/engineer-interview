# 第九章  学情、课堂与家长

高水平班课管理的目标，是让不同能力学生都持续思考，同时保持合理预期。

## 本章学习目标

- 先诊断后干预
- 保护不同水平学生的思考机会
- 与家长建立透明且不过度承诺的沟通

## 推荐学习顺序

先完成 Q091-Q096 的主解/主回答；第二轮只看追问；第三轮任选3题做口述或试讲。

## 本章达标标准

- 任取一道题，30 秒内说出第一触发器/第一立场。
- 数学题能独立完成并指出一个边界；教学题能给出动作与评价证据。
- 至少能处理一道追问，不依赖原答案措辞。
- 能把本章任意一道题改造成一个同构变式和一个边界变式。
