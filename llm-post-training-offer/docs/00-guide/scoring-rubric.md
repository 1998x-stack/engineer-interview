# 面试回答评分 Rubric

用同一个 rubric 自评每道题，避免“感觉会了”。

| 级别 | 表现 |
|---|---|
| 1 | 只能说定义或论文名 |
| 2 | 能给核心结论，但解释不出 why |
| 3 | 能写公式/画流程，并解释关键变量 |
| 4 | 能讲 failure mode、工程指标和 ablation |
| 5 | 能把问题映射到自己项目，用约束自然推出算法选择，并能处理反例 |

**高频 20 题目标：L5。其余 80 题目标：至少 L3。**

## V2 · 95 分回答的证据结构

高分回答至少形成一条完整链：**定义 → 公式/机制 → 中间量预测 → failure → 指标 → controlled ablation → scale trade-off → 为什么不选替代方案**。如果缺“中间量预测”和“证伪实验”，即使术语很多也仍然接近背诵。
