# 内容口径与来源方法

本仓库由《剑指 LLM 后训练 Offer：100 道面试题精讲》扩展而来。

- **PDF 原始提要**：保留原 PDF 的题目、核心结论、深入理解、失分点与追问框架。
- **扩展讲义**：结合论文、官方技术报告与工程文档，补充 know-why、know-how、failure mode、ablation 与系统指标。
- **公开真题**：只表示公开面经中出现过该类问题或近似问题；面经是候选人自述，不代表企业官方题库。
- **事实优先级**：论文/官方文档 > 公开实现 > 面经描述 > 经验性推断。

如果某个细节没有被原 PDF 或引用资料明确支持，应把它当作工程建议或推断，而不是“原题标准答案”。

## 使用建议

把本页内容与具体问题文件联动使用：先选一个 Qxxx，按本页模板做白板/实验/项目复盘；记录自己无法回答的变量、指标和反例，再回到对应章节补齐。目标是形成**可迁移的问题解决结构**，而不是增加背诵量。
