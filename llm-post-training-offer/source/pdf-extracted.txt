序言：不要背 100 答案，要建立 10 条推理链
2026 年的大模型后训练面试已经明显从“RLHF / DPO 八股”进入“算法 + 数据 + reward + distributed system + Agent
environment”的联合考察。公开面经里，PPO 的 clip 正负优势、GAE、GRPO 的 token credit、DAPO/GSPO、rollout
长尾、MoE routing mismatch、FSDP/ZeRO、TRL/verl 都已经出现。
因此本书不把题目当孤立知识点。每题按照“面试官为什么问 → 核心结论 → 深入理解 → 常见误区 → 追问”展开，并把题
目放回算法演化链。你应该能够从问题约束自然推出算法，而不是从算法名反推故事。
公开面经属于候选人自述，不是企业官方题库。本书把可验证到的公开题目标为“公开真题”，其余标为“高频 / 推导 / 设
计”，用来覆盖真实面试中的连续追问。
一条高分回答的骨架 Problem → Objective → Data → Reward → Exploration → Credit Assignment
→ Compute/System → Failure Mode → Algorithm Choice → Eval。

第一章 后训练全景与 SFT：先把“训练目标”想清楚
本章目标 完成面试题 1-10。要求不是记忆名词，而是把每个方法与其输入、目标函数、failure mode 和

面试题 01 什么是 Post-Training？为什么 Pretraining 后仍需要后训练？
[高频题] [L1]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：Pretraining 学“哪些 token 在上下文中可能出现”，后训练则把这种通用建模能力塑造成可控行为：指令遵
循、偏好、安全、推理、工具使用与领域适应。
深入理解：把两种目标函数区分开：语言建模是分布拟合，post-training 是行为分布重塑。强 base model 的很多能力已
经存在，后训练经常更像 capability elicitation 与 policy shaping，而非从零注入知识。
常见失分点：不要把 post-training 等同于 RLHF；SFT、偏好优化、RLVR、Agentic RL 都属于后训练。
面试官追问：如果 base model 已经很强，为什么少量高质量 SFT 仍然有效？
面试题 02 SFT 到底在学什么？为什么说它是 behavior cloning？
[高频题] [L1]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：SFT 用目标回答作为唯一轨迹做 teacher forcing，本质是最大化专家轨迹的条件似然。它最擅长输出格式、基
本指令遵循、工具调用语法、风格与 cold-start reasoning。
深入理解：关键局限是它只“模仿看过的轨迹”，不会主动探索训练集没有的解法，也无法自然表达多个候选答案之间的相
对偏好。
常见失分点：把 SFT 说成“让模型更聪明”过于粗糙；应区分能力、行为与分布。
面试官追问：为什么最佳 SFT checkpoint 不一定是最佳 RL initialization？
面试题 03 公开真题：SFT 数据如何筛选和采样？
[公开真题] [L2] · 来源见题尾索引标记与附录
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：按数据工程链路回答：来源治理 → 去重/泄漏 → 正确性 → 指令质量 → 难度 → 多样性 → 格式 → 安全 → 领域配
比 → train/eval 隔离。
深入理解：面试官真正看的是你能否把“数据质量”变成可执行规则。对 reasoning 数据应额外检查最终答案、推理一致
性、长度、语言混用和可验证性。采样可采用 temperature、domain cap、hard-example mining 与 capability-aware
sampling。
常见失分点：只讲“清洗、去重、过滤低质”没有区分度；一定要讲筛选信号和错误样本如何回流。
面试官追问：如果只允许保留 20% SFT 数据，你会依据什么排序？ [I7]

面试题 04 SFT 数据是越多越好吗？如何理解 data quality × diversity × difficulty？
[高频题] [L2]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：不是。大量低质量、重复或过易数据会放大错误梯度、模板化和 verbosity bias，并可能覆盖 base model 原有
能力。
深入理解：有效数据价值更接近“边际训练信号”：正确、非重复、覆盖能力盲区、难度贴近当前 frontier 的样本贡献更
高。对强模型而言，100 万条简单指令可能不如 5 万条高质量 hard cases。
常见失分点：只按 token 数汇报数据规模；忽略数据重复率、错误率和难度分布。
面试官追问：怎么做 data ablation 才能证明“数据质量”而不是训练步数带来的提升？
面试题 05 为什么 SFT 会造成 catastrophic forgetting 或 alignment tax？
[原理推导] [L2]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：因为优化分布从超大规模 pretraining distribution 收缩到较窄的 instruction distribution，梯度会持续推动参
数适配新分布。
深入理解：缓解手段包括较小 LR、pretraining replay、领域混合、参数高效微调、early stopping 和回归评测。所谓
alignment tax 是行为对齐带来的通用能力/某些 benchmark 回退，应通过多目标数据与阶段化训练控制。
常见失分点：只会说“学习率太大”；forgetting 首先是分布与目标的问题。
面试官追问：为什么 replay 一定要有？什么情况下 LoRA 反而限制最终能力？
面试题 06 多领域 SFT 数据应该怎么配比？
[高频题] [L2]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：不应按原始数据量等比例采样，而应围绕业务价值、质量、稀缺性、难度、遗忘风险和当前能力短板设权重。
深入理解：可以将 mixture weight 视作控制训练梯度来源的策略变量；常见方法包括 temperature sampling、上限截断、
curriculum、loss-aware sampling 与分阶段 mixture。
常见失分点：把“英语 50%、中文 50%”当成原则；真正应回答为什么这么配、如何在线调整。
面试官追问：某领域 loss 很高，是该加大权重还是数据质量有问题？如何区分？
面试题 07 为什么 instruction data 需要 prompt diversity，而不只是 response
diversity？
[原理推导] [L1]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：同一意图的多种表达可以降低模板记忆，提高对意图而非表面形式的泛化。
深入理解：一个完善的数据扩增要同时改变措辞、上下文、约束组合、角色、语言和信息缺失方式，并避免 synthetic
paraphrase 造成模式单一。

面试题 08 公开真题：CoT 数据怎么构建、筛选与验证？

面试题 09 为什么 SFT 经常是 RL 的 cold start？DeepSeek-R1-Zero 又为什么可以跳
过？
[原理推导] [L3]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：RL 需要策略在初始分布中能采到非零 reward 轨迹；若几乎全错，梯度信号稀缺。SFT 可把策略移到可探索区
域。
深入理解：但若 base model 足够强、任务可验证且 sampling budget 大，纯 RL 也可能直接激发 reasoning。DeepSeek-
R1-Zero 展示了这种可能，同时也出现可读性与语言混用问题，后续 R1 又引入 cold-start data 与多阶段训练。[P8]
常见失分点：把“必须先 SFT”当成铁律。
面试官追问：什么条件决定 pure RL 能否工作？
面试题 10 SFT、DPO 与 Online RL 应该如何选？
[系统设计] [L3]
面试官为什么问：考察你是否能在信息不完备时做工程权衡：先定义约束和成功指标，再选择算法与系统。
核心结论：SFT 解决“学会目标行为模板”；DPO 解决“离线偏好排序”；Online RL 解决“通过新采样探索并最大化可计

第二章 Preference、Reward Model 与 Reward Design
本章目标 完成面试题 11-20。要求不是记忆名词，而是把每个方法与其输入、目标函数、failure mode

面试题 11 Reward Model 如何训练？Bradley-Terry 假设是什么？
[高频题] [L2]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：对同一 prompt 的 preferred / rejected 输出学习标量 reward，使 r(chosen) > r(rejected)。经典损失是 -log
σ(r_w-r_l)。
深入理解：Bradley-Terry 把偏好概率表示为 reward 差的 logistic 函数；它只约束相对顺序，不要求 reward 是可解释的绝
对分数。
白板公式 L_RM = -log σ(r_w-r_l)
常见失分点：把 RM 输出当“真实质量分”；忽略 calibration 与分布外问题。
面试官追问：如果 preference 出现循环 A>B、B>C、C>A，标量 RM 会发生什么？
面试题 12 公开真题：PPO 中的 Reward Model 数据从哪里来？
[公开真题] [L2] · 来源见题尾索引标记与附录
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：通常由 prompt 上的 policy 多样生成，再由人工或 judge 排序，构造成 preference pairs 训练。
深入理解：RM 数据应覆盖当前 policy 真正会产生的失败模式。policy 演化后，老 RM 可能进入 OOD 区域，出现 reward
extrapolation 与 exploitation，因此需要迭代采样/重训或 ensemble。
常见失分点：只说“人工标注”；不说明 policy distribution。
面试官追问：什么时候应刷新 RM？怎样判断 RM 已经失效？ [I6]
面试题 13 Preference pair 的 margin、难度和 annotator agreement 为什么重要？
[原理推导] [L2]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：winner 与 loser 差距过小会带来高标签噪声；差距过大又可能过于简单。最有价值的是模型容易混淆、但标注
相对可靠的 pair。
深入理解：可用 agreement、judge margin、uncertainty、response similarity 和 difficulty 分层抽样，构建既可靠又能
提供决策边界信号的数据。
常见失分点：只追求“chosen 很好、rejected 很差”，导致训练信号过易。
面试官追问：如何主动挖掘 hard preference pairs？

面试题 14 如何处理不同标注员之间的 preference disagreement？
[系统设计] [L3]
面试官为什么问：考察你是否能在信息不完备时做工程权衡：先定义约束和成功指标，再选择算法与系统。
核心结论：先区分噪声与真实多样偏好。可采用多标注、软标签、置信度、annotator modeling、分群偏好或保留 Pareto
trade-off。
深入理解：若任务本质主观，强行 majority vote 会抹平真实分布；产品应明确是优化平均偏好、特定用户群，还是可个性
化策略。
常见失分点：把 disagreement 一律视作脏数据删除。
面试官追问：如何设计一个既保留多样性又可训练的 preference objective？
面试题 15 Reward Model 为什么会被 policy exploit？
[原理推导] [L3]
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：policy 在做 argmax reward，而 RM 只是有限数据拟合出的 proxy。优化会主动把策略推向 RM 误差最大的尾
部。
深入理解：这可类比 Goodhart's Law：proxy 一旦成为优化目标，就会被利用。缓解包括 online data refresh、ensemble
uncertainty、rule constraints、held-out judge 与 reward cap。
常见失分点：把 reward hacking 当偶然 bug，而不是优化代理目标的系统性风险。
面试官追问：为什么更强的 optimizer 反而可能让 proxy reward 更不可靠？
面试题 16 公开真题：什么是 Reward Hacking？常见类型有哪些？
[公开真题] [L2] · 来源见题尾索引标记与附录
面试官为什么问：考察你是否能把概念放进完整后训练链路，并从目标函数、数据分布与系统约束解释选择，而不是复述论
文摘要。
核心结论：模型最大化 proxy reward，却没有提升真实任务目标。常见有 length/verbosity、format、keyword、
