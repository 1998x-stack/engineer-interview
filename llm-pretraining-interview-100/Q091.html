手写 Multi-Head Attention，面试官真正看什么？

定位：A 类高频真题型 · 难度 中 · 频率 ★★★★★ 章节：手撕、系统设计与项目拷打

1. 面试官为什么问

公开面经高频手撕题，shape 正确比 API 熟练更重要。

这道题真正区分的是：能否把“知道概念”推进到“解释机制、量化成本、落到训练系统并设计验证”。

本题的三层观察镜

  • 正确性：代码/公式/系统是否在边界条件下仍正确？
  • 量化：参数、显存、吞吐、成本是否可手算/实测？
  • 证明：项目贡献是否有对照实验和可归因结果？

2. 30 秒结论

手撕 Attention 的第一原则：每一行代码旁边都知道 tensor shape。

30 秒版本的目标不是覆盖所有细节，而是先给出正确结论 + 最关键因果关系，让面试官知道你掌握主线。

3. 3 分钟标准回答

3.1 核心机制

输入 [B,S,D] 经过 QKV projection，reshape/transposition 为 [B,H,S,D_h]；计算 score=[B,H,S,S]，除 √D_h，加入 causal/padding mask，softmax 后与 V 相乘，再 transpose/reshape 回 [B,S,D] 并做 output projection。

3.2 关键 Trade-off / 边界

面试官通常观察你是否能持续维护 shape、softmax 维度、mask 语义和 contiguous/view 问题，而不是能否背 torch.nn.MultiheadAttention。

核心公式

[B,S,D] → [B,H,S,D_h] → scores [B,H,S,S] → [B,S,D]

面试时不要只写公式。要逐个解释符号、shape/量纲，以及公式如何导出工程结论。

4. 深度展开

PyTorch 参考骨架

class MHA(nn.Module):
    def forward(self, x, mask=None):
        B, S, D = x.shape
        qkv = self.qkv(x).view(B, S, 3, self.h, self.dh)
        q, k, v = qkv.unbind(dim=2)
        q, k, v = [t.transpose(1, 2) for t in (q, k, v)]  # [B,H,S,Dh]
        score = q @ k.transpose(-2, -1) / math.sqrt(self.dh)
        if mask is not None:
            score = score.masked_fill(~mask, float('-inf'))
        p = score.softmax(dim=-1)
        y = (p @ v).transpose(1, 2).contiguous().view(B, S, D)
        return self.out(y)

面试时必须同步说出每一步 shape、mask 广播规则和数值稳定性。

5. Know-how：如何落到实现与训练系统

  1. 动作 1：先在白板逐行标 shape，再写代码。
  2. 动作 2：mask 使用足够负值并考虑 dtype。
  3. 动作 3：为 B=2,S=4,H=2 写最小单元测试。
