# Q001. 手推 Self-Attention：为什么要除以 √d_k？

> **定位**：A 类高频真题型 · 难度 **中** · 频率 **★★★★★**
> 章节：[Transformer 与模型架构](./README.md)

## 1. 面试官为什么问

这道题真正区分的是：**能否把“知道概念”推进到“解释机制、量化成本、落到训练系统并设计验证”**。

- **数学尺度**：公式是否解释了数值尺度、梯度和表示能力？
- **结构成本**：参数量、FLOPs、KV Cache 与 kernel shape 如何变化？

## 2. 30 秒结论

> √d_k 的本质是标准差归一化：让点积 logits 的典型尺度不随 head dimension 爆长。

30 秒版本的目标不是覆盖所有细节，而是先给出**正确结论 + 最关键因果关系**，让面试官知道你掌握主线。

## 3. 3 分钟标准回答

### 3.1 核心机制

给定 X，先做线性投影得到 Q=XW_Q、K=XW_K、V=XW_V，再计算缩放点积注意力。若 q_i、k_i 近似独立、零均值、单位方差，则 q·k 的方差随 d_k 线性增长；维度越大，softmax 输入越容易进入饱和区。

### 3.2 关键 Trade-off / 边界

除以 √d_k 相当于把 logits 的标准差重新压到 O(1) 量级，使 softmax 的熵和梯度尺度更稳定。它不是“为了让概率和为 1”——softmax 本身已经完成归一化。

### 核心公式

```text
Attention(Q,K,V) = softmax(QKᵀ / √d_k)V
```

> 面试时不要只写公式。要逐个解释符号、shape/量纲，以及公式如何导出工程结论。

## 4. 深度展开

### 方差推导
若 $q_i,k_i$ 近似独立、$\mathbb{E}[q_i]=\mathbb{E}[k_i]=0$、$\mathrm{Var}(q_i)=\mathrm{Var}(k_i)=1$，则

$$
\mathrm{Var}(q^\top k)=\mathrm{Var}\left(\sum_{i=1}^{d_k}q_i k_i\right)\approx d_k.
$$

因此标准差约为 $\sqrt{d_k}$。除以 $\sqrt{d_k}$ 后，logit 的典型尺度回到 $O(1)$。面试时要把“方差随维度增长”与“softmax 饱和”连接起来，而不是只背缩放项。

## 5. Know-how：如何落到实现与训练系统

1. **动作 1**：白板先写 Q/K/V 与 tensor shape，再解释方差尺度。
2. **动作 2**：训练中同时监控 attention logits 的 max/RMS 与梯度范数；异常放大常与数值不稳定相关。
3. **动作 3**：进一步联系 QK-Norm：它直接约束 Q/K 的范数，是更强的 logit-scale 稳定手段。

### 架构 Ablation

固定训练 Token 与大部分 recipe，只改变目标组件；同时比较 validation loss、下游能力、训练稳定性、参数/FLOPs 与推理成本。

- 不要只比较最终 benchmark；记录收敛速度。
- 至少做等参数或等 FLOPs 对照。
- 改变 head/hidden 等 shape 时同时检查 kernel efficiency。

## 6. 高频追问与回答方向

### 追问 1：为什么不是除以 d_k？

**回答方向**：从方差与标准差区分：点积方差约为 d_k，因此要除以标准差 √d_k；除以 d_k 会过度压缩 logits。

### 追问 2：如果 head dimension 从 64 改到 256，会发生什么？

**回答方向**：说明 logit 方差、kernel shape 与 head 数的联动；保持 hidden size 时 head dimension 变化还会改变 head count。

### 追问 3：BF16 下 attention logit 过大时你会看哪些指标？

**回答方向**：从 exponent range、overflow/underflow、accumulation dtype 与敏感算子保留高精度回答。
