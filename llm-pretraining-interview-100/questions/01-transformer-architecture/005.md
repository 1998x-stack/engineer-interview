# Q005. RMSNorm 与 LayerNorm 的区别是什么？

> **定位**：A 类高频真题型 · 难度 **易** · 频率 **★★★★★**
> 章节：[Transformer 与模型架构](./README.md)

## 1. 面试官为什么问

高频基础题，同时能追到数值稳定、参数和 kernel 实现。

这道题真正区分的是：**能否把“知道概念”推进到“解释机制、量化成本、落到训练系统并设计验证”**。

### 本题的三层观察镜

- **数学尺度**：公式是否解释了数值尺度、梯度和表示能力？
- **结构成本**：参数量、FLOPs、KV Cache 与 kernel shape 如何变化？
- **生命周期**：训练架构选择会如何影响推理成本？

## 2. 30 秒结论

> RMSNorm 保留“控制尺度”，放弃“强制零均值”。

30 秒版本的目标不是覆盖所有细节，而是先给出**正确结论 + 最关键因果关系**，让面试官知道你掌握主线。

## 3. 3 分钟标准回答

### 3.1 核心机制

LayerNorm 对特征做去均值再除以标准差；RMSNorm 不减均值，只按均方根缩放。RMSNorm(x)=x/√(mean(x²)+ε)·γ。

### 3.2 关键 Trade-off / 边界

RMSNorm 省掉 mean-centering，计算路径更简单，在现代 LLM 中被大量采用。关键不是“少一个减法”，而是很多 Transformer residual stream 并不依赖显式去均值也能稳定训练。

### 核心公式

```text
RMS(x)=√(mean(x²)+ε),  y=x/RMS(x)·γ
```

> 面试时不要只写公式。要逐个解释符号、shape/量纲，以及公式如何导出工程结论。

## 5. Know-how：如何落到实现与训练系统

1. **动作 1**：手写时使用 mean(x²)，不能误用 std。
2. **动作 2**：归一化通常用更高精度累积，尤其在低精度训练中。
3. **动作 3**：检查 epsilon、weight dtype、fused kernel 与张量布局。

### 架构 Ablation

固定训练 Token 与大部分 recipe，只改变目标组件；同时比较 validation loss、下游能力、训练稳定性、参数/FLOPs 与推理成本。

- 不要只比较最终 benchmark；记录收敛速度。
- 至少做等参数或等 FLOPs 对照。
- 改变 head/hidden 等 shape 时同时检查 kernel efficiency。
