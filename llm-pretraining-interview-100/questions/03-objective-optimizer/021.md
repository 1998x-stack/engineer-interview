# Q021. Causal LM Loss 是什么？为什么 Next-Token Prediction 能学出复杂能力？

> **定位**：B 类等价追问题 · 难度 **中** · 频率 **★★★★★**
> 章节：[目标函数、Optimizer 与 Training Recipe](./README.md)

## 2. 30 秒结论

> Next-token objective 的强大之处在于把几乎所有文本位置都变成训练信号。

30 秒版本的目标不是覆盖所有细节，而是先给出**正确结论 + 最关键因果关系**，让面试官知道你掌握主线。

## 3. 3 分钟标准回答

### 3.1 核心机制

标准 causal LM 最大化每个 token 在历史条件下的似然，等价于最小化 cross-entropy。训练信号覆盖几乎每个位置，因此海量原始文本都能直接成为监督。

### 3.2 关键 Trade-off / 边界

为了降低条件预测误差，模型必须压缩语法、语义、事实关系、代码结构和隐含状态等统计规律。所谓 reasoning 能力不能简单解释为“loss 神奇地产生了推理”，更准确是规模、数据与训练使模型学到支持多步预测的内部计算结构。

### 核心公式

```text
L = -Σ_t log p_θ(x_t | x_<t)
```

> 面试时不要只写公式。要逐个解释符号、shape/量纲，以及公式如何导出工程结论。

## 5. Know-how：如何落到实现与训练系统

1. **动作 1**：区分 token-averaged loss 与 sequence/sample weighting。
2. **动作 2**：注意 padding、packing、特殊 token 是否参与 loss。
3. **动作 3**：按 domain 分解 validation cross-entropy，避免总体 loss 掩盖能力。

### 优化曲线实验

保持模型与数据固定，比较 LR/batch/optimizer 变体的 token-normalized loss、grad norm、更新范数和稳定性。

- 以 consumed tokens 而非 step 对齐。
- 记录 effective batch tokens。
- 避免只看最终 loss 而忽略 wall-clock。
