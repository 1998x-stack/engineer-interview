# Q053. Activation Memory 和 Parameter Memory 谁更大？

> **定位**：B 类等价追问题 · 难度 **中** · 频率 **★★★★★**
> 章节：[显存、数值精度与性能](./README.md)

## 1. 面试官为什么问

考察动态显存随 batch/sequence/depth 的增长。

这道题真正区分的是：**能否把“知道概念”推进到“解释机制、量化成本、落到训练系统并设计验证”**。

### 本题的三层观察镜

- **bytes**：每种 state/activation 实际占多少字节？
- **IO**：瓶颈是计算还是 HBM/网络搬运？
- **峰值**：steady-state memory 与 transient peak 是否分开？

## 2. 30 秒结论

> 显存瓶颈是配置函数：参数规模决定底座，B×S×H×L 决定 activation 压力。

30 秒版本的目标不是覆盖所有细节，而是先给出**正确结论 + 最关键因果关系**，让面试官知道你掌握主线。

## 3. 3 分钟标准回答

### 3.1 核心机制

没有统一答案。Parameter states 主要随参数 N 增长；activation 则大体随 microbatch B、sequence S、hidden H、layers L 增长，并受 Attention/MLP 中间张量与 checkpointing 强烈影响。

### 3.2 关键 Trade-off / 边界

长上下文或大 microbatch 下 activation 可能成为主导；大参数、小 batch 时 optimizer/model states 更突出。面试应先问配置，再判断瓶颈。

## 4. 深度展开：从定义走向 Production

本题的深挖重点是：**显存瓶颈是配置函数：参数规模决定底座，B×S×H×L 决定 activation 压力。**
