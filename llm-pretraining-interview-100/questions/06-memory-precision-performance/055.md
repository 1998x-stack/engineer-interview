# Q055. 为什么 BF16 通常比 FP16 更适合 LLM 预训练？

> **定位**：A 类高频真题型 · 难度 **易** · 频率 **★★★★★**
> 章节：[显存、数值精度与性能](./README.md)

## 1. 面试官为什么问

考察浮点格式与 overflow/underflow。

这道题真正区分的是：**能否把“知道概念”推进到“解释机制、量化成本、落到训练系统并设计验证”**。

### 本题的三层观察镜

- **bytes**：每种 state/activation 实际占多少字节？
- **IO**：瓶颈是计算还是 HBM/网络搬运？
- **峰值**：steady-state memory 与 transient peak 是否分开？

## 2. 30 秒结论

> BF16 的优势是 FP32 级 exponent range，用精度换更安全的动态范围。

30 秒版本的目标不是覆盖所有细节，而是先给出**正确结论 + 最关键因果关系**，让面试官知道你掌握主线。

## 3. 3 分钟标准回答

### 3.1 核心机制

BF16 与 FP32 都有 8-bit exponent，因此动态范围接近 FP32；FP16 exponent 只有 5 bit，虽然 mantissa 更精细，但更容易在大范围梯度/activation 中 overflow。

### 3.2 关键 Trade-off / 边界

LLM 训练通常更看重动态范围而非额外尾数精度，因此 BF16 更省去繁琐 loss scaling。但关键算子仍可能需要 FP32 accumulation。
