# Q093. 手写 RMSNorm：最常见错误是什么？

## 2. 30 秒结论

> RMSNorm = RMS 尺度归一化，不做中心化。

30 秒版本的目标不是覆盖所有细节，而是先给出**正确结论 + 最关键因果关系**，让面试官知道你掌握主线。

## 3. 3 分钟标准回答

### 3.1 核心机制

RMSNorm 计算 mean(x²) 的平方根，不减均值，也不是 x.std()。通常在最后一维归一化，再乘可学习 scale γ。

### 3.2 关键 Trade-off / 边界

低精度实现常把平方和/mean 转到 FP32 累积，再 cast 回输入 dtype，以降低 reduction 误差。

### 核心公式

```text
y = x / √(mean(x²)+ε) · γ
```

> 面试时不要只写公式。要逐个解释符号、shape/量纲，以及公式如何导出工程结论。

## 4. 深度展开

### RMSNorm 最小实现
```python
def rms_norm(x, weight, eps=1e-6):
    rms = x.float().pow(2).mean(dim=-1, keepdim=True).add(eps).rsqrt()
    y = x * rms.to(x.dtype)
    return y * weight
```
关键点：RMS 不是 standard deviation；是否在 FP32 中计算平方均值是一个数值实现选择。
