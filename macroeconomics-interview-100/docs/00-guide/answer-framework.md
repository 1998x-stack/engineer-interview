# 统一的 6 层回答法

| 层级 | 面试动作 |
|---|---|
| 1. Definition | 20 秒内准确下定义，划清概念边界 |
| 2. Equation / Graph | 给最小必要方程或图，不堆公式 |
| 3. Mechanism | 用“冲击 → 中间变量 → 行为 → 结果”讲因果链 |
| 4. Comparative Statics | 改变一个条件，说明结论如何变化 |
| 5. Assumption & Limitation | 主动说明结论依赖什么、模型遗漏什么 |
| 6. Reality | 映射到现实数据，并说明还需要什么证据 |

## 90 秒节奏

- **0-15 秒：** 直接给结论与定义。
- **15-35 秒：** 写/说出核心方程或图形。
- **35-70 秒：** 完成主机制链。
- **70-90 秒：** 主动补一个成立条件、限制或现实映射。

第一轮不要把所有知识倾倒出来。高质量面试答案应当“信息密度高、边界清楚、给追问留接口”。
