# Question Markdown 规范

每个 `qXXX-*.md` 必须包含：

1. YAML Front Matter：题号、模块、难度、PDF 页码、标签。
2. `这道题真正考什么`。
3. `90 秒标准作答（PDF 原稿）`。
4. `核心公式 / 结构`。
5. `深挖解析（PDF 原稿）`。
6. `专业扩展`：机制、假设、边界。
7. `教授追问与参考答题路径`。
8. `常见失分点`。
9. `举一反三 / 迁移训练`。
10. `面试评分 Rubric`。
11. `关联题目`。
12. `资料与来源`。

新增题目时请保持结构一致，以便脚本与网站导航正常工作。
