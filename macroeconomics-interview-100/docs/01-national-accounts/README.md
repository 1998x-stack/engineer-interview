# PART 01｜国民收入核算与宏观数据

> **范围：** GDP、GNI、CPI、实际与名义变量、储蓄投资恒等式

先把“生产了什么、在哪里生产、谁取得收入、价格怎样变化”分清楚。所有后续短期模型中的 Y 都建立在这一核算口径之上。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
