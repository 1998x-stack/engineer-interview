# PART 02｜凯恩斯交叉与乘数

> **范围：** 收入决定、计划支出、存货、财政乘数、自动稳定器

聚焦短期固定价格框架：计划支出怎样决定产出，非计划存货怎样触发调整，财政冲击怎样通过收入—支出循环放大。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
