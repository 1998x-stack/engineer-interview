# PART 03｜IS-LM 与政策组合

> **范围：** 产品市场、货币市场、挤出、流动性陷阱、现代利率规则

把产品市场与货币/金融条件联合起来，训练“曲线移动—均衡变化—斜率决定政策强弱—现代央行操作框架”的完整链条。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
