# PART 04｜AD-AS、通胀、失业与周期

> **范围：** 总需求、总供给、Phillips 曲线、预期、奥肯定律

把价格水平内生化，区分需求冲击与供给冲击，并把产出缺口、通胀、失业和预期放进同一短中期分析框架。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
