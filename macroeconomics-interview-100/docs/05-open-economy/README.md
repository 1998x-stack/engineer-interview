# PART 05｜开放经济与汇率

> **范围：** 实际汇率、净出口、J 曲线、Mundell-Fleming、不可能三角

任何开放经济题先声明汇率定义，再判断汇率制度与资本流动程度；政策效果取决于制度约束，不能把封闭经济结论直接照搬。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
