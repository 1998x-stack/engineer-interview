# PART 06｜长期增长

> **范围：** Solow、黄金律、收敛、技术进步、人力资本与内生增长

核心是区分“提高产出水平”和“永久提高增长率”。稳态、资本边际报酬递减、技术进步和制度/人力资本是高频追问入口。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
