# PART 07｜现代宏观与预期

> **范围：** 跨期消费、投资、RBC、新凯恩斯、Taylor Rule、DSGE

从静态关系升级到跨期优化、预期与微观基础。面试重点不是堆模型名，而是说明预期、名义摩擦和政策规则为何改变传统结论。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
