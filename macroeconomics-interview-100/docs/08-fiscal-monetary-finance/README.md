# PART 08｜财政、债务、货币与金融传导

> **范围：** 债务动态、QE、信贷渠道、银行、房地产、债务通缩

把政策工具与资产负债表连接起来：利率只是传导链的一环，银行资本、抵押品、债务可持续性和金融反馈会显著改变宏观效果。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
