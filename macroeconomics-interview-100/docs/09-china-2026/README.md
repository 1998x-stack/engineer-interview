# PART 09｜2026 中国宏观热点

> **范围：** 增长目标、物价、消费、房地产、地方财政、政策组合

热点题必须坚持“事实—诊断—模型—政策—风险”五步法，避免只复述政策语言或只报数据。数据有时效性，结论必须带日期。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
