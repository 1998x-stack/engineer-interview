# PART 10｜研究能力与压力面试

> **范围：** 因果识别、VAR、政策评估、预测框架、英文表达、综合答题

考察从理论走向研究：相关与因果、识别假设、可证伪预测、模型选择、英文压缩表达。优秀答案要能说明“什么证据会让我改变结论”。

## 本模块训练目标

- 不看材料时能说出核心定义、方程和图形。
- 能把一个冲击写成完整机制链，而不是背“曲线左移/右移”。
- 能在考官改变一个假设后立即重算方向。
- 至少能把 2 道题连接到其他模块，形成模型网络。
