# 附录 A｜高频公式表

| 主题 | 核心式 | 面试提醒 |
|---|---|---|
| 国民收入 | $Y=C+I+G+NX$ | 先确认每项是否为“本国当期最终生产” |
| 名义-实际 | $(1+g_N)=(1+g_R)(1+\pi)$ | 小变化时 $g_N\approx g_R+\pi$ |
| 乘数 | $k_G=1/(1-c),\;k_T=-c/(1-c)$ | 税、进口、价格和利率会削弱简单乘数 |
| 货币市场 | $M/P=L(Y,r)$ | $P$ 上升会降低实际货币余额 |
| Fisher | $r\approx i-\pi^e$ | 低通胀可提高实际利率 |
| Phillips | $\pi=\pi^e-\beta(u-u_n)+v$ | 预期和供给冲击会移动曲线 |
| Solow | $\Delta k=sf(k)-(n+g+\delta)k$ | 稳态不是总量零增长 |
| 黄金律 | $MPK=n+g+\delta$ | 目标是最大化稳态消费 |
| 实际汇率 | $q=eP^*/P$ | 必须先声明汇率定义 |
| 债务动态 | $\Delta d\approx(r-g)d-primary\ surplus$ | 关注 $r-g$ 与初级余额 |
| Taylor Rule | $i=r^*+\pi+a(\pi-\pi^*)+b(y-y^*)$ | 政策规则的基准表达 |
| 数量方程 | $MV=PY$ | 长期约束不等于短期一比一 |

## 使用原则

公式只用于压缩结构。任何公式必须能回答三件事：**变量是什么、方向是什么、成立条件是什么**。
