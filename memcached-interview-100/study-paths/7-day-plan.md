# 7 天冲刺计划

| 日期 | 范围 | 目标 |
|---|---|---|
| Day 1 | 001-020 | 基础 + Item + SET/GET；白板画 `set foo bar` 主调用链。 |
| Day 2 | 021-040 | Slab + Assoc；手写 Class/Page/Chunk 与 `h_next`/LRU 指针图。 |
| Day 3 | 041-060 | LRU/TTL + Worker/Lock/Protocol；理解 strict LRU 在高 QPS 下为何昂贵。 |
| Day 4 | 061-080 | 一致性哈希 + 缓存工程；口述节点故障、击穿、雪崩、Hot Key。 |
| Day 5 | 081-100 | 监控 + 高级特性 + 系统设计；完成百万 QPS 设计题。 |
| Day 6 | 必刷复盘 | 只刷 ⭐ 题；每题 90 秒回答 + 两轮追问。 |
| Day 7 | 模拟面试 | 随机 20 题 + 2 道设计题；答案必须包含“机制 + 取舍 + 生产影响”。 |

## 每天的完成标准

- 能在无资料状态下给出 30-90 秒答案。
- 能画出至少一张数据结构/调用链图。
- 能指出一个典型错误答案。
- 能设计一个最小实验验证结论。
