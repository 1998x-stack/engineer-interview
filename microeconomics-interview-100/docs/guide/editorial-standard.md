# 题目 Markdown 专业标准

每一道题不是“知识点摘要”，而是一份可独立用于模拟面试的训练单元。

## 必需层次

1. **定位**：面试官为什么问；
2. **快速答案**：20–30 秒形成结论；
3. **标准展开**：约 3 分钟机制说明；
4. **数学**：核心公式、FOC/KKT/均衡/IC/反事实；
5. **边界**：哪些假设改变会使结论失效；
6. **识别**：现实数据如何区分竞争性机制；
7. **追问**：至少一次改变参数、一次改变模型结构；
8. **错误诊断**：指出错误发生在定义、推导、均衡、比较静态还是识别；
9. **迁移**：换行业后仍能使用同一机制；
10. **Advanced Deep Dive**：研究生级推导、可证伪预测、Evidence Matrix 与研究边界。

## 内容质量规则

- 公式必须解释变量、单位与成立条件；
- 图必须对应一个明确经济命题；
- 模型预测与事实结论必须分开；
- “前后变化”不得未经论证直接称为因果效应；
- IO/损害题必须明确 but-for；
- 信息问题必须明确谁知道什么以及信息时序；
- 动态或一般均衡问题应说明静态局部结论的限制；
- 来源不明的公开面经不得标为官方逐字真题。

## Mastery 标准

“稳定掌握”至少意味着：能无提示给出短答、白板推导、回答三次追问、指出一个边界、提出一项识别证据并完成陌生场景迁移。
