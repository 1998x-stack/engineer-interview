# 如何使用这套题库

这不是 100 个“标准答案”，而是一个面试表现训练系统。目标是把知识从 recognition 推进到 recall、explanation、application 和 transfer。

## 每题四轮

1. **30 秒**：只看题目，结论 → 机制 → 条件。
2. **3 分钟**：写一个关键公式/图，完整讲模型。
3. **追问**：遮住答案，连续回答至少 2 个变式。
4. **迁移**：换行业、换参数或换信息结构，重新建模。

## 什么时候算掌握

- 能脱离材料复述核心机制；
- 能解释公式每一项而不是背公式；
- 条件变化后会更新结论；
- 能说出一个反例或模型失效条件；
- Case 题能提出最小数据集或识别策略。

## 面试表达模板

> **结论**：在标准 X 假设下，我预计 A。  
> **机制**：因为 B 改变了 C 的边际条件/均衡约束。  
> **边界**：如果 D 不成立，方向可能变化。  
> **验证**：我会用 E 数据/反事实区分替代解释。
