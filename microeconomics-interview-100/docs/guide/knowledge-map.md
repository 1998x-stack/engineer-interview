# 知识地图

主干逻辑：

```text
偏好/目标
  ↓
约束与信息
  ↓
边际决策
  ↓
个体最优
  ↓
战略互动
  ↓
市场均衡
  ↓
福利与分配
  ↓
政策/行为反事实
  ↓
因果识别与证据
```

## 三条贯穿全书的桥

1. **最优化桥**：MRS / MR=MC / IC / best response 都是“边际上不能再改进”的不同形式。
2. **均衡桥**：个人最优必须彼此兼容，价格或策略是内生结果。
3. **反事实桥**：应用微观最终问的不是“发生了什么”，而是“如果关键行为/政策没有发生会怎样”。


## 从 100 题到 8 个可复用算子

1. **Optimize**：给定约束找最优选择；
2. **Equilibrate**：让个体最优彼此兼容；
3. **Differentiate**：改变一个参数做 comparative statics；
4. **Decompose**：把总效应拆成替代/收入、成本/需求、静态/动态等渠道；
5. **Internalize**：判断外部性、所有权或合并如何改变边际激励；
6. **Incentivize**：在信息不对称下写 IC/IR；
7. **Counterfact**：明确 actual 与 but-for；
8. **Identify**：说明什么数据变化能把结构参数或因果效应识别出来。
