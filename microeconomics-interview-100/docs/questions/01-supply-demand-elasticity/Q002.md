# Q002 · 手机价格可能受到哪些供给和需求因素影响？

> **模块**：供给、需求与弹性  
> **难度**：★★  
> **来源标注**：Bates White 官方 case 衍生  
> **核心 20**：否

## 1. 面试官为什么问这题

这道题不是只检查定义，而是检查你能否沿着 **观察 P/Q → 写供需 → 定位 shifter → 比较静态 → 构造反事实 → 寻找识别证据** 的路径，把一个口头问题转化为可验证的微观经济模型。商业 brainstorming 只有在映射到需求或供给 shifter 后才具有经济含义。进一步可把成本拆为边际成本与固定成本：前者更直接影响短期价格/数量，后者在竞争市场短期未必改变供给。

**前置知识**：供给与需求曲线; 市场均衡; 百分比变化。

## 2. 30 秒回答

> 按供给侧、需求侧和共同宏观冲击分类；每个因素必须说明移动哪条曲线以及预期的价格/数量方向。

一个好的 30 秒版本应包含三件事：**先给结论、再给机制、最后加条件/边界**。不要在开头堆背景知识。

## 3. 3 分钟标准展开

1. 供给：芯片、屏幕、电池、工资、物流、汇率、生产率。
2. 需求：收入、替代品价格、质量、品牌偏好、人口结构、换机周期。
3. 宏观变量可能同时影响两侧，不能机械归类。
4. 高分回答最后说明如何用销量、成本数据和事件研究验证。

### 更专业的组织方式

1. **定义对象与选择变量**：先说清楚谁在选择什么，哪些变量是外生条件，哪些是均衡结果。
2. **写出最小模型**：只保留解释本题所需的方程/约束，避免过度建模。
3. **做边际或均衡推理**：说明为什么最优条件、best response 或市场清算条件给出该结论。
4. **给 comparative statics**：改变题目中的关键参数，预测价格、数量、福利或策略如何变。
5. **说出边界**：指出一个会使结论失效或需要修改的假设。

## 4. 白板公式与推导路线

**PDF 核心公式：**

```text
P*=P*(X_d,X_s)
```

白板上建议按以下顺序写：

- **Step A｜原始条件**：写目标函数/供需/预算/收益/信息结构中最关键的一条。
- **Step B｜最优或均衡条件**：使用 FOC、市场清算、best response、IC/IR 或反事实定义。
- **Step C｜方向判断**：只对题目真正改变的参数做 comparative statics。
- **Step D｜解释符号**：把数学结果翻译回经济机制，而不是让公式停在白板上。

> 面试提示：如果完整推导超过 90 秒，先说结论和关键等式，再询问面试官是否希望继续展开代数。

## 5. 模型假设与边界

- **Ceteris paribus**：必须明确哪些条件被固定，否则“相关性”容易被误称为因果机制。
- **内点与边界**：一阶条件通常只描述内点；角点、容量、离散选择或不可逆约束可能使等式失效。
- **时间尺度**：短期与长期的可调整变量不同，弹性、成本和进入退出都会改变。
- **市场/信息结构**：price-taking、market power、可观察性、承诺与时序改变时，结论往往需要重做。

**本题特别要记住：** 商业 brainstorming 只有在映射到需求或供给 shifter 后才具有经济含义。进一步可把成本拆为边际成本与固定成本：前者更直接影响短期价格/数量，后者在竞争市场短期未必改变供给。

## 6. 数据与识别视角

数据上优先同时观察价格、数量和外生 shifter；若价格是均衡内生变量，避免把简单相关关系解释成结构需求/供给。

如果这是经济咨询/研究岗位，建议主动补一句：**“我会先明确需要识别的结构参数或反事实，再决定需要什么数据，而不是先跑回归再解释。”**

可采用的最小证据清单：

- outcome：本题关心的价格、数量、利润、福利或策略结果；
- shifter：理论上只移动某一侧/某一约束的外生变化；
- benchmark：没有政策/行为时的可比组、历史期或结构模型预测；
- robustness：替代定义、替代样本、共同趋势/成本冲击、安慰剂检验等。

## 8. 高频错误与修正

- **只做商业 brainstorm，没有经济结构。**  
  **修正方向**：供给：芯片、屏幕、电池、工资、物流、汇率、生产率。  
  再说明错误具体破坏了定义、最优条件、比较静态还是反事实中的哪一步。
- **说“广告使价格上涨”却不解释需求移动。**  
  **修正方向**：需求：收入、替代品价格、质量、品牌偏好、人口结构、换机周期。  
  再说明错误具体破坏了定义、最优条件、比较静态还是反事实中的哪一步。
- **忽略替代品和成本传导。**  
  **修正方向**：宏观变量可能同时影响两侧，不能机械归类。  
  再说明错误具体破坏了定义、最优条件、比较静态还是反事实中的哪一步。

### 一个额外的高级错误

- **把模型结论当作事实结论。** 正确表达应是：“在 X、Y、Z 假设下模型预测 A；现实判断还需验证这些假设和反事实。”

## 14. Advanced Deep Dive｜研究生级深化

### 14.1 这道题在微观理论中的位置

把市场写成均衡条件 $F(P;X,Z)=Q_d(P,X)-Q_s(P,Z)=0$。只要局部稳定且 $F_P<0$，就可用隐函数定理研究需求/供给 shifter 对均衡价格和数量的影响；这比“画箭头”更严格，也能直接连接识别问题。

**本题的额外关键点：** 把商业因素映射成参数变化：芯片单价更接近边际成本 shifter，品牌广告可能移动需求，研发固定投入主要改变利润与长期进入而未必立刻改变短期 MC。这个分类能显著提升 case interview 的结构感。

### 14.2 从公式到经济机制：严格推导路线

本题的核心表达是：

```text
P*=P*(X_d,X_s)
```

从 $F(P;θ)=0$ 出发，对参数 $θ$ 微分：$dP^*/dθ=-F_θ/F_P$。方向判断来自分子代表哪一侧移动、分母代表均衡稳定性。

把它用于本题时，建议按以下顺序推进：

1. 供给：芯片、屏幕、电池、工资、物流、汇率、生产率。
2. 需求：收入、替代品价格、质量、品牌偏好、人口结构、换机周期。
3. 宏观变量可能同时影响两侧，不能机械归类。
4. 高分回答最后说明如何用销量、成本数据和事件研究验证。

然后做三个检查：

- **符号检查**：结论的正负方向是否与经济直觉一致；
- **单位检查**：弹性、margin、价格、数量、效用或概率是否混用了不同量纲；
- **边界检查**：角点、容量、非凸性、信息约束、进入退出或长期调整是否会改变一阶条件。

### 14.3 图形 / 几何 / 状态空间直觉

优先画同一坐标系下的旧/新供需曲线，并同时标出 $P^*,Q^*$。若同时存在两侧冲击，不要凭价格方向强行识别；把“方向可判定”和“幅度/来源可识别”分开。

针对 **Q002**，画图时不要只画最终曲线；至少标出：

1. **baseline / before**；
2. **shock / policy / strategic change**；
3. **new equilibrium / optimum**；
4. 若是因果或损害题，再画 **but-for**，并明确 actual 与 but-for 的差不是自动因果。

> 白板原则：图形必须服务于一个命题。每画一条线，都能回答“它由哪个假设决定、移动代表什么、数据里对应什么”。

### 14.4 可证伪预测与 comparative statics

一个专业答案不止给方向，还要给“什么现象会推翻我的解释”。对本题，可以围绕以下层次展开：

- **一阶预测**：按照 `P*=P*(X_d,X_s)`，关键参数变化应使最优选择/均衡变量出现可解释方向；
- **二阶预测**：响应幅度应随弹性、曲率、margin、网络规模、风险厌恶或信息结构而变化；
- **异质性预测**：不同消费者、企业、市场或 type 的响应不必相同；
- **反证**：如果数据中的符号、时间顺序或受影响群体完全不符合机制，应降低对该解释的置信度。

### 14.5 实证识别 / 咨询分析怎么落地

实证上要区分结构需求/供给曲线与均衡点云。价格通常内生，识别需要一侧的排除变量、制度冲击、成本 shifter、自然实验或结构模型。

对这道题，推荐先写一个最小 **Evidence Matrix**：

| 层次 | 要回答的问题 | 典型证据 | 主要风险 |
|---|---|---|---|
| 机制 | 理论渠道是否存在？ | 制度、合同、成本/需求变量 | 只讲故事 |
| 方向 | 结果方向是否符合模型？ | 价格、数量、份额、行为 | 共同冲击 |
| 因果 | 变化是否由目标因素引起？ | IV、事件、DID、结构模型、自然实验 | 内生性/选择 |
| 反事实 | 没有该行为会怎样？ | benchmark、控制组、预测模型 | benchmark 不可比 |
| 稳健性 | 替代解释能否排除？ | placebo、替代样本/定义、敏感性 | specification search |

对于面试，不需要机械罗列所有方法；选择**最贴近本题识别困难的一种**，并说明 exclusion / parallel trends / functional form 等核心假设。

### 14.6 高阶追问：把“会答”升级成“会研究”

- **若芯片价格涨但手机价格没变，可能为什么？**：先回到核心条件 `P*=P*(X_d,X_s)`，再判断需要放松哪一个假设；最后给出可观察预测。
- **竞争更激烈会如何改变成本传导？**：先回到核心条件 `P*=P*(X_d,X_s)`，再判断需要放松哪一个假设；最后给出可观察预测。
- **如何估计电池成本上涨的 pass-through？**：先回到核心条件 `P*=P*(X_d,X_s)`，再判断需要放松哪一个假设；最后给出可观察预测。

再追加两个研究级问题：

- **如果把当前静态模型改成动态模型，哪些状态变量需要加入？** 例如库存、学习、进入退出、声誉、网络规模、未来政策或资产价值。
- **如果允许异质性，平均效应是否仍有政策意义？** 说明哪些群体/企业可能有不同弹性、成本、约束或信息。

### 14.7 面试语言升级

不要说“价格涨说明需求增加”；说“在单一冲击且其他条件不变时，$P$ 与 $Q$ 的联合方向可用于初步诊断，但因果识别仍需 shifter”。

针对本题，一个更专业的收束句可以是：

> “我的结论是在明确的行为与市场假设下得到的。下一步我会用 `P*=P*(X_d,X_s)` 对应的可观察预测去区分替代机制，并把最终判断表述为相对于一个可辩护反事实的条件化结论。”

### 14.8 研究级边界：哪些情况下需要换模型？

- 当核心选择是**离散**而非连续时，简单 FOC 可能不够；
- 当存在**容量、不可逆投资或动态状态变量**时，静态比较静态可能误导；
- 当存在**多产品、多市场或一般均衡反馈**时，局部单市场结论可能不成立；
- 当信息结构改变时，需要从完全信息模型切换到 **Bayesian / signaling / screening / contract** 框架；
- 当目标是政策或诉讼中的因果结论时，必须单独论证 **identification**，不能用理论模型替代证据。

**对 Q002 最重要的边界提醒：** 商业 brainstorming 只有在映射到需求或供给 shifter 后才具有经济含义。进一步可把成本拆为边际成本与固定成本：前者更直接影响短期价格/数量，后者在竞争市场短期未必改变供给。
