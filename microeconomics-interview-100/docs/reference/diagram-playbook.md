# 白板图形 Playbook

## 1. Supply–Demand

必须同时标旧/新均衡、曲线 shifter 与 P/Q 方向。税收画 wedge；价格管制画 shortage/surplus。

## 2. Consumer

预算线 + 无差异曲线。价格变化可画 pivot；收入变化平移。Slutsky/Hicks 分解需标补偿束。

## 3. Firm

P/MR/MC/AVC/AC。短期关停与长期退出分开。

## 4. Monopoly / IO

D/MR/MC 适合单产品；差异化多产品更适合 diversion/ownership network 和 actual-vs-but-for。

## 5. Game Theory

payoff matrix、best response curves、game tree。动态题必须画顺序。

## 6. Welfare

画 wedge 和被挤掉的边际交易，标 consumer/producer/government/externality components。

## 7. Information

风险画凹效用；screening/signaling 画 type-specific indifference curves；合同题标 IC/IR。
