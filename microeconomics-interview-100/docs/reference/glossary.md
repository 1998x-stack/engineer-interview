# 微观经济学面试术语表

- **Comparative statics**：比较参数变化前后的均衡/最优，不必描述完整动态路径。
- **Counterfactual / but-for**：如果关键事件没有发生，本来会出现什么结果。
- **Endogeneity**：解释变量与结构误差相关，使简单相关不能解释为因果/结构参数。
- **Marginal condition**：最优点附近，增加一单位行动带来的边际收益与边际成本的关系。
- **Best response**：给定其他玩家策略时，某玩家的最优策略集合。
- **IC**：incentive compatibility，类型/代理人愿意选择制度设计者希望其选择的行动/合同。
- **IR / participation constraint**：参与机制至少不差于 outside option。
- **Pass-through**：成本/税变化向最终价格传导的幅度。
- **Diversion ratio**：某产品流失顾客中转向另一产品的比例。
- **DWL**：相对有效率基准消失的总剩余，不把纯转移误算为损失。
