# 来源与方法

## 题目来源分级

- **官方 case 衍生**：公开经济咨询公司 case 的问题结构经过中文改写和扩展；不声称逐字转载。
- **公开面经题型**：来自公开候选人报告，只证明“该题型曾被报告出现”，不等同于公司官方确认。
- **经典高仿真面试题**：由标准微观理论、公开大学考试结构与真实岗位能力要求重新设计。

## 内容原则

- 公式与标准理论用原创解释，不长篇复制教材。
- 官方案例只用于校准问题风格和可公开核验的 case 结构。
- 对反垄断规则等会变化的制度内容，优先链接官方现行材料；面试前仍应再次核验最新版本。
