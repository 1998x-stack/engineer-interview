# 统一答题框架

网络安全面试最稳定的高分结构是：

```text
定义 -> 原理 -> 成立条件 -> 真实影响 -> 证据 -> 根因修复 -> 纵深防御 -> 验证 -> 追问
```

## 漏洞题

先找 Source，再跟踪 Propagation，确认最终 Parser/Sink；随后说明安全不变量应是什么。不要把 payload、关键字或某个工具等同于漏洞定义。

## 协议题

说明参与方、状态、消息顺序、超时/重试和信任边界。进一步解释安全产品在链路中“能看到什么语义”。

## 身份题

明确主体、凭证、认证方、授权决策点、对象和生命周期；特别区分 Authentication 与 Authorization。

## 应急题

从 Validate -> Preserve Evidence -> Scope -> Contain -> Eradicate/Recover -> Improve 展开，始终考虑业务影响和证据完整性。

## 架构题

从资产与威胁模型出发，给出默认安全、最小权限、隔离、可观测性、故障模式、灰度与回滚、验证指标。
