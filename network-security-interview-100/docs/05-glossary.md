# 术语表

- **Asset**：需要保护的系统、数据、身份或业务能力。
- **Trust Boundary**：数据、身份或权限跨越信任级别的边界。
- **Attack Surface**：攻击者可触达的入口、功能、身份、协议或依赖集合。
- **Authentication**：证明主体是谁。
- **Authorization**：决定主体能对资源执行什么动作。
- **Telemetry**：用于检测、调查与验证的安全观测数据。
- **IOC**：具体可观察入侵痕迹。
- **IOA**：表示攻击行为的迹象。
- **TTP**：战术、技术和过程的行为模式。
- **SAST/DAST/IAST/SCA**：静态、动态、插桩式应用测试和软件成分分析。
- **BOLA/IDOR**：对象级授权缺失。
- **SSRF**：服务端代攻击者发起受控请求，导致网络/身份边界被借用。
- **SBOM**：软件物料清单，主要解决组件可见性。
- **KMS/HSM**：密钥管理系统 / 硬件安全模块。
- **JIT**：Just-In-Time privilege，按需短期授予权限。
