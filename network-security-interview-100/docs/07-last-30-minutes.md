# 面试前最后 30 分钟

## 遇到陌生漏洞题，先问 6 个问题

1. 不可信输入从哪里进入？
2. 中间经过哪些解析、转换和信任边界？
3. 最终被谁解释、执行或用于权限决策？
4. 真实影响是什么，是否受权限和网络可达性限制？
5. 最根本的工程修复是什么，哪些只是纵深防御？
6. 修复后用什么测试、日志或监控证明问题已关闭？

## 遇到应急题，先问 6 个问题

1. 事件是否真实？当前证据可信度如何？
2. 影响了哪个身份、资产和业务？
3. 时间线从哪里开始，当前是否仍在进行？
4. 哪些易失证据必须先保全？
5. 最小破坏的 containment 是什么？
6. 如何恢复并验证攻击者已无法继续访问？
