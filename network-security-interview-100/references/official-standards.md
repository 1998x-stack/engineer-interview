# 官方标准与参考资料

> 以下官方链接用于校准 2026 年口径。仓库正文只做必要转述，不复制长段标准原文。

## OWASP Top 10:2025

2025 Web 应用风险总览；A01 Broken Access Control，A03 Software Supply Chain Failures，A05 Injection。

- https://owasp.org/Top10/2025/

## OWASP ASVS 5.0.0

2025-05-30 发布；用于 Web 应用技术安全控制验证与安全开发要求。

- https://owasp.org/www-project-application-security-verification-standard/

## OWASP API Security Top 10:2023

API1 BOLA、API7 SSRF 等 API 风险。

- https://owasp.org/API-Security/editions/2023/en/0x11-t10/

## OWASP Web Security Testing Guide

Web 安全测试方法论参考。

- https://owasp.org/www-project-web-security-testing-guide/

## NIST Cybersecurity Framework 2.0

Govern / Identify / Protect / Detect / Respond / Recover。

- https://www.nist.gov/cyberframework

## NIST SP 800-61 Rev.3

2025-04 发布；将事件响应融入 CSF 2.0 风险管理。

- https://csrc.nist.gov/pubs/sp/800/61/r3/final

## NIST SP 800-218 SSDF v1.1

Secure Software Development Framework。

- https://csrc.nist.gov/pubs/sp/800/218/final

## NIST SP 800-207 Zero Trust Architecture

Zero Trust Architecture。

- https://csrc.nist.gov/pubs/sp/800/207/final

## MITRE ATT&CK Enterprise

对手行为、检测覆盖和 Purple Team 的行为模型；分类会持续演进。

- https://attack.mitre.org/tactics/enterprise/

## CISA Known Exploited Vulnerabilities Catalog

已在野外利用漏洞的权威目录，可作为漏洞管理优先级输入。

- https://www.cisa.gov/known-exploited-vulnerabilities-catalog
