# 答题方法：从“背术语”到“解释机制”

原 PDF 采用题目驱动式编排。仓库保留这一主线，并把每道题固定为以下六层：

1. **一句话核心结论**：先让面试官确认你没有概念性错误。
2. **机制链**：说明状态如何变化、数据结构/硬件/内核如何配合。
3. **Why**：没有这个机制时会发生什么。
4. **Trade-off**：性能、内存、复杂度、隔离、可靠性怎么交换。
5. **Linux/工程**：用真实接口、指标和故障场景落地。
6. **追问树**：把一个问题连接到下一层，而不是等待面试官逐字提示。

## 60 秒回答模板

```text
0-15s  ：定义 + 概念边界
15-40s ：核心机制链
40-55s ：Why + trade-off
55-60s ：主动抛出 Linux/工程延伸
```

## 训练标准

- 30 秒：定义准确、无混淆。
- 2 分钟：能解释机制和 Why。
- 5 分钟：能谈 trade-off、Linux 和工程场景。
- 10 分钟：能接连续追问并跨章节连接。
