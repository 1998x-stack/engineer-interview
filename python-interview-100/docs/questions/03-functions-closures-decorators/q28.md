## 最小可运行实验

```python
from functools import wraps

def retry(times):
    def deco(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            last = None
            for _ in range(times):
                try:
                    return fn(*args, **kwargs)
                except Exception as e:
                    last = e
            raise last
        return wrapper
    return deco
```

### 实验怎么读

代码共 14 个非空行，建议逐行观察“名字绑定/对象状态/控制流”的变化，而不是只看最终输出。
