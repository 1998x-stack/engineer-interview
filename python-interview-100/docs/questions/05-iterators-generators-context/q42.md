# Q42. iter(x) 实际发生了什么？

## 最小可运行实验

```python
class CountDown:
    def __init__(self, n): self.n = n
    def __iter__(self): return self
    def __next__(self):
        if self.n <= 0: raise StopIteration
        self.n -= 1
        return self.n + 1
```

### 实验怎么读

代码共 7 个非空行，建议逐行观察“名字绑定/对象状态/控制流”的变化，而不是只看最终输出。 类相关示例建议配合 `type()`、`__dict__`、`__mro__` 或 descriptor 方法调用顺序观察。

## 易错点 / Gotchas

- ❌ **常见误区**：在 __next__ 结束时返回 None 而不是 raise StopIteration。
  - **改进方式**：回答时先声明适用范围，再用一个反例或最小实验校验结论。
- ❌ **常见误区**：容器和 iterator 状态混在一起导致不能嵌套遍历。
  - **改进方式**：回答时先声明适用范围，再用一个反例或最小实验校验结论。

### 2. 边界条件：什么时候“标准答案”会失效？

实现 __iter__ 返回 self 时对象就是一次性 iterator；返回新对象时可支持重复遍历。

面试中主动给出边界，通常比多背三个 API 更能体现成熟度。可以使用下面的句式：

这样可以避免把“平均复杂度”“默认 CPython”“当前标准库实现”说成绝对规律。

### 3. 成本模型：不要只说对错，还要说代价

惰性计算的关键指标是**峰值内存、首项延迟、吞吐和可重复消费性**。O(1) 内存必须结合生成器内部状态与下游缓存一起判断。

| 空间 | 是否复制、缓存、持有对象或制造峰值内存？ |
