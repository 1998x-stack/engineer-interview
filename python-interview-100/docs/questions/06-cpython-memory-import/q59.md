# Q59. .pyc 是什么？什么时候会失效？

> **难度**：★★  ·  **频率**：中  ·  **关键词**：`pyc`, `bytecode cache`, `import`

## 题目定位

判断候选人是否能区分语言规范和 CPython 实现，并据此诊断内存与导入问题。

## 30-60 秒标准回答

> .pyc 是编译后的 Python bytecode/code object 缓存，用于减少后续导入的编译成本；它不是 native machine code，也不应视为稳定跨版本分发格式。

### 2. 边界条件：什么时候“标准答案”会失效？

pyc 不是源码保护机制，也不是通用独立可执行文件；缓存不存在/失效通常只意味着重新编译。

面试中主动给出边界，通常比多背三个 API 更能体现成熟度。可以使用下面的句式：

### 3. 成本模型：不要只说对错，还要说代价

CPython 内存题要区分**对象生命周期、Python heap、allocator、native heap 与 OS RSS**；import 题要区分查找、编译缓存和模块执行。

### 6. 面试追问：完整回答示范

**追问：如果面试官故意把条件改掉，应该怎么回答？**

追问“没有写权限还能 import 吗”时答：通常可以执行，只是无法写缓存；具体受路径/loader 影响。

**推荐回答结构：**

1. 先指出新条件改变了哪个前提；
2. 保留仍然成立的语义；
3. 撤回不再成立的实现/性能结论；
4. 给一个最小反例或测量方法。
