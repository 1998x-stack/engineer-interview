# PDF 内容追溯

本目录用于保证 Markdown 知识库与专业版 PDF 可追溯。

- `pdf-extracted-text.txt`：从专业版 PDF 提取的文本快照，仅用于内容校验。
- 原始 PDF：[`../assets/recommender_system_interview_100_pro.pdf`](../assets/recommender_system_interview_100_pro.pdf)。
- `manifest.json`（仓库根目录）：记录 100 题题号、章节、Markdown 路径与参考资料。

实际学习和维护应以 `docs/questions/` 下的结构化 Markdown 为主。
