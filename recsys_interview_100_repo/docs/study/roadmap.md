# 7 天 / 30 天冲刺路线

## 7 天

| Day | 重点 | 每天必须产出 |
|---|---|---|
| Day 1 | 完整链路 + 项目复盘 | 画出召回→排序→重排图；准备 3 分钟项目介绍 |
| Day 2 | 双塔 / InfoNCE / 负采样 / ANN | 手写 loss；解释 false negative / hard negative |
| Day 3 | FM / DeepFM / DCNv2 | 手推 FM 二阶优化与 DCN cross |
| Day 4 | DIN / DIEN / SIM / Transformer | 比较目标、复杂度与长序列方案 |
| Day 5 | MMoE / PLE / ESMM | 画结构；讲清 negative transfer 与 SSB |
| Day 6 | AUC / GAUC / A/B / Bias | 用真实项目解释 offline → online |
| Day 7 | 100 题模拟 + 前沿 | 只看题目口述；重点 HSTU / RankMixer / Generative Rec |

## 30 天

- **前 14 天**：按章节系统学习，至少完成两轮。
- **后 16 天**：项目深挖 + mock interview。
- 每 2 天做一次 45 分钟模拟面试，记录“被追问断点”，下一轮只补断点。
