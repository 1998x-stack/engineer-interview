# 使用说明与序言

## 原创声明

本仓库采用“问题驱动、递进追问、短答案 + 深答案”的训练方式。题解、扩展分析、图表与仓库结构为原创整理，不复制《剑指 Offer》或其他出版物的原文、例题解析或页面设计。

“真题 / 高频题型”来自公开面试经验中长期稳定出现的知识点，以及 Search / Relevance / Retrieval 岗位的核心能力模型。公开面经无法像公司官方题库一样逐题认证，因此应理解为 **高置信度面试题型 + 工业级知识框架**。

## 算法岗真正考什么

搜索面试不是 100 个孤立知识点，而是一条完整因果链：

```text
Query → Understanding → Recall → Rank → ReRank → Experiment
```

以及两条支撑链：`Indexing / Serving` 与 `Logs / Labels / Training`。

高级候选人与普通候选人的差别，通常不在于能否背出 BM25 公式，而在于：

1. 能否从公式解释行为，而不是只背符号；
2. 能否把离线指标、线上用户行为和偏差联系起来；
3. 能否做数量级估算与延迟/内存/召回权衡；
4. 能否看到 cascade 中错误如何传播；
5. 能否把模型、数据、系统和 A/B 组成持续优化闭环。

## 建议用法

- 第一遍：只看每题 **30 秒回答**。
- 第二遍：看 **5 分钟深度回答 + 数学/白板推导**。
- 第三遍：只看 **追问链**，脱稿回答。
- 第四遍：完成 **实战练习**，把知识转成工程判断。
- 最后：用 Q095–Q100 做 30–45 分钟系统设计模拟。
