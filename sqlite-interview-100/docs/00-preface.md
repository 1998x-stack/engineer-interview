# 前言：这不是“背答案”的 SQLite 题库

SQLite 的面试难点并不在 SQL 语法，而在于它把数据库服务器中通常隐藏的很多机制 - 文件格式、锁、日志、页面缓存、查询规划、并发边界 - 直接暴露给应用工程师。

本仓库把 100 道题组织为十条主线：架构定位、类型与 ROWID、事务与并发、Journal/WAL、索引、Query Planner、存储引擎、运维完整性、高级能力、生产系统设计。每题在 PDF 主干上进一步拆成：

- 30 秒标准回答；
- Know-Why 原理推导；
- 深入分析；
- 白板 / SQL 实验；
- 边界条件与易错点；
- 递进式追问；
- 工程 Checklist；
- 相关题跳转；
- SQLite 官方资料。

## 版本基线

截至 2026-09-02，本仓库以 SQLite **3.53.4（2026-07-24）** 为稳定版基线。面试前仍应在目标环境执行：

```sql
SELECT sqlite_version();
PRAGMA compile_options;
```

因为 Android/iOS SDK、Python/Node runtime、嵌入式设备和系统包管理器可能携带不同 SQLite 版本或构建选项。

## 四遍学习法

1. **第一遍**：只读“30 秒标准回答”。
2. **第二遍**：精读 Know-Why，自己重画因果链。
3. **第三遍**：关答案口述并运行实验。
4. **第四遍**：只刷 S 级与生产场景题，做跨章节串联。
