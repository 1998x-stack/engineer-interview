# 内容来源与增强说明

## PDF 基线

仓库附带的 `pdf/时间序列面试100题_专业详细版_2026.pdf` 是 100 题的内容基线。每个问题 Markdown 中以下区块来自 PDF：

- 20 秒标准回答（由 PDF 的“一句话标准回答”抽取）
- 核心公式 / 结构
- 原理深挖
- 易错点
- 高级加分点
- PDF 中列出的面试官继续追问

## GitHub 专业扩展

以下部分是仓库版新增，不应被误认为 PDF 原文：

- 题目真正考察的能力
- 进一步的统计/工程解释
- 追问回答方向
- 工程检查清单
- Python 示例与辅助模块
- 关联题、学习路线、标签索引
- 前沿模型延伸阅读

## 前沿资料

TS Foundation Model 相关内容以官方/原论文为优先参考，见 `REFERENCES.md`。前沿 benchmark 结果只作为研究资料，不代表具体业务数据上的稳定收益。

## GitHub v2 深度增强说明（2026-09）

每个 Q001-Q100 Markdown 中的 `深度专业版 v2` 均为仓库新增内容，不属于 PDF 原文。新增内容用于：

- 补充题目专属的理论机制、边界条件与反例；
- 将“模型知识”扩展为 point-in-time validation 与生产工程视角；
- 加入 2~3 分钟高级面试口述结构与自测清单；
- 对 Q97-Q100 的前沿 TSFM 内容使用 2026 年当前公开官方资料校准。

因此引用 PDF 时应只引用页面内明确标记的 `PDF 基线`；引用 v2 扩展时应引用本仓库版本。
