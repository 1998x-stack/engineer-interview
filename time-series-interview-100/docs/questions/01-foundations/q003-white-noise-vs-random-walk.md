## 20 秒面试回答

白噪声本身不可由过去线性预测；随机游走是白噪声的累积，其方差随时间增长，因此不平稳。随机游走的一阶差分就是白噪声。

### 1. 这道题真正考什么

把时间序列从“带时间戳的表格”提升为“带有信息集约束的随机过程”。重点是依赖、非平稳和信息可用性。

- 白噪声要求零均值、常方差、零自协方差；高斯白噪声才进一步具有由高斯性带来的独立性。

## 深度专业版 v2：从“会答”到“能推导、能上线”

> 这一节是 GitHub 版第二轮扩展，不改写上面的 PDF 基线。目标是把题目扩展到高级算法岗 / Forecasting Scientist / Staff DS 面试所要求的深度。

### 1. 核心机制拆解

1. 白噪声 $\epsilon_t$ 的关键是均值和方差稳定且序列间不相关；随机游走 $y_t=y_{t-1}+\epsilon_t$ 会累积 shock。
2. 随机游走的方差随时间线性增长：$\operatorname{Var}(y_t)=t\sigma^2$，因此不是协方差平稳过程。
3. 随机游走的一阶差分就是白噪声，这正是 ARIMA 中 integration/differencing 的最小原型。

### 2. 一条可复用的推理链

回答 **“White Noise 和 Random Walk 有什么区别？”** 时，推荐按下面顺序组织，而不是先抛模型名：

1. **定义对象与信息边界**：目标变量、时间粒度、forecast origin、horizon、当前可用信息分别是什么。
2. **写最小数学结构**：指出核心随机关系、损失函数或约束。
3. **说明成立条件**：平稳性、独立性、未来协变量可用性、样本长度、分布假设等。
4. **给反例或失败模式**：至少说明一种“理论上成立但工程上失败”的情况。
5. **落到 OOS 证据**：用 rolling / expanding backtest 和强 baseline 证明选择，而不是靠模型复杂度。

### 3. 典型反例、边界与故障模式

- **边界 1：** 把“白噪声”误解成必须服从高斯分布；Gaussian white noise 是更强条件。
- **边界 2：** 用样本 ACF 很小就断言真白噪声；有限样本下只能通过统计检验和残差诊断获得证据。

> **面试习惯：** 只会描述模型“优点”通常是中级答案；主动说出失效条件、可观测症状和修复动作，才更接近高级答案。

### 4. 具体业务例子

资产价格常被用作“近似随机游走”教学例子，而价格收益/差分更接近平稳序列；但真实金融数据还常有波动聚集。

把例子继续追问到工程层时，至少要回答：**这个变量在预测 cutoff 当时真的可见吗？这个 horizon 的误差由谁承担？模型失败时 fallback 是什么？**

### 5. 高级加分点

若误差不相关但不独立，二阶模型可能看似白噪声而高阶依赖仍存在；这也是 ARCH/GARCH 出现的背景。

这一点不是为了“炫术语”，而是为了说明你能把统计原理、验证协议和生产约束放在同一个框架里。

### 6. 统计假设检查 Checklist

- [ ] 时间索引/频率定义是否正确
- [ ] 是否存在趋势、季节、结构突变
- [ ] 样本之间是否存在实体/横截面依赖

建议把 checklist 真正落实到实验记录中：每个候选模型保存 `data_snapshot / cutoff / feature_version / model_version / horizon / metrics_by_segment`，才能复现实验和定位线上偏差。

### 8. 2～3 分钟完整口述参考

>

## 面试表达模板

> **结论：** 白噪声本身不可由过去线性预测；随机游走是白噪声的累积，其方差随时间增长，因此不平稳。随机游走的一阶差分就是白噪声。  
> **原理：** 随机游走是理解 unit root、naive forecast 与 differencing 的入口。对 random walk，最优一步点预测常常就是最后观测值。  
> **边界：** 说明何时假设会失效，以及如何通过 rolling/expanding backtest 验证。
