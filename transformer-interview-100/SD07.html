SD07 现代 Decoder-only Block 与 2017 原版的演化

1. 2017 原始 Transformer

经典 encoder-decoder，Decoder 子层：

  1. masked self-attention；
  2. cross-attention；
  3. ReLU FFN；
  4. Post-LayerNorm；
  5. sinusoidal position encoding。

3. 为什么 Decoder-only

统一 next-token objective、prompt/answer 同一序列、in-context learning 和 serving API 简洁。

但 encoder-only / encoder-decoder 仍适合 representation、retrieval 和特定 seq2seq。

4. Post-LN → Pre-Norm

主要目标：深层训练稳定性与 gradient path。

5. Sinusoidal/Absolute → RoPE

位置从 input embedding 层转向 query-key geometry，直接影响 pairwise score。

6. ReLU/GELU → SwiGLU

FFN 从单激活扩展为 learned gate，提升表达能力；参数预算需重新配平。

7. MHA → GQA/MQA

主要由 autoregressive serving 的 KV cache / bandwidth 驱动，而不是训练参数本身。

8. Attention 数学 → FlashAttention Kernel

模型公式几乎不变，但实现从 materialize $T^2$ 中间矩阵变为 tiled online softmax，体现“算法与硬件协同”。

9. Dense FFN → MoE

解耦总参数容量与每 token active compute，但引入 routing/all-to-all。

10. 架构比较方法

任何现代变体都按以下 6 维比较：

维度 问题
Objective 是否改变训练概率分解？
Expressivity 是否改变函数族/归纳偏置？
Params 总参数/激活参数？
FLOPs train/prefill/decode 分别？
Memory/IO activation/KV/HBM？
Systems kernel/通信/调度是否成熟？

11. 面试追问

为什么现代 LLM 不是“2017 Transformer 放大版”？ 因为训练稳定性、位置、FFN、KV、GPU IO、并行和 serving 都发生结构性变化。
