# 前言：这套题库如何使用

本仓库由《Web 漏洞面试 100 题 · 2026 专业题解手册》扩展而来。

它不是 Payload 速查表，而是一套面向面试与 AppSec 工程的安全推理框架。每道题都强调四层回答：

1. **定义 / 边界**：概念究竟约束什么，不能解决什么。
2. **根因 / 机制**：为什么漏洞成立，解释器、浏览器、授权或状态机在哪一步失去安全不变量。
3. **工程控制**：如何在代码、框架、平台、网络和流程层形成纵深防御。
4. **验证 / 监控**：如何通过代码审计、自动化测试、日志与生产监控证明控制真正有效。

## 内容分层

每个 `Qxxx.md` 分为两部分：

- **PDF 母版题解**：忠实保留原手册中的题目、结论、考察点、原理、工程原则、Gotchas、追问与复习检查。
- **GitHub 增强版**：新增更细的工程解释、安全不变量、审计清单、设计评审问题、2026 标准映射与关联题目。

## 安全边界

仓库用于合法、授权的安全学习、面试与防御性工程实践。内容聚焦根因、审计和防御，不提供针对真实目标的破坏性攻击链或滥用步骤。
