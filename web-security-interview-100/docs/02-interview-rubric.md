# 面试评分尺：从 60 分到 90+ 分

| 水平 | 典型表现 | 面试官通常看到的能力 |
|---|---|---|
| 60 | 能给定义和常见防御 | 知道名词，概念基本正确 |
| 75 | 能解释根因、边界、典型错误防御 | 具备工程理解，知道“为什么” |
| 85 | 能比较方案、讨论 trade-off、设计验证 | 能独立做 AppSec 分析 |
| 90+ | 能从 trust boundary / parser / lifecycle / invariant 抽象系统问题 | 能做架构安全、代码审计与安全平台设计 |

## 一分钟高分回答结构

```text
一句话结论
  ↓
根因 / 安全边界
  ↓
错误方案为什么不成立
  ↓
工程控制（预防）
  ↓
测试/审计/监控（验证）
  ↓
进一步 trade-off / 追问
```


## 高级评分维度（建议）

| 维度 | 初级 | 中级 | 高级 |
|---|---|---|---|
| 根因 | 能复述定义 | 能解释机制 | 能抽象到通用安全模型 |
| 边界 | 只说输入校验 | 能指出信任边界 | 能分析跨服务/代理/异步边界 |
| 防御 | 给单点修复 | 给多层控制 | 能说明控制职责与失败模式 |
| 验证 | “测试一下” | 给具体负向用例 | 建立自动化回归 + 运行时证据 |
| 权衡 | 只追求最严格 | 能说兼容性/性能 | 能做风险分层和平台化治理 |

优秀回答通常同时包含 **机制正确、工程可落地、边界清晰、验证可重复** 四个特征。
