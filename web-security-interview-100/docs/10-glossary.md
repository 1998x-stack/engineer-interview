# 术语表

## AuthN

Authentication，认证：确认主体是谁。

## AuthZ

Authorization，授权：确认主体是否可以对某资源执行某动作。

## BOLA

Broken Object Level Authorization，对象级授权失效。

## BFLA

Broken Function Level Authorization，函数级授权失效。

## BOPLA

Broken Object Property Level Authorization，对象属性级授权失效。

## SOP

Same-Origin Policy，同源策略。

## CORS

Cross-Origin Resource Sharing，跨源资源共享。

## CSRF

Cross-Site Request Forgery，跨站请求伪造。

## XSS

Cross-Site Scripting，跨站脚本。

## SSRF

Server-Side Request Forgery，服务端请求伪造。

## SSTI

Server-Side Template Injection，服务端模板注入。

## SCA

Software Composition Analysis，软件成分分析。

## SBOM

Software Bill of Materials，软件物料清单。

## SAST

Static Application Security Testing，静态应用安全测试。

## DAST

Dynamic Application Security Testing，动态应用安全测试。

## IAST

Interactive Application Security Testing，交互式应用安全测试。

## Security Invariant

系统在任何允许状态下都必须持续成立的安全规则。

## Trust Boundary

数据、身份或控制跨越不同信任等级的位置。

## Parser Differential

多个组件对同一输入产生不同语义解释。

## Fail-secure

依赖/异常失败时保持安全不变量，而不是自动开放。
